# Package matrix re-run after the fixing phase (2026-09-30)

Re-run of the Phase-1 package matrix (`REPORT.md`, `scripts/package_bench.py`) to close the campaign's fixing
phase. Same 49 package workloads + 2 controls, same harness, same Node/Bun pins, compiled **from source** with Perry
and compared against **Node 26.5.1 and Bun 1.3.14 only** (no comparison with the removed bindings). Every number is
gated on output byte-identical to Node and on the liveness check (package modules compiled natively, no removed
`perry-ext-*` symbol) — all 49 workloads passed liveness on both hosts.

## Headline

- **Instructions:** over the 38 workloads measured correct in both runs, the Perry/Node geomean went **19.7× → 12.4×**;
  median per-workload change in Perry instructions **−32 %**. Only `redis/set_get` (+4 %) and `date-fns/diff_interval`
  (+7 %) got more expensive.
- **Wall (mini):** over the 30 workloads with wall data in both runs (excluding `exponential-backoff`), Perry/Node
  geomean **18.7× → 12.0×**, median change **−36 %**.
- **Correctness:** 8 workloads that failed at the baseline now produce Node's output (`node-forge/sha256`, `/hmac`,
  `/aes_cbc`, `jsonwebtoken/rs256`, `node-cron/match`, `pg/select`, `pg/insert_batch`, `rate-limiter-flexible/consume`),
  and `mongodb/insert_find` (manifest `known_hang`, #11460) now runs correctly. **2 Perry failures remain**, both new
  symptoms, both with package-free repros (below).
- **Still > 2× Node on instructions: 44 of the 47 workloads Perry runs correctly.** Under 2×: `jsonwebtoken/decode`
  (1.91×), `fastify/listen_fetch` (1.71×), `exponential-backoff/retry` (1.03×). 31 are still > 10×.
- **Peak RSS (mini):** Perry is below Node on 38 of 39 workloads; the exception is `dayjs/diff_startof` (195 MB vs
  91 MB; it was 214 MB). Only `moment/parse_format` grew vs the baseline (38 → 42 MB, the #11645 trade the owner
  accepted, tracked in #11699). On Linux `mongodb/insert_find` peaks at **1,185 MB vs Node's 115 MB** (new data —
  it never ran before).

## Perry correctness failures (output ≠ Node)

Both reproduce deterministically (3/3) at `9e29f59d43` **and on current `origin/main` `9e05951071`** (re-checked 2026-10-01), with the package-free repros below as well as the workloads.

**A. `node-forge/rsa_sign`** — `TypeError: Cannot read properties of undefined (reading 'data')` on the first
`privateKeyFromPem`. Root: inside a `do { … } while` body, **`this` is `undefined` in any non-class function**
(function expression assigned to a prototype, object-literal method, `f.call(obj)`); the same body in a `while`
loop, or in a class method, works. node-forge's `ByteStringBuffer.prototype.getInt` is such a loop, reached by ASN.1
long-form lengths (any DER length ≥ 128 bytes).

```ts
const o = { d: 7, f(n: number) { let r = 0; do { r += this.d; n--; } while (n > 0); return r; } };
console.log(o.f(1));   // node: 7   perry: TypeError: Cannot read properties of undefined (reading 'd')
```

**B. `fastify/inject`** — `ERROR Cannot read properties of undefined (reading 'once')` (the baseline's `setHeader is not
a function`, #10454, is fixed). Root: light-my-request's `Response` is a CommonJS function-constructor subclass of
`http.ServerResponse` (`http.ServerResponse.call(this, req)` + `util.inherits`); `this.assignSocket(sock)` is
silently a no-op on it, so `this.socket` / `this.connection` stay `undefined` and `this.connection.once(...)` throws.

```js
// sr3.cjs
const http = require('node:http'), { Writable } = require('node:stream'), util = require('node:util')
function Response (req) {
  http.ServerResponse.call(this, req)
  this.assignSocket(new Writable({ write (c, e, cb) { cb() } }))
  console.log(typeof this.socket, typeof this.connection)   // node: object object   perry: undefined undefined
}
util.inherits(Response, http.ServerResponse)
module.exports = Response
// main.ts:  import http from "node:http"; import R from "./sr3.cjs"; new (R as any)(new http.IncomingMessage(null as any));
```

The same shape written in a `.ts` file throws instead (`ServerResponse.prototype.assignSocket called on an object that
is not a ServerResponse`).
