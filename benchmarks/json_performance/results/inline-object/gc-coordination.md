GC production files, thresholds, policy, gc_bump_malloc_trigger and the parse-boundary hook implementations remain unchanged from v0.5.1520. This does NOT mean JSON/GC interaction is unchanged.

The inline-object leaf changes crates/perry-runtime/src/json/parse_api.rs and adds parse_inline_object.rs. It fully decodes eligible <=64-byte objects into inline stack values before any collection. A schema-cache miss returns to the original parser before allocation or collection. On a hit, RuntimeHandleScope roots the existing key array, gc_collect_pending_suppressed_parse runs, and ordinary js_object_alloc services the final allocation trigger. The initialized object is rooted, keys are rederived, and native shape metadata is minted after allocation; an old ShapeId could have retired during GC. Field initialization, cache cleanup and pressure scheduling do not allocate managed values. This leaf avoids the general parser's suppression/unsuppression and gc_bump_malloc_trigger sequence. Caller suppression flags remain untouched by the leaf itself.

No key bytes or JSON output are retained in a new cache. The existing bounded parse-schema cache supplies canonical key metadata. The original input is no longer needed after successful native decoding; inline values hold no managed edges. Values are decoded on every call and each successful parse allocates a fresh ordinary object.

The new test allocation counter accounts for exactly the returned objects across 1000 calls. Moving-GC tests prove actual input/output movement and valid keys/values. The dedicated stronger test that moves a nursery canonical keys array and then drops cache roots remains follow-up validation, not an accomplished claim. All 36 compiled stress runs use actual copying minors and moved objects. GC directory changes are tests only; source hashes and compiled result records are included.

Earlier branch changes to general parse input rooting/rederivation, scalar/empty leaves and stringify ownership are listed in ../plan-scan/gc-coordination.md. No coordination message has been sent externally.
