This experiment changes the callback-free nested-record emitter only. Private key-plan offsets are established while appending complete escaped UTF-8 keys; the hot loop uses those proven boundaries without repeating character-boundary checks. Text up to 32 bytes is copied inline with first/last 16-, 8-, 4- or 2-byte unaligned words, or one byte. Loads and stores stay entirely within their respective exact-length ranges. Source and destination allocations are disjoint; overlapping first/last words within a range are deliberate. Output reserve occurs before deriving destination pointers, and the String length is published only after writing valid UTF-8. Longer text retains the existing general copy.

Inline strings at most five bytes use a guarded ASCII path: every byte must be 0x20..0x7f excluding quote and backslash. Those bytes need no escaping and prove valid UTF-8; quotes are assembled into seven bytes of native stack storage and appended once. Controls, quotes, backslashes, Unicode and malformed inline bytes retain the previous writer/null behavior. Numbers use an exact i32 equality guard after saturating conversion; -0 spells 0. Fractions, larger values, NaN/Infinity and NaN-boxed int32s retain the existing formatter. No benchmark-specific values, input memoization or cross-call result caches are used.

Every per-instance header/layout/prototype/descriptor/allocation-bound check and every ShapeId plan budget remains unchanged. The complete successful attempt still has no managed allocation, callback or safepoint, and all native scratch is destroyed before fallback. The existing output rollback, serializer-state and actual-moving getter tests remain active. GC collection policy, thresholds and hooks remain unchanged from 0.5.1520; the inherited retained-growth diagnostic repair is explicitly documented.
