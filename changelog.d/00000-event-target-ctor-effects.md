`new EventTarget()` no longer holds the realm in the facts solve. The runtime declaration of the built-in `EventTarget` constructor now states its effects (`stores(fresh); returns(fresh(EventTarget.prototype))`), which is exactly what `js_event_target_new` does: it allocates a fresh object, stores its listener state on that object only, links it to `EventTarget.prototype`, and reads no argument or global. Before, the declaration had no effects, so the call counted as one of an unknown constructor: the realm was held and the intrinsic iterator `next` behind every program `for..of` counted as written.
