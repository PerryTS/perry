`--target web`: a class value carries its named static methods, so a call through it works: `const K: any = C; K.m()`, a subclass value's inherited `m()`, and an arrow that calls a static method of a class declared after it (`` () => C.tag`x` ``). An inherited static method runs with the subclass as `this`, a nearer static field still shadows it, and a class expression's static methods read their own evaluation's captures. These evaluated to `undefined` before (#14727).
