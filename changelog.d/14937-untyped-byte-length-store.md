Untyped `x.length` on a typed array, `Uint8Array` or `Buffer` is read from the receiver's header at the access site instead of through the complete property read, and a `Uint8Array` store whose value is not provably a Number (`b[i] = table[b[i] & mask]`) stores a value that is a Number at runtime inline. nanoid's pool refill (closure-captured table, `Buffer` pool) runs ~9× faster and an `any`-typed `Uint8Array`/`Uint16Array` loop ~5–6× faster (#10515).
