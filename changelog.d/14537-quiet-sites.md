Fix: an indexed loop "without calls" sees a length change made by program code its own reads, stores and operators run. `for (let i = 0; i < xs.length; i++)` with no call in its body is lowered with `xs.length` read once when the loop's walker (`classify_for_length_hoist`) finds no store in the body that can change it. The walker took a loop without call expressions for a loop that runs only its own code, and walked through property reads, element reads and stores, computed stores, operators, conversions, `Math` intrinsics, `new Error(m)` and array spread without asking what they run: a setter or a Proxy `set` trap behind `q["w"] = 1` or `q.w = 1`, a getter or `get` trap behind `q.v`, `valueOf` / `toString` / `@@toPrimitive` behind `n + q`, `q < 5`, `-q`, `` `${q}` ``, `Math.abs(q)`, a key's `toString` behind `o[k]`, an iterator behind `[...q]`. When that code popped the walked Array the loop read past the end (`1,2,3,undefined,undefined,undefined,` for node's `1,2,3,`), and when it pushed, the loop stopped early (64 constructs wrong on main when the Array is also held by a field, 8 more when the Array itself carries the code). The walker now asks, per site, whether it runs program code (`perry-codegen` `quiet`), and the answer comes from the whole-program facts (new `perry-wpfacts` `quiet_sites`, a projection of what the solve already decided: the read verdicts, the element sites' receivers and keys, the value nodes' kinds): a named read is quiet when its verdict is an own data slot or an intrinsic member, an element site when its receivers are plain program Arrays (or Strings) under a Number key with nothing defined on them, a field store by the facts' store rule, an operator when its operands are primitives. No fact means the site may run code and the loop reads its length at every step. A versioned clone is not asked: it is dropped when a call survived in its emitted blocks. Check mode compares the kept length with the live one in such a loop's condition block ("quiet sites"); `PERRY_FACTS_SABOTAGE=quiet` is the negative control. `PERRY_FACTS_QUIET_SITES=0` restores the previous walker.
