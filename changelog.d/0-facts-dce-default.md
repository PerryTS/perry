Dead-body removal from the whole-program facts is on by default (`PERRY_FACTS_DCE`, before: off unless `=1`). A body the activation reach calls inactive (solve complete, body classified, no path reaches it) is emitted as an `llvm.trap` entry, and LLVM drops its statements. An incomplete reach, a missing or a new identity stays active. `PERRY_FACTS_DCE=0` turns removal off (emitted code = the previous default); the switch stays a compile-cache input. The known false inactive claims of check mode (`PERRY_VERIFY_FACTS=1`), activation classes A–H and the call-kinds report, are fixed, and the full parity corpus has no check-mode false proof. `scripts/test-dce-stub.py` pins the default: it uses the S0 control `noreachprotoaccessors` as its deliberate false claim, since the iterator-close witness it used before is now reached.
