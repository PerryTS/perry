Add an explicit `--sea` profile that exposes embedded assets through `node:sea.isSea()`, `getAssetKeys()`, `getAsset()`, and `getAssetAsBlob()` without a Node executable or runtime extraction. This follows the asset API in [Node v26.12.1](https://github.com/nodejs/node/blob/v26.12.1/lib/sea.js) and [Node v27.0.0-alpha.0.0.0](https://github.com/nodejs/node/blob/v27.0.0-alpha.0.0.0/lib/sea.js). `getRawAsset()` and Node's `useVfs` filesystem behavior remain unsupported.
