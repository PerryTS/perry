Performance: `for (const x of A)` over an Array that whole-program facts prove immutable (a plain program Array literal that no store, in-place method, native or unknown code ever writes after its birth: `Rep::Arr` with `im`) no longer tests the Array's header or asks the runtime at the loop's entry, and its iterator-protocol copy is not compiled. When every Array the loop may walk is such a literal of the same Number constants (`BindingFacts::const_elems`), the loop is emitted as its iterations in order, each with the binding a constant: no counter, no element read, no back edge and no loop poll (at most 8 elements, and at most 1024 HIR nodes over all copies; a larger loop keeps the counted walk). `PERRY_FACTS_CONST_ARRAYS=0` restores the previous loops; `PERRY_VERIFY_FACTS=1` runs the replaced entry and compares every constant with the Array's slot (`constant array`), and `PERRY_FACTS_SABOTAGE=arrconst` is the negative control.
