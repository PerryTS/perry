`--target web`: a `console.log`/`warn`/`error` call is an expression whose value is `undefined` in the WebAssembly backend too, so a module holding one in a conditional arm, an initializer or an arrow body validates. With the whole-program facts on, every `console.log(...)` lowers as the namespace pair `NamespacePatched(console) ? <generic call> : <console call>`, so every web module failed validation at boot (#14876).
