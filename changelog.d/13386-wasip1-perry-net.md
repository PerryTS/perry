Add the opt-in `PERRY_WASM_NET=1` build of the `--target wasip1` output, which imports three `perry_net` functions so a program can make outbound TCP connections to names and addresses without blocking the event loop while they resolve and connect, and use `dns.lookup` (which, as on `--target wasi`, waits for the host's answer); the default build still imports only `wasi_snapshot_preview1`. The reference preview 1 host implements the imports with an asynchronous resolver and a `--dns` knob for the suite, and the import checker now allows each import by name and signature.
