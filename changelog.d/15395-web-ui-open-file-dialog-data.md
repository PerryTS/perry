Add `openFileDialogData(accept, callback)` to `perry/ui`. On the web target it opens the file picker filtered by `accept` and passes the callback the file's name and its contents as a base64 `data:` URL, ready for an upload request; `openFileDialog` gives a browser page only the name. A cancelled picker passes two empty strings and an unreadable file its name alone; native backends open no dialog and report a cancelled one.
