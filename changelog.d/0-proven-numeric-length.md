Fix: `x.length` counts as a Number in arithmetic and comparison lowering only when `x` is a literal, a binding whose initializer proves a String or an Array, or a binding the whole-program facts prove holds only strings and ordinary Arrays. A declared `string[]` element written through `any` can be a Number, whose `length` is `undefined`; a Number accumulator adding it printed `undefined` instead of `NaN`. `PERRY_PROVEN_NUMERIC_LENGTH=0` restores the annotation answer.
