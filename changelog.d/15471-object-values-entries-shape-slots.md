`Object.values` and `Object.entries` of an ordinary object now copy the values straight from the shape's slots, driven by the shape's immutable own-key list, instead of snapshotting the keys and doing a name lookup per key (17114 to 592 Ir/call for values, 24889 to 1487 for entries on an 8-key literal); a table with no hidden or deleted keys also copies its keys in one block in its own out-of-line function, which lowers `Object.keys` and `for-in` on such objects.
