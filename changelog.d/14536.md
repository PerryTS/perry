`arr.length = n` on a non-extensible or sealed Array follows ArraySetLength: a non-extensible Array shrinks and grows, a sealed one grows and rejects a shorter length at its highest element, and a truncation stopped by an element that cannot be deleted throws a TypeError in strict code (`Reflect.set` returns `false`). Assigning `length`, `byteLength`, `byteOffset` or `buffer` on a typed array no longer creates an own property: it is ignored in sloppy code and throws in strict code.
