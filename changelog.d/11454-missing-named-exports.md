#10433: Diagnose statically missing named imports before code generation instead of emitting unresolved native function symbols. Validate relative and package imports through renamed/star re-export chains, handle cycles, and preserve erased/dynamic/require imports and builtin-backed exports. Errors identify the import, local alias, importer, and resolved module, with a CommonJS default-import hint.

A TypeScript importer is held only to the named imports it reads as values: TypeScript elides a specifier used only in type positions (mongodb's `src/bson.ts` imports `DeserializeOptions`, which `bson` exports only via `export type { .. }`), so such a specifier has no runtime export to find and never reaches the linker. JavaScript importers keep Node's rule that every named specifier must resolve.
