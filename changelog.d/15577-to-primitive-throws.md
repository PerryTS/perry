ToPrimitive throws a `TypeError` when `Symbol.toPrimitive` is neither undefined, null nor callable (`number 42 is not a function`) and when it returns an object (`Cannot convert object to primitive value`), for `isNaN`, `isFinite`, `Number`, `Math.*`, `String`, templates, property keys and the `+` operator alike. A `valueOf` that returns an object on an object without `toString` now throws after one call instead of being called twice.
