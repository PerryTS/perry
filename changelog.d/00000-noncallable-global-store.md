A program store that replaces a declared global the runtime cannot call (`globalThis.performance = {...}`, also `Math`, `JSON`, `Reflect`, `Intl`, `Atomics`) is now that global's program field instead of an escape: the runtime reaches those objects through its own cells and never reads the global by name, so the realm is no longer handed to unknown code and the program's other sites stay proven. Constructors and functions, `process`, `console` and `WebAssembly` (which the runtime does read by name) keep the escape.
