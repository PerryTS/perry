A complete constructor-free construction is born as its image (birth cost): a closed object literal, or a class whose constructor is exactly one `this.f = p` store per field, used to call the shared birth helper in its nursery arm (two loops that fill every slot with its default), give each I32 lane its word of 0, and then overwrite every slot with its value. When the whole-program facts say the class has a fixed layout and every field is a definite birth field at codegen's slot, the nursery arm now writes the header image and each slot's final word once, with no call; the allocating arm and a construction whose values fail the number test keep the shared helper and the constructor (one call site instead of two). Check mode marks every slot unwritten before the image and reports one still marked (`birth image`, exit 86), and every build asserts that no call sits between the bump and the last slot store. `PERRY_BIRTH_IMAGE=0` restores the shared fill; `PERRY_SITE_STATS=1` names each image birth and each refusal with its reason.
