With `PERRY_FACTS_VALUE_RECORDS=1` a binding that holds only instances of an admitted value-record template has the representation `Rep::Record` (joined only with itself; until codegen lowers records in VR-3 its slot is the Boxed word, so no signature or generated code changes), and check mode (`PERRY_VERIFY_FACTS=1`) witnesses records: every instance of an admitted template is claimed at birth (an OBJECT header bit used in check mode only), and every compiled `===`/`!==`/`==`/`!=` between non-literal operands and every `switch` case exit 86 on a claimed operand (the runtime's own identity routes wait for VR-3's copies: a flag test there would cost release code). New S0 arms `vrident`, `vrswitch`, `vrinline` and parity fixtures with their expected ledger verdicts (value records VR-2).
