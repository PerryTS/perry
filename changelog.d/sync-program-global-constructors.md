A program whose only asynchronous construct is `new Promise(executor)` (or another global constructor named by `new`, such as `new MessageChannel()` or `new BroadcastChannel(name)`) keeps its event loop: `new Promise(res => res(1)).then(v => console.log(v))` printed nothing and exited 0, and an unhandled rejection in such a program exited 0 without a report. The compiler's "this program schedules nothing" proof (`sync_program`) read the class name of `New { class_name }` as string data; it now accepts that name only when the module declares or imports the class, or when it is a built-in constructor known to be synchronous. No switch: off would be the wrong answer. Programs that keep the proof are byte-identical.
