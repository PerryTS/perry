Enforce the maximum string length (536,870,888 UTF-16 units) on every string allocation path: concatenation, appends, templates and JSON.stringify throw node's RangeError: Invalid string length instead of building an over-long string (a doubling concat past 2^31 bytes used to crash), checked before any storage is reserved; Buffer#toString / TextDecoder#decode throw node's Error [ERR_STRING_TOO_LONG], and Blob#text, Response#text/json, Request#text and stream/consumers text()/json() reject as node does without leaking the byte buffer. A Buffer, typed array, ArrayBuffer or Blob body longer than the limit is accepted by new Response() and new Request() again (its bytes are carried outside the string type), so arrayBuffer(), bytes() and blob() read it. execSync, execFileSync and spawnSync release their captured output before throwing ERR_STRING_TOO_LONG (or a failed command's error), and exec/execFile before their RangeError.
