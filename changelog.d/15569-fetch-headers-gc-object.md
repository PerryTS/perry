`Headers` is an ordinary GC object that owns its header list: it is born on `Headers.prototype` (class `HEADERS`), its methods are realm members of that prototype, and a subclass `super()` attaches the list to `this`. The Headers id registry, its bound-method cache, the dispatch-hub and kind-probe arms and the lifecycle release/observe arms are gone; a Request/Response keeps its Headers object as a GC edge. Node parity: `forEach` passes the Headers object as its third argument, `JSON.stringify(headers)` is `{}`, an unbound `get` and an invalid name or value throw `TypeError`, `response.headers.append` keeps combined values, `Response.error()` headers are immutable, `h.expando = 5` is an ordinary property, `new Response(body, { headers: [[k, v]] })` keeps pair-list headers, and `new Response(null, response)` takes the headers of the init response.
