A construction that provably runs no code outside its own class no longer makes the inliner forget what earlier objects are. `perry-transform` gains an effect summary (`effects`): a function is closed when its body only stores parameters or literals into fields of its own receiver, and each parameter is then either dropped or kept by the receiver. The first use is `new`: for a class of the module with no parent, no accessor for a stored name, no computed member and no decorator, whose constructor is closed, the exact-receiver facts of other locals survive the construction. `const a = new V(i, 1); const b = new V(2, i); s += a.dot(b)` now inlines `dot` and keeps both objects off the heap (100M iterations: 0.57 s to 0.29 s, no heap use). A constructor that computes with an argument, calls anything, stores into another object, has a default, a parent or a field initializer that reads, keeps today's behaviour.
