Fixed `new WebAssembly.Module(bytes) instanceof WebAssembly.Module` returning `false` under the wasm-host (wasmi) runtime. The module wrapper's `[[Prototype]]` does not reach `WebAssembly.Module.prototype`, so it is brand-checked directly. The brand is a live host module pointer this runtime handed out (recorded at construction and required by the check), not the enumerable, user-writable `__wasmKind` string — so a plain object that copies the internal fields (`{ __wasmKind: "module", __wasmModulePtr: 1 }`) correctly answers `false`, matching Node.
