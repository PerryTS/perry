Fixed `new WebAssembly.Module(bytes) instanceof WebAssembly.Module` returning `false` under the wasm-host (wasmi) runtime. The module wrapper's `[[Prototype]]` does not reach `WebAssembly.Module.prototype`, so it is brand-checked directly. The brand is now a GC-aware internal wrapper identity paired with its trusted host handle, not the enumerable, user-writable `__wasmKind` or `__wasmModulePtr` fields. Copying both fields from a genuine module therefore cannot forge `instanceof` or pass an arbitrary pointer to module metadata host calls.
