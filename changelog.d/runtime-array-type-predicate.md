Every test for the ordinary array GC type now goes through one predicate in `perry-abi/src/array_type.rs`: `gc_type_is_array!`, `gc_type_is_not_array!` and `gc_array_type_pat!` in the runtime and perry-stdlib, and `target_layout::emit_gc_type_is_array` / `emit_gc_type_is_not_array` for the inline type-byte tests codegen emits. Each expands to the comparison it replaces, so generated code and runtime behavior are unchanged. Column (e) of `scripts/check_object_header_access.sh` (now a CI `lint` step, with a self-test) fails on a new raw `GC_TYPE_ARRAY` compare, so the record-array type of value records VR-4b has one place to be told apart from an ordinary array (value records VR-4a).
