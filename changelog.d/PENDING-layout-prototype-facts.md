Builtin prototype holders allocated on a runtime layout (Array.prototype's named-property holder, added in object model step 7) now carry the same per-object facts as every other layout-born object: plain ordinary, null prototype, descriptors and integrity. Both layout allocators now set these facts through one helper. Previously the holder carried an Ordinary-kind shape without the plain-ordinary record, which tripped the shape-store-facts audit in debug builds.
