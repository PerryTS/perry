Namespace class static calls without a native dispatch entry now read and call the exported constructor value. This fixes `ns.URL.canParse`, `ns.KeyObject.from`, and `ns.Stream.getMaxListeners`, while preserving Buffer's existing value route and native entries with either a matching class filter or a module-wide filter (including inherited events/cluster statics). Static reads, getters, and user-module classes continue through ordinary value lowering. Missing built-in static values are tracked separately in `issue-missing-statics.md`.
