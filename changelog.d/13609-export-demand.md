Compiled programs no longer contain declarations that only unused exports reach. Between the two collection walks the compiler follows the program's export demand through every import, re-export and `export *` by name, and the second walk lowers each module without the top-level items nothing demands: function, class and `const` declarations whose evaluation only creates their bindings, decided by structure, together with the import specifiers only those items used. Every module still evaluates, in the same order, with every item that can run code. A module whose exports can't be followed by name (dynamic `import()`, a namespace used as a value, CommonJS, `eval`) keeps everything. `new globalThis.<name>()` for a name no global owns now throws TypeError instead of building an empty object.
