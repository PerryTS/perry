Whole-program facts: an array's helper nodes are made once per array, not once per call. What iterating an array yields (its elements and, when it may hold a hole, `undefined`) and the `constructor` that ArraySpeciesCreate reads off it depend on the array alone, so one node per array object now serves every `values()`, `entries()`, `[Symbol.iterator]()` and species-creating call on it; each call keeps its own edge into its iterator or result array. The facts do not change (every proven site is the same in tssrc, tscwork, fastify_inject, chess, chesst and d_zod4); the solver makes fewer nodes and does less work (tssrc: 3,026,132 to 2,797,461 nodes, work 87,456,134 to 83,099,461, points-to entries 10,366,213 to 8,784,107).
