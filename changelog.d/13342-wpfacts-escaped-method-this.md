Per-unit facts no longer prove a published class method on its own class alone once the method leaves its module as a value. A unit that holds the method as a value (a result, a field, an array element, the prototype) admits and publishes the receivers it runs it on, as for a method call; a method that leaves through something no contract describes runs on any receiver and any arguments, as whole-program facts assume of unknown code. Fixes a per-unit miscompile where `C.box().get.call({ pad: 0, raw: "s" })` read the literal's first slot (`0`) instead of `raw` (`s`).
