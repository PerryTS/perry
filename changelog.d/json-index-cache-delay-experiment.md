Move the dynamic indexing cache load into the shape-carried Array-subclass branch so ordinary arrays and lazy JSON arrays need no unused cache pointer. Full semantic fallback still receives the static cache slot address. Runtime and GC sources are unchanged.

This experiment is not accepted for landing: six smaller changing-index controls improve 1.03–2.57% against R5, but 20m mixed fields remain 3.27% slower than main, 20m scan regresses 0.71% against main, and 20m random access regresses 1.19% against R5. All 770 timed checksums and CPU/RSS samples verify. Details and validation limitations: `benchmarks/json_performance/INDEX_CACHE_DELAY.md`.
