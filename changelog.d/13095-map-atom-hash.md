- **perf(runtime): Map and Set string keys that are atoms use their stored hash** (#13095).
A Map or Set index looked a string key up by hashing its bytes on every `set`, `get` and `has`. A property-atom key (a literal, a property name, a minted key) now uses the hash it was interned with, which is the same FNV-1a. Trimming a program literal that has nothing to trim now returns the literal (and its atom) instead of a copy, so keys normalized with `name.trim()`, like opentui's keymap command names, keep that hash. Witness: a Map keyed by trimmed literals uses 24% fewer instructions; opencode TUI typing -0.6%. Gap test: `test_gap_map_set_string_key_hash.ts`.
