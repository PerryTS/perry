Codegen: a relational or equality test over an integer product, sum or difference (`piece * color > 0`, `a + b < c`, `p * q === r`) whose leaves are int32 values (int32 locals, literals, I32 lanes, at-rest and int32 element reads) is one integer compare instead of `sitofp` / `fmul` / `fcmp`. The intervals choose the width: i32 when every value of the test stays inside int32, i64 otherwise; every operand of an operator stays inside ±2^53, and a root that may round (the product of two arbitrary int32 values) is taken only against a value strictly inside ±2^53, where the rounded order is the integers' order. A test absorbs the sign of a zero, so `0 * -5 === 0` needs no `-0`; value uses of a product keep the double. `PERRY_INT_PRODUCTS=0` restores the double lowering (a compile-cache input); `PERRY_ARRAY_BASE_DIAG=1` prints one `[perry intprod]` line per candidate test; check mode tests each leaf against its interval (`PERRY_FACTS_SABOTAGE=intprod` is the negative control).
