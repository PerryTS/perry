A for-of / for-await head pattern binds each element like the same pattern in a declaration: `for (const [a, b] of [iterator, set, generator, "str", ...])` iterates the element (and closes its iterator when the pattern stops early), a rest takes the remainder, an object pattern takes numeric keys (`{ 0: z }`), and a non-iterable element throws a TypeError. It indexed the element (`elem[0]`) before, so an iterator element bound `undefined`. A plain Array element with the default iterator keeps the indexed read. `PERRY_FOR_OF_PATTERN_PROTOCOL=0` restores the old binder.
