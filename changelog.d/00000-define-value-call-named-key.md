An `Object.defineProperty(o, "key", desc)` that lowering keeps as a dynamic call (because a computed-key define on the global object elsewhere in the program makes `Object` count as possibly replaced) now defines that String-constant key by name, as the direct call does, instead of writing any key of the receiver; a global define such as `navigator` no longer turns every global read unknown, and the program sites behind it stay proven. A key that is not a constant keeps the computed-key path.
