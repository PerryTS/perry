On `--target web`, `++`/`--` on a member now writes the updated value and returns the right one. `o.x++` and `this.n++` used to return the new value and leave the field unchanged. `++o.x` built a module that failed validation (`expected 0 elements on the stack for fallthru, found 2`). `a[i]++` evaluated its base and index twice, so `arr[i++]++` advanced `i` twice. Its postfix result could also come back as the receiver (`this.items[1]++` returned `this`). Base and key are now evaluated once, and prefix returns the updated value while postfix returns the old one (#14684).
