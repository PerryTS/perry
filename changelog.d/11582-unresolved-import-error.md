**A called import of an uninstalled package is a compile error, not a link error (#11576).** `import { nanoid } from "nanoid"; nanoid()` with no nanoid installed used to warn and then fail in the linker on the local binding name (`_nanoid`, `_uuidv4`). Perry now stops before codegen with `Cannot find package 'nanoid' imported from <file> (binding 'nanoid' …)` and an install hint, listing the other missing packages too. Narrow on purpose: bare package specifiers, importers outside node_modules, no CJS-wrapped requires, and only bindings that are called directly — so nothing that links today changes.
