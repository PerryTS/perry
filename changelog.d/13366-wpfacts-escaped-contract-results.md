Published functions that later reach unknown code also let that code retain their results. Per-unit facts now escape those results, including when publication came through a literal field, while preserving the result contract of known closed callers. A named function import read before its contract is published keeps its unknown value and tracks the owner function beside it, so handing it to unknown code reports escapes of its returned layouts to their owners.

A summary that only copies an unchanged parameter to its return now gives each caller its own argument back. This preserves function identity through helpers such as Struct.lambda without adding contexts, and prevents whole-program facts from merging unrelated callbacks. Spread calls and summaries with additional result sources retain their conservative transfer.
