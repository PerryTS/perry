Whole-program facts: a load of `flags`, `source` or a flag getter (`global`, `ignoreCase`, `multiline`, `dotAll`, `unicode`, `unicodeSets`, `sticky`, `hasIndices`) on a RegExp now holds the getter's declared result instead of an unknown value. The runtime declares the ten `RegExp.prototype` accessors where it defines them: `flags` reads the eight flag properties through [[Get]] and returns a String, `source` returns a String, and each flag getter returns a Boolean, or `undefined` when the receiver is `RegExp.prototype` itself (ECMA-262 22.2.6). The solve reads a declared getter on the realm holder of a builtin object's kind when the runtime's image lock makes that member final (`loads::bobj_declared_getter`; today this applies to the RegExp accessors only). Without the unknown results, the RegExp protocol of `match` / `replace` / `split` no longer puts an unknown value into a program, so `family_reach` can call families `never` for programs that use a regex. `PERRY_FACTS_DECLARED_GETTER_RESULTS=0` restores the previous model.
