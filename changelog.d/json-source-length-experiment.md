R11 experiment: reuse the source string's stored UTF-16 length for a large unescaped JSON string token when the surrounding bytes are ASCII and small relative to the token. A bounded tail check rejects malformed sequences that could consume the closing quote during length counting. Output still uses the existing JSON leaf allocator and copies its bytes; GC policy, caching and fallback semantics are unchanged. Correctness and performance qualification are pending; no release version bump.
