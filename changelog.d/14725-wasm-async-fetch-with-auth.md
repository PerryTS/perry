`--target web`: `fetchWithAuth` and `fetchPostWithAuth` inside an `async` function now send the request instead of evaluating to `undefined` (#14711 covers the synchronous path). The async-body JavaScript emitter calls the same `fetch_with_options` bridge the WASM arms use. It sends the auth header as `Authorization`, and for `fetchPostWithAuth` it sends POST with the body. The arguments are evaluated in source order.
