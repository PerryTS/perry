Class registration finds each declared prototype member's position once and carries it to the readers of that member, so the declared-method, kept-value and accessor lookups no longer search the declaration by name (and byte-compare names) again. Equal literal names of a declaration share one pointer in the emitter's string pool, which the runtime reads from a declaration flag to dedupe members without comparing text. The class member order ranks each name once instead of once per sort comparison, and the coloured-atom list is ordered by the program's own colour numbers instead of by name text.
