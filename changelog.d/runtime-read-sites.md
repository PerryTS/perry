Builtins can now read a fixed key through a runtime read site: the same
compact word and full cache an emitted `o.key` site holds, kept per agent and
answered by the same IC front, holder entry and slow entry. The first consumer
is the promise resolution `Get(resolution, "then")` for values the plain-object
probe cannot prove: awaiting or resolving with a class instance, a subclass
instance or a constructor-function instance now costs 3.9k-4.9k instructions
per step instead of 21k-29k.
