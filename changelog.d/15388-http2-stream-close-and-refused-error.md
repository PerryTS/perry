`http2`: a client stream emits `'close'` after its `'end'`, `'error'` or reset, as in Node, instead of never (#15376). A refused `http2.connect()` errors the session with the `Error` `net` gives for the same failure (`connect ECONNREFUSED 127.0.0.1:PORT`, with `.code`, `.errno`, `.syscall`, `.address`, `.port`) instead of the string `"ECONNREFUSED"`, and a request cancelled by it names that message (#15377).
