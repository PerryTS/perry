The memory-stability gate's forced old-page workload now runs on every platform, and its report checks the accounting that block-granular evacuation actually guarantees. The `test_old_page_defrag_target_gate_emits_trace` fixture minted its shape — whose keys arrays are shape-shared and never move — into the same old block as the parent it meant to evacuate, so the whole-block pass declined and moved nothing (a 2 MiB "fill the block" filler cannot isolate the parent where blocks are 1 MiB, as on macOS). The report asserted `old_page_moved_bytes <= old_page_selected_live_bytes`, but the pass moves every indexed occupant of the source block, unmarked ones and other pages' included; it now requires `old_page_moved_bytes >= old_page_selected_live_bytes` whenever the pass moved anything, and keeps `old_page_moved_bytes <= released_original_bytes`.
