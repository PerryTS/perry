Whole-program facts and codegen: a method call proven to be a field element read lowers as that read. The call is `r.m(…)` whose one target body is `m(…) { return this.f[p] ?? L; }`, with plain parameters and the call's argument count. The read must also neither throw nor run user code: the index argument is an integer Number, the field holds only program arrays, no index accessor is reachable on their prototype chain, and no element descriptor is defined on them. It reads with the method's own field and element facts, as an i32 index when the proven interval fits. Check mode runs the real call beside the read and reports a mismatch. `PERRY_FACTS_FIELD_READ_CALLS=0` turns it off; `PERRY_FACTS_SABOTAGE=fieldreadcall` is the negative control.
