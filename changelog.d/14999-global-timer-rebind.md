A bare `setTimeout(…)`, `setInterval`, `setImmediate`, `clearTimeout`, `clearInterval`, `clearImmediate` or `queueMicrotask(…)` call now calls the replacement when the program rebinds that global (`globalThis.setTimeout = wrapper`, a bare `setTimeout = wrapper`, `Object.defineProperty(globalThis, "setTimeout", …)`, `Object.assign(globalThis, { setTimeout })`, a write through `const g = globalThis`, or a store into the global object under a non-static key), as Node does. Before, the call bound the built-in timer directly and ignored the replacement. A program that never writes these bindings keeps the direct call. `typeof setTimeout` no longer folds to `"function"` when the binding may be rebound.
