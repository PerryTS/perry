A `--target wasip1` program can use perry-stdlib and the Node module crates: the wasip1 runtime archive is built with the stdlib, the http, undici, websocket and zlib crates and the TLS-consuming modules bundled in, and the link installs only the features the program selects. zlib on wasm32 uses a Rust implementation of the same C ABI (native keeps zlib-ng), so dictionary streams, including mid-stream `params()` switches, behave as they do natively. `--target wasi` is unchanged.
