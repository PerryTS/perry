The CommonJS wrapper no longer stores each module's factory as the ordinary property `module.__perry_cjs_factory`. The module record is now born with a runtime-declared layout (`CJS_MODULE_RECORD`: Node's keys, the `__perry_cjs_record` marker and one private entry) in a single `__perry_cjs_module_record(...)` call; the factory sits in the private entry, which no own-key reader lists and no script can name, so `Object.keys(module)`, `in` and `getOwnPropertyNames` do not see it. The entry module's main-module placeholder is born with the same layout and receives its factory through `__perry_set_cjs_factory`. The only reader is the reload that runs a loaded module again after `delete require.cache[...]`. JSON modules build the same record for their re-parse factory, so their `require.cache` entries carry Node's record keys too. Building the record in one call is also cheaper at startup than the folded literal was.

Retained function source that no execution can read is now dropped. The retained-source classification (`PERRY_SOURCE_NEED_REPORT`'s census) runs on every compile over the final HIR, before the object-cache key hashes it, and removes the text of every function, closure, class member and class it classifies as never a value or a value that reaches no string sink under the strict rule. A dropped function keeps its non-strict-ordinary bit: an info records it without a source range, and the copying registry gets an empty range carrying it. With the factory hidden, the outer text of every CommonJS module (the factory's whole-module text) is among what drops. `PERRY_RETAIN_ALL_SOURCE=1` keeps everything, for the census soundness check, which runs the program with all source present and checks every text read against the classification. The census now reports owners in decoded bytes over both retained-source pools and checks the pools' physical bytes against `.perry_src`.

Compile-package membership (`is_in_compile_package`) no longer tests every listed package against every ancestor of a resolved path: each ancestor asks the package set for the two names its position under `node_modules` can carry, and the compile-package-dir check looks the ancestors up the same way. With a wildcard `compilePackages` expansion (opencode: ~1800 packages) one resolution pass over all imports took 25 s; the retained-source classification, which resolves every module's imports once, now takes 3 s on opencode instead of 29 s.
