perry/ui on iOS and macOS, fixes found shipping a real app (Skelpo CMS Admin): `await fetch()` no longer hangs in UI apps (the macOS/iOS UI pump now settles the turnloop through the new `js_loop_settle_once`); iOS no longer asks for notification permission at launch, only on the first `notificationSend`/`notificationSchedule*`/`notificationRegisterRemote`; iOS `stackSetAlignment` translates the documented NSLayoutAttribute values to UIStackView alignments instead of crashing at launch; iOS `Image(url)` caches decoded images by URL (NSCache) and decodes them off the main thread, downscaled to 1400 px; iOS `alertWithButtons` gives "Cancel" the cancel style and Delete/Remove/Discard/Archive/Sign out/Suspend the destructive style; `TextArea` uses the system font with inner padding (macOS: no bezel, no Menlo; iOS: 16 pt); macOS `widgetMatchParentWidth` respects the parent stack's edge insets; positional `Image(url)` / `Image(url, alt)` lowers to the UI call instead of returning handle 1; and the stack-map assembler is given the code generator's default CPU (`apple-m1`) on Apple arm64 when no `--march` is set, so iOS device builds no longer fail with `instruction requires: rcpc`.
