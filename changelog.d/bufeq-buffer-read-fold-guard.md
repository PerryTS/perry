Inlined Buffer numeric reads (`buf.readUInt8(0)`, `buf.readInt32BE(0)` and the other `read*` accessors) now honour a patched `Buffer.prototype` however it was written: each inlined read first tests the Buffer.prototype bit that the runtime Buffer dispatch reads, and once the prototype was written (a computed key, `Object.getPrototypeOf(buf)[k]`, `eval` or `new Function` included) the call goes through the ordinary method dispatch and runs the patched function like node. The module-wide scan for literal `readX` property writes that used to switch the inlining off is removed.
