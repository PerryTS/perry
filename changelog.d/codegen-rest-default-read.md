Performance: `a[k] ?? <int32 literal>` over an Array stored at rest (I32 words) is lowered as an i32: the slot's word when the key is below the floor, else the literal where the accessor's read is `undefined`. Before, the hit path converted the word to a double, merged it with the cold read, tested the merged value for `undefined` and converted back for an int consumer. A board helper `at(sq) { return this.board[sq] ?? 0 }` now costs one unsigned compare and one load. `PERRY_REST_DEFAULT=0` restores the old lowering; `PERRY_REST_DIAG=1` shows the sites as `form=default`.
