Codegen: a loop's element reads of an array binding it never assigns use one descriptor. The array is validated lazily (heap band, an ordinary unforwarded array without element descriptors) and its handle is cached. A read whose index is an i32-exact non-negative Number below the live length, and whose element is own data, is then one raw load, at any index and not only the loop counter. Every other case takes the ordinary read. After that cold arm returns, every descriptor reloads its binding (a getter may have reassigned it). Every call that may run code or collect clears the cached validation. A loop is admitted only when its other enders are the back-edge poll, and while no other receiver fact or loop table is active that a cold arm's user code could stale. `PERRY_RECEIVER_COLD_ARM_REFRESH=0` turns it off; `PERRY_RECEIVER_COLD_ARM_SABOTAGE=reload|guard|handle` drops one recipe step (negative controls).
