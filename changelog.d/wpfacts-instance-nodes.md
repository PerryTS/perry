Fix: an Array literal that a function passes to a callee, and that the callee grows or shrinks through its parameter, no longer keeps a constant length. `function p(xs: number[]) { const other = [5, 6, 7]; for (const v of xs) { s += other.length; fill(other, 1); } return other.length; }` (with `fill` pushing onto its parameter) folded every `other.length` to 3. wpfacts solves a function that has an object parameter once per call site (a summary instance), each instance on its own copy of the body's nodes, and a literal such a body bears is one Array per instance when the body itself never reads or writes its elements: the instance's copy of the local holds that Array, while the shared node keeps the literal's template token, which no effect of a callee ever reaches. `bindings::facts_of` read a local's facts off the shared node alone, so the local kept the literal's birth state: `arr<f64,3,dense,fixed,im>`, `const_length = 3`, `immutable_array`, `const_elems = [5,6,7]`, and a local fed by its length (`const n = other.length`) kept the interval `[3,3]`. A binding's facts are now read off its shared node and every instance copy of it (`bindings::BindingNodes::of`, the one function that yields a binding's nodes): the representation (`Rep::Arr` with its element representation, floor, `dense`, `fixed`, `im`; `Record`; F64/I32), the primitive kinds, classes, `other`, the integer interval, int demand, −0 tolerance, `const_length`, `length_number`, `indexed_owner`, the held bodies, the class object and the literal-string fact of every local and every `this`; `immutable_array` and `const_elems` (`const_arrays`); the module constants (`const_numbers`); a typed signature's parameter representation and interval (`signatures`, which is the parameter local's own fact); the argument intervals of a call (`call_arg_ranges`) and the constant-length element reads (`element_reads`), whose operands are nodes of the same bodies. Growth by `push`, `unshift`, an inserting `splice` or a `length` store, shrinking by `pop`, `shift` or a removing `splice`, a recursive caller and two call sites with different instances are all covered by `tests/parity/language/array/test_array_instance_literal.ts`; a literal that only read-only callees see keeps its constant length and stays folded. Check mode (`PERRY_VERIFY_FACTS=1`) already reported the false claim ("array constant length", exit 86); `PERRY_FACTS_SABOTAGE=instlit` reads the shared node alone again and is the negative control (`scripts/test-verify-facts-s0.py`, arm `instance-literal-negative`). `PERRY_FACTS_INSTANCE_NODES=0` restores the old reading (a compile-cache input); the dump (`PERRY_FACTS_DUMP`) prints one `# inst_nodes` line per local whose instance copies change its facts, with the representation, constant length and interval of the shared node alone and of the binding.
