Whole-program facts publish `family_reach`: per runtime family (one install-hook group of the runtime: typed arrays and Buffer, the regex engine, JSON, `perf_hooks`, Temporal, ...), whether the program may ever create or observe a value of it. `never` is the only actionable value and nothing acts on it yet: no link, codegen or runtime decision reads the fact, and default binaries are byte-identical. A family is live when the solve is incomplete, when the program holds an unknown value or may run interpreted code (every family), when the solve resolves a load, store, call, construct or birth to one of the family's realm entries, when the program text names the family (a global, an intrinsic node, a module specifier, a member key), or when a live family requires it or an observed entry declares one of its entries born. The family list and the membership of realm entries are one table, `perry_runtime_manifest::families`, kept equal to the runtime install list by a test. `PERRY_FACTS_DUMP` prints one line per family, `# family_reach <family> live|never reason=<rule>:<what>`; `PERRY_FACTS_FAMILY_REACH=0` turns the fact off (not computed, no lines).
