**`main` compiles its test targets again after #13622.** That PR added `CompileOptions::namespace_self_import`, and the field is required in a struct literal, but the fixtures across `perry-codegen`'s and `perry`'s test targets name their fields explicitly instead of spreading `Default` — so `cargo check -p perry-codegen --tests` and `cargo check -p perry --tests` stopped compiling on `main` (42 sites). Each one now sets `namespace_self_import: false`, which is what every fixture means: the flag is false in every test path, exactly as a defaulted field would be, so there is no behaviour change. The regression was invisible to the checks #13622 ran (`cargo check -p perry --bins` and the gap harness do not build the test targets), which is why the repair is verified by exit code this time: both commands exit 0.
