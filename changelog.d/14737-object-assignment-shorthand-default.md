A shorthand property in an object assignment pattern applies its default: `({ o = 7 } = {})` assigns `7`, also inside nested patterns such as `[[q = 1], { r = 2 }] = [[], {}]`. As in the declaration form, the default runs only when the property reads `undefined` (a `NaN` keeps its value), and an anonymous function default is named after its target. Before, the default was dropped and `o` stayed `undefined`, natively and on `--target web` (#14732).
