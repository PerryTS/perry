A method call on `this` inside a constructor, a `super` method or accessor, and a read of a key that is not own yet (an accessor on the prototype chain may run) all run code that holds `this` before the constructor has assigned every key. Facts treated them as plain reads, so a key assigned after them was claimed set before anyone could observe the instance, and a declared field lost its initial `undefined`. `this.p === undefined` inside such a method then folded to false. They now close the constructor phase.
