node:http requests and responses keep their runtime layout's fixed slots when the program adds keys to them (`req[sym] = meta`, `res.write = ...`): every shape record states, when it is published, the runtime layout (`IncomingMessage` or `ServerResponse`) it descends from by key adds, so the payload cell and the request's header view are one field load instead of a key lookup. `res.setHeader` validates the value's bytes in place, checks the name token once, looks the lowercase name up on the stack and keeps the header byte count as it changes. A node:http fixture with Next-style key adds drops from 975k to 729k instructions per request (632.8k vs 642.7k without adds); nextjs-hello `/` and `/api/hello` drop by about 1.9% and 1.7%.
