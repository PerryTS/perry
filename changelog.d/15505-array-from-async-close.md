`Array.fromAsync` reads an array-like's `length` before `Construct(C, «len»)` and each element only on its own step, instead of cloning the source first. It closes the source iterator (`return()`) when the mapping function throws or rejects or a result define fails. It also stops awaiting values a real async iterator yields, rejects on a throwing `next()` or a non-object iterator result, and treats a number or boolean source as an empty array-like.
