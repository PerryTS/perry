Four correctness fixes. `delete` through a TDZ-checked binding no longer misbehaves; object spread (`{...o}`) re-checks the remaining keys after a getter ran, so a key a getter deleted is skipped (spec CopyDataProperties); a spread or rest of an object with exotic own properties (a `Date`) copies them; `Object.hasOwn`, `hasOwnProperty.call` and `propertyIsEnumerable.call` on a `Proxy` call its `getOwnPropertyDescriptor` trap (the trap body was previously compiled as unreachable and crashed).
