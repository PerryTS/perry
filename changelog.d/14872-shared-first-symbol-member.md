A class declared in a function that runs more than once keeps all of its prototype methods when it has an instance member keyed by a well-known or `Symbol.for` symbol (`*[Symbol.iterator]()`, `get [Symbol.toStringTag]()`); before, every member from that one onward was missing, so mongodb's `List` had no `push` or iterator and `MongoClient.close()` threw "value is not a function" (#11043).
