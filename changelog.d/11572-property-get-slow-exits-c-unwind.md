**The generic property-get slow exits are `extern "C-unwind"` (#11560).** `js_object_get_field_ic_nonptr` / `js_object_get_field_ic_slow` (79fb4463a) raise the nullish-receiver TypeError and can run throwing getters, but were plain `extern "C"`. Under `panic=unwind` (every debug runtime) rustc guards such frames with abort-on-unwind, so a caught `o.foo` on `undefined` aborted with "panic in a function that cannot unwind". Fixes the three `issue_5247_property_read_source_location` tests.
