Performance: the ToInt32 of an immutable local that holds only Numbers and `undefined` is computed once. A parameter or `const` used as a bitwise operand several times (`move & 127`, `(move >> 7) & 127`, `move & FLAG`, ...) range-tested and truncated its double at every use when whole-program facts could not prove it a Number alone (for example a for-of value of an Array whose index stores may leave holes). ToInt32 of such a value runs no user code, so it is now taken once where the local is initialized and each bitwise operand reads that i32. `PERRY_INT32_SHADOWS=0` restores the old lowering.
