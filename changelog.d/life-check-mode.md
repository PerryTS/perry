### Added
- `PERRY_VERIFY_FACTS=1` checks the life census's lifetime claims at run time: a `frame` local dies at the end of its scope, at each `break` / `continue` that leaves it and at each return (a throw edge leaves it unchecked), an argument birth whose callee fate is Dropped dies right after the call. A copied minor that reaches a dead object exits 86 with one JSON line naming the holder (walk phase, owning frame); a claim resting on a bet prints `PERRY_BET_FAILED` once per site and continues. `PERRY_VERIFY_FACTS_LIFE_EVERY` (compile time, default 4096) samples the exact check at death; `PERRY_FACTS_SABOTAGE=fate:<fn>#<i>` / `fatebet:<fn>#<i>` plant a wrong fate. Release builds emit nothing. The collector hooks live only in the instrumented runtime variant (`scripts/build_instr_runtime.sh`), which a `PERRY_VERIFY_FACTS=1` compile now links; the default archives carry neither the hooks nor the check, so a check build linked against them fails to link.
