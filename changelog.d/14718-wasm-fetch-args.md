`--target web`: a program that calls `fetchWithAuth` or `fetchPostWithAuth` now compiles to a valid WebAssembly module. Before this change, the page failed to boot with `i64.store[0] expected type i32` (#14711). The lowering stores each argument in its own bridge slot as soon as the argument is evaluated, in source order (url, auth header, body), instead of juggling those values through the operand stack and `temp_local`.
