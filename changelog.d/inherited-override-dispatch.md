A method's `this.m()` call resolves `m` through the receiver's prototype chain
when the receiver's class is one the method's module does not know. The
class-id tower that a `this.m()` site lowers to (when the guarded direct call
does not apply, e.g. a class with a computed field) sent every class id it had
no arm for to the base body, and its no-override form called the base body for
every receiver. A subclass declared in an importing module, or a class
expression, that inherited an intermediate class's override (or declared its
own) ran the base body instead, and an own-property override on an instance of
a tower class was skipped. The tower now probes the own property first, keeps
its direct arms for the class ids the module's table resolves, and sends any
other class id to the universal method site. opentui's `ScrollBoxRenderable`
(and every other `BoxRenderable` subclass) lost its background fill this way:
opencode's slash-command dropdown let the logo show through.
