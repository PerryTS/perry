- **Top-level declarations of a `.ts` entry no longer leak onto `globalThis` (#11591).** A plain entry file (no `import`/`export`) was treated as a *Script*, so `function URL(){}` became `globalThis.URL` and shadowed the builtin, and `typeof globalThis.foo` was `"function"` where Node says `"undefined"`. Node runs such a file as a module (CommonJS or ESM), whose declarations are module-scoped. Script `GlobalDeclarationInstantiation` (function reflection, top-level `var` mirroring, Annex B `undefined` pre-declarations) now applies only under the existing global-script opt-in `PERRY_GLOBAL_SCRIPT_THIS=1`, which the Test262 runner already sets. `perry-hir/src/lower/lower_module_fn.rs` empties `script_global_functions` / `annexb_global_undefined_names` outside that mode, so codegen emits nothing. Regression: `test-files/test_gap_11591_module_function_not_global.ts`, `issue_5579_script_global_function_reflection::plain_ts_entry_does_not_reflect_top_level_declarations`; the #5579/#5848/#8595 reflection tests now opt into script mode explicitly.
