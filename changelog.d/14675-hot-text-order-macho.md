Apple targets can take the runtime's default hot-text order too, opt-in: with `PERRY_HOT_TEXT_ORDER=on`, a macOS / iOS / tvOS / watchOS / visionOS link resolves the checked-in hot-text list against the Mach-O runtime archives (the hash-free keys without the leading `_`) and passes the exact symbol names to ld64 or ld64.lld as an `-order_file`, kept in the compile cache per archive identity. Unset or `off` keeps today's layout; the default stays off until the effect on 16 KiB pages is measured. Linux is unchanged.
