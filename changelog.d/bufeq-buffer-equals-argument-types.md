`Buffer.prototype.equals` and `Buffer.prototype.compare` now throw node's `TypeError [ERR_INVALID_ARG_TYPE]` for an argument that is not a `Buffer` or `Uint8Array` (a `Uint8ClampedArray`, another typed array, a `DataView` or an `ArrayBuffer` used to be accepted), and `Buffer.prototype.copy` rejects an `ArrayBuffer` target as node does while still accepting every `ArrayBufferView`.
