Performance: a read of a module-level `const` whose every value is one integer Number is now that Number, not a load of the binding's cell followed by number and range tests. `const EP = 1 << 17` used in `(move & EP) !== 0` compiles to a test against the immediate. The fact comes from the whole-program facts: bitwise operators over single int32 values, and a left shift by a constant count, now keep their exact interval (a shift used to be the whole int32 range), and a module `const` whose binding holds only the Number primitive with a one-value interval is exported as that constant. Only a `const` declared by a top-level statement qualifies; a read that can run before the declarator keeps its dead-zone check and still throws. `PERRY_FACTS_CONST_NUMBERS=0` restores the previous intervals and reads; `PERRY_VERIFY_FACTS=1` compares the binding's cell with the constant at every such read, and `PERRY_FACTS_SABOTAGE=constnum` is its negative control.
