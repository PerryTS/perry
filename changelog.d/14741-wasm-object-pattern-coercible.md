`--target web`: object destructuring binds from its source. `const { k } = v` and `for (const { k } of arr)` threw `Cannot read properties of undefined (reading 'k')`, because the wasm backend had no arm for the `requireObjectCoercible` check that opens every object pattern and replaced the source with `undefined`. The source now passes through, and a `null` or `undefined` source throws a TypeError as it does natively (#14733).
