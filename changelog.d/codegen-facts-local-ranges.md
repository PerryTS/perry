Performance: the whole-program interval of an int32 local reaches codegen's range proofs. wpfacts already proved such intervals (a `let` read from an int Array is in the Array's element interval; a typed body's I32 parameter is in its signature's interval) but exported only "this local is an int32", so an element key built from such locals (`table[(old + 6) * 128 + square]`) was computed in doubles and normalized by a runtime call, and an at-rest element site keyed by a signed int32 local converted the key to a double and back. Now the key is an i32 chain bounded by one unsigned compare. `PERRY_FACTS_LOCAL_RANGES=0` restores the old lowering. Check mode witnesses the interval at every store into such a `let` (signature parameters are witnessed at their call sites).
