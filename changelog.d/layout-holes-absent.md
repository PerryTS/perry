A layout key a descriptor declares optional (`LAYOUT_KEY_OPTIONAL` in its attribute byte) is absent while its slot holds the hole: `in`, `hasOwn`, `getOwnPropertyDescriptor`, every enumeration (`Object.keys`, for-in, `JSON.stringify`, `Object.assign`, spread, `Reflect.ownKeys`, `structuredClone`, `util.inspect`, `v8.serialize`) and every value read (which continues to the prototype) go through one view, `object/key_view.rs`. Whether a layout can have holes is a summary bit of its immutable key list, so layouts without optional keys keep their cost; caches decline layouts that have it. `child_process.spawnSync` results use it: a successful run's `error` slot stays a hole, as node omits the key.
