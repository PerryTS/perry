hir/transform: A label on a module-level loop no longer changes its lowering. Module-level `for`/`while`/`do…while` bodies lower like loops in a function body (the block is the loop body list, no lexical `if (true)` wrapper; `for` gets the same receiver hoist), a labelled module-level loop lowers through that same module path and only gains the label, and the `Math.imul` polyfill rewrite visits every statement kind (labelled loops, switch cases and try blocks kept the polyfill call).
