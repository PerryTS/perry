Runtime realm: a built-in function can declare, at the runtime's own definition of the function, what it does to its inputs (`#[realm(Array.prototype.push, effects = { reads(this); stores(rest(0) -> elems(this)); returns(prim(num)) })]`; six verbs: reads, coerce, calls, stores, returns, open). The compiler's realm table is now generated once, by perry-hir's build script, and carries the declarations typed (`RealmEntry.effects`); whole-program facts can read it, no solver rule uses it yet. `perry-gc-effects effects` checks every declaration against the runtime call graph (a body that reaches a JS entry or the write barrier must say so) and prints the census of all realm natives. First declarations: Array.prototype push, reverse, sort, filter. The compiled runtime and compiled programs are unchanged.
