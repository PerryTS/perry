An array destructuring with a rest element (`const [a, ...rest] = xs`) no longer counts as a write that may change an Array's `@@iterator`: its append defines a numeric index only. Before, one such statement anywhere in a program made every other array destructuring take the iterator-protocol path in the facts solve, so `for (const [k, v] of Object.entries(o)) globalThis[k] = v` stored under any key and the realm was handed to unknown code.
