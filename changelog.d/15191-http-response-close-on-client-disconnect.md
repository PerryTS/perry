`node:http` server: a client that disconnects mid-response now closes the response as Node does: `'aborted'`, the response's `'close'`, the socket's `'close'`, then the request's `'close'`. Later `res.write()` calls return `false` with `res.destroyed` true. The request stays usable after its response closed: `req.method`, `readableEnded`, `destroyed` and own properties work in the response's `'close'` and afterwards, and `req.readable`/`readableEnded`/`destroyed` no longer read `undefined` on a live request. This fixes `@hono/node-server` exiting with `TypeError: Invalid native property owner` on its first POST (#15172).
