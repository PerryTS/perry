Before, the static type alone chose the lowering: a typed-array subclass instance behind the annotation ran the built-in instead of its override, `null` / `undefined` returned a value (or crashed) instead of throwing TypeError, an ordinary object ran the built-in for `set` and `subarray`, and `concat` on a real typed array ran `Array.prototype.concat` (node: TypeError).
