**GC call effects now come from a generated, CI-checked table (RFC deferred collection, S1).** `classify_direct_callee` no longer uses the hand-kept allowlist. It reads `crates/perry-codegen/src/gc_effects/{linux-x86_64,macos-aarch64,windows-x86_64}.tsv` and takes the most conservative class of the three.

- **Generator.** The tables are generated by `scripts/gc_call_effects/callgraph.py` from a symbol-level call graph of the linked runtime/stdlib archives. Every seed, cut and exemption, each with its reason, is in `seeds.txt`. `why.py` prints the witness path to the tainting seed.
- **CI.** `gc-call-effects-linux` and `gc-call-effects` (macOS aarch64, Windows through `cargo xwin`) regenerate each table from freshly built archives and fail on any difference, with the witness path and the regenerated table as an artifact. `lint` runs a self-test that plants a `js_proxy_get` call in a leaf helper across ELF, Mach-O and COFF objects and requires the check to go red.
- **Runtime.** The #11523 non-collecting root-registry guard is now a distinct type, `NonCollectingRootRegistryGuard`. Its drop has no path to `flush_deferred_gc_request`, so the graph can prove its callers leaf.
- **`root_reload`.** Its `NON_COLLECTING` list must agree with the table.
- **S2 fast paths.** The four GC-leaf IC hits S2 (#11554) hand-listed (`js_object_get_field_ic_fast`, `js_class_field_{get,set}_ic_fast`, `js_put_value_set_packed_fast`) now come out of the generated table as `Leaf` on all three targets, and their `_fast_miss` / `_packed_miss` continuations as collecting. No cut was needed for the two edges S2's census had to cut: the `Arena as Drop` TLS destructor is a `teardown` rule in `seeds.txt`, and `typed_feedback::invalidate_representation_change` takes the registry through `NonCollectingRootRegistryGuard`.
- **Windows build.** `PERRY_AGENT_PTRS` is no longer `#[no_mangle]` on Windows: MSVC's thread-local shim takes the same symbol name, so every release build of `perry-runtime` for `x86_64-pc-windows-msvc` failed with "symbol already defined". Only ELF executables name the symbol.
- **Measured against main**, on benchmarks/suite plus the 60 largest gap tests: −7.1 % statepoints and −3.4 % `gc.relocate`.
