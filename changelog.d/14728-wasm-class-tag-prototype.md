`--target web`: a Perry object no longer carries its class name as an own `__class__` property; a class instance inherits it from one prototype per class, and an object literal is a plain object. An object literal passed as `fetch` headers no longer sends an extra `__class__: __AnonShape_<hash>` request header under Node, `Reflect.ownKeys`/`Object.getOwnPropertyNames` list only declared fields, and `console.log` of an instance built in an async body no longer prints `[__class__]` (#14726).
