Whole-program facts: a `console` method formats its arguments with the operations the runtime's formatter performs, not with any key. It calls a class's or an object's `[util.inspect.custom]` hook, `@@toPrimitive`, `valueOf`, `toString` and `toJSON`, reads every property (so getters run) and formats every value it shows the same way (nested properties, elements, Map and Set entries, what a hook returns); a spread hands it the elements. Functions handed to `console` no longer escape (the formatter prints them, it does not call them), and a hook on a nested value now runs, which the any-key touch missed. The three.js `error()` repro proves 6 of 6 sites (was 2), with no proven site gained or lost in tssrc, tscwork, fastify_inject, chess, chesst or d_zod4.
