A class born on a family now matches the layout word its objects carry. The
dispatch tower's `$pshape` recheck compared the static id of the class keys,
which no compiled object carries, so the proven clone never ran for a
family-born receiver; it now accepts the family word when the family holds the
birth layout. A checked field read admits a literal family (class id 0) by its
descriptor word, and the runtime fact check admits it the same way.
