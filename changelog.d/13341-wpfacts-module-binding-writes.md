Per-unit facts carry a constructor function across units: a `new` of another unit's function (an export, or a value a function unit writes into a module binding, such as a CommonJS record's `exports`) constructs its owner's `new f` layout, which the owner builds from the arguments every constructing unit passes and publishes with its prototype methods; a function that leaves undescribed is constructed by unknown code. Per unit is never stronger than the whole program on these layouts (fastify with factories not flattened: 29 stronger facts to 0 real).
