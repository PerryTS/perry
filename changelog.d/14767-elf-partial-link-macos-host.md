- **codegen: ELF codegen units merge with lld on a macOS host (#14767).** A Mac cross-compiling for Android or Linux handed ELF objects to Apple's `ld -r -keep_private_externs`, and every module split into codegen units failed with `ld: Missing -arch option`. The partial linker now follows the object format: `ld.lld` (the NDK's when configured, else PATH) for ELF, ld64 for Mach-O; `PERRY_LD` still overrides.
