The whole-program facts lost a value that came out of `Object.fromEntries` (an entry's key and value were not read from the entry array's elements) or out of `Map.groupBy` (its result was not modelled as a Map, so `get` returned nothing). A write through such a value, for example patching `Buffer.prototype.equals` with an object obtained from `Object.fromEntries([["p", Buffer.prototype]]).p`, was therefore not seen, and a call site could be compiled as if the patched built-in member were untouched, printing different output than Node. Likewise `Object.assign(Buffer.prototype, Object.fromEntries(...))` copied keys the facts could not name and was not counted as a write of the prototype. Both reads now hold what the program put in, such a copy is a write of every key of the target, and a patch through either makes the site use the ordinary method call.
