### Changed

- Per-unit whole-program facts (`perry-wpfacts`, the default since #13132) carry phase 03 of the closed-world work: class instances' definite fields take store effects, TS enums and nested literals are contracts, a rest parameter takes only the extra arguments, a returned literal's field functions are contract functions. A closed class's constructor fed instances of its own class (trees, linked lists) keeps the class's layout proof across units, so `node.left`-style reads compile to direct slot loads again (js-compiled 23-binary-trees: -17.8% instructions).
- A unit that hits the facts work bound no longer checks its contracts (it publishes none), and a use walking an argument marker's members counts as solve work, so the TypeScript-sized units that hit the bound stop sooner: facts-only tssrc -58% wall, tscwork -64% wall / -16% RSS vs main; facts unchanged.
- A unit holds another unit's module namespace (`import * as ns`) with only the keys its code names; one handed to code outside the unit (the receiver of `ns.k()` with an undescribed callee) makes only the keys whose values carry another unit's objects. On effect / schema-record the facts graph was 2x main (every `Effect.succeed(...)` call made the whole `Effect` namespace in its unit); it is now 1.10M nodes vs main's 1.15M, facts-only RSS -7% and compile wall within noise of main.
