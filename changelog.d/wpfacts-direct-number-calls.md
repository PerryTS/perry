Performance: the result of a direct call (`f(a)`, or a call of any other callee value) that whole-program facts prove a Number is a canonical double for its consumers, as a method call's result already was. `moves.push(encode(from, to))` into a Number array now takes the inline push (capacity test, store, length bump) instead of the guarded runtime push with its two runtime calls per element; the same proof removes the `ToNumber` leaf on arithmetic over such a call. Under `PERRY_VERIFY_FACTS=1` the call's result is checked to be a plain double (a false proof exits 86; negative control `PERRY_FACTS_SABOTAGE=numbercall`). `PERRY_FACTS_DUMP` lists the proven calls as `# number_call module= call=`. `PERRY_FACTS_DIRECT_NUMBER_CALLS=0` restores the old lowering.
