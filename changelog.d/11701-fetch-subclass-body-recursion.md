- **fix(runtime): `Response`/`Request` subclass body methods no longer resolve to `{}`** (#11700). Since #11682 the by-name dispatch tower walks a class instance's declaration prototype on every vtable miss, so `class X extends Response {}` reached the intrinsic no-op-backed `Response.prototype.text`. Calling that method re-dispatched `x.text()` by name (#3716's uncurry-this path) and recursed until the call-depth guard returned `{}`. The tower now skips an inherited no-op-backed builtin method that would re-dispatch under the same name, so the fetch-subclass body forward answers the call (`crates/perry-runtime/src/object/native_call_method/proto_dispatch.rs`, `is_self_redispatching_proto_method`). Gap test: `test_gap_11700_fetch_subclass_body_methods.ts`.
