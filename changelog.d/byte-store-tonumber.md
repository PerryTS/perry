A `Uint8Array` / `Buffer` element store converts its value with ToNumber before the store, as every other typed-array kind did: an object's `valueOf` / `toString` / `Symbol.toPrimitive` runs, a BigInt or a Symbol throws, a string is parsed as a number (`"0x10"` is 16), and a value past int32 wraps modulo 2^8 instead of saturating. The value converts before the bounds test and for an invalid index too; the view is rooted across a conversion that runs program code. `u.set(array)`, `u.with(i, v)` and `u.fill(v)` use the same conversion, and a BigInt view converts an out-of-range value (a Number throws). Codegen keeps the inline byte store only for a value proven an int32 or a canonical Number; `PERRY_BYTE_STORE_TONUMBER=0` restores the old codegen.
