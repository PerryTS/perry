Building `%Object.prototype%` on its first use from a program operation (`Object.getPrototypeOf`, `util.inherits`, `__proto__`, a function's `.prototype`) no longer seals it as already modified when the program also names one of its members: the build runs as the runtime's own definition, so `Pristine` holds for every builtin family and checked builtin calls such as `s.charCodeAt(i)` keep their direct body instead of the generic `Call(Get(…))` path for the rest of the process (#10504).
