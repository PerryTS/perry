Web Streams state now sits behind one access layer (`streams/state.rs`): typed refs and per-record accessors, with no other module naming a registry. The 13 side maps (tee links and flags, transform bookkeeping, parked BYOB reads, expando properties) are fields of the stream records they belonged to, and `pipeTo` locks its source and destination with real reader and writer records instead of lock ids. Behavior, values and the ABI are unchanged; this is the first step of turning Web Streams into ordinary GC objects.
