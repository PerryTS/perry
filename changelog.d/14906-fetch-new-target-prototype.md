`Reflect.construct(Headers|Request|Response|Blob|File, args, newTarget)` gives an instance whose prototype is `newTarget.prototype`, as in Node, instead of the bare Fetch value with the builtin's own prototype; the instance keeps its native state, so `Headers.prototype.get.call(instance, name)` and the other prototype members still work on it. `class X extends File` instances now inherit `X.prototype`. `Blob.prototype` gains the `size`/`type` getters and `File.prototype` the `name`/`lastModified` getters, and `File` now inherits from `Blob`, so a `class X extends Blob` instance reads `size` (#12629).
