Add `Link(text, href)`, `routerNavigate(path)`, `routerOnChange(callback)` and `routerCurrentPath()` to `perry/ui`. On the web target a `Link` is an `<a href>` whose same-origin clicks navigate without a reload, and the router keeps the route in the browser's history, so a page has deep links, a working back button and shareable URLs. Native backends show a `Link` as its text, ignore navigation and return `undefined` from `routerCurrentPath`.
