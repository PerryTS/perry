Add `Link(text, href)`, `routerNavigate(path)`, `routerOnChange(callback)` and `routerCurrentPath()` to `perry/ui`. On the web target a `Link` is an `<a href>` whose same-origin clicks navigate without a reload, and the router keeps the route in the browser's history, so a page has deep links, a working back button and shareable URLs. A `javascript:` `href` is ignored on every target. Native backends have no route: `routerNavigate` and `routerOnChange` do nothing, `routerCurrentPath()` returns `""` (except on HarmonyOS, where its value must not be used), and a `Link` opens an `http`, `https`, `mailto` or `tel` URL (on tvOS, watchOS and HarmonyOS it is only its text). `openURL` from `perry/system` opens URLs again on iOS, tvOS and visionOS builds linked against a current SDK.
