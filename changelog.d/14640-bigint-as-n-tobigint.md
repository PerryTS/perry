`BigInt.asIntN` / `BigInt.asUintN` answer node's value in every program: their argument is converted by a ToBigInt of the runtime core (`bigint_coerce`), not through the typed-array group's slot, whose empty arm made `BigInt.asIntN(8, 255n)` print `0n` in a program that links no typed arrays. Only a typed array as the argument still takes the group's arm (its patched own `valueOf` / `toString`). `BigInt.asIntN` / `asUintN` are no longer members of the typed-array family.
