UUID v4/v7 generation moved out of its standalone `perry-uuid` crate into `perry-stdlib`'s crypto module, next to its single consumer (`crypto.randomUUID` / `crypto.randomUUIDv7`). The `getrandom` entropy dependency stays behind the `crypto` feature exactly as the old crate's `v4`/`v7` features kept it optional, so a stdlib built with no features still pulls no entropy dependency.
