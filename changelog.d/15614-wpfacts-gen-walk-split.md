Constraint generation's walker `crates/perry-wpfacts/src/gen/walk.rs` is split into `gen/walk/layout.rs`, `gen/walk/body.rs`, `gen/walk/class.rs` and `gen/walk/stmt.rs` by responsibility (template birth layouts and the class chain, function bodies and parameters, classes and store sites, statements). Code is moved, not changed; provenance edge locations (`edge@<file>:<line>`) recorded by the moved code now name the new files, for example `gen/walk/stmt.rs` for the return edge.
