`new URL` parses its input once with the url crate and keeps the href plus the component boundaries; getters slice the href, and `searchParams` is made on first read. A `new URL` of an absolute URL runs 8.5k instructions instead of 20.1k, a relative one 8.5k instead of 20.3k; the Next.js `/` route runs 1.1 % and `/api/hello` 1.9 % fewer instructions per request. An undefined base counts as an omitted base, a URL without authority has an empty host, and `Invalid URL` is a `TypeError` with own `code`, `input` and `base`, as in node. The url crate is vendored (`third_party/url`, 2.5.9) with the current WHATWG steps for `file:` paths, Windows drive letters against a `file:` base, `///host` against a special base and spaces before `?`/`#` in opaque paths, so these URLs now serialize as in node.
