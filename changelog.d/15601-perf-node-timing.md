- **`performance.nodeTiming`.** `performance.nodeTiming` read `undefined`; it is an accessor on `Performance.prototype` again, returning the PerformanceNodeTiming entry, and an entry read before the event loop starts reports the loop's real `loopStart`. `performance.eventLoopUtilization()` and `performance.toJSON()` no longer abort in a program that uses the global `performance` without importing `node:perf_hooks`.
