Performance: a loop over a local Array holds `a.length` across the calls in its body when the whole-program facts prove that nothing which runs during the loop can change it. `for (const x of f())` and `for (let i = 0; i < a.length; i++)` used to read the length, test the receiver and bound the index at every step once the body held a call, because the call might push onto `a`. wpfacts now exports `BindingFacts::stable_length` (module `held_lengths`) for a local `a` of a plain function `H` when every Array `a` may hold (a) lives in frames only: every node that holds it is a local, parameter, temporary or result of a plain function that no other function references (no field, element, closure cell, imported binding, `arguments` object, generator or async frame holds it), (b) is handed to no call in `H` (no argument, no receiver of a call that binds a function), and (c) has no length event in `H`. The solve records each event that can change an Array's length or move its elements (an element or `length` store, `push`, `pop`, `shift`, `unshift`, `splice`, a computed method name, `Object.assign`, `defineProperty` of an index, a declared native's element store) with the function it is in; an event the solve cannot place ends the fact for that Array. An Array that only frames hold and that `H` hands to nobody can be reached by no activation below `H`, so its length is the same throughout `H`'s activation, whatever those activations do to other Arrays of the same birth site (recursion included). Codegen (`expr::held_len`, `stmt::held_len`) then lowers the loop as the hoisted loop: the length is read once, the counter is compared with it as an `i32`, and `a[k]` at the loop's counter has no bound test; when every such Array also has a defined length (`stable_front`) the slot is `h + 24 + 8k` with no capacity or size load. Only the length (a scalar) is held: the Array's address is read from its root slot at every read, so a collection that moves the Array in a callee needs no re-derivation. Chess: search −X.XX%, perft −X.XX%, legal −X.XX% instructions. Check mode (`PERRY_VERIFY_FACTS=1`) compares the held length with the live one at every read of it and tests each bounded read against the live length (exit 86, "held length"); `PERRY_FACTS_SABOTAGE=heldlen` is the negative control. `PERRY_FACTS_HELD_LENGTHS=0` turns the fact and the loop off (a compile-cache input); the dump (`PERRY_FACTS_DUMP`) prints one `# held_len` line per Array local with its verdict or the rule that refused it, and `PERRY_ARRAY_BASE_DIAG=1` prints one `[perry held len]` line per loop.
