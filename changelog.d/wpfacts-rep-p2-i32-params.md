A parameter that whole-program facts give the I32 representation takes the canonical-i32 slot at function entry, and a `let` they give I32 takes it on that proof alone, so their bodies compute in i32. A method call whose every callee returns only Numbers is a Number by the facts (a canonical double), so its consumers skip the INT32 tag test (representation RFC §10.4, phase P2, first slice). Under `PERRY_VERIFY_FACTS=1` such a call's result is checked to be a plain double (a false proof exits 86; negative control `PERRY_FACTS_SABOTAGE=numbercall`). The calling convention is unchanged. `PERRY_WP_REP_P2=0` keeps parameters in their double slots and call results unproven.
