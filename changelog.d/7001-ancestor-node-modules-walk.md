fix(resolve): consult every ancestor `node_modules` directory when resolving a bare specifier, matching Node's algorithm. The walk previously stopped at the first `node_modules` found — under pnpm a package's own `node_modules` holds only `.bin`, so every transitive dependency of a compiled package (living in the `.pnpm/<pkg>@<v>/node_modules` sibling) was unresolvable and its call sites linked as undefined raw symbols.
