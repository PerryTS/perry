Keyed adds of a table object whose layout is empty append in place, and every overflow table now carries its hash index at twice its capacity, so a lookup no longer has a linear path. Observable behavior is unchanged: key order, property attributes, deletes, spreads and enumeration give the same results. Dynamic-key reads, writes, spreads and object builds execute fewer instructions (dyn read -5, dyn write -14, dict build -2900 per op in the micro matrix), and the tssrc self-compile runs about 0.6% fewer instructions.
