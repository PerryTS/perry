`map`, `filter`, `flat` and `flatMap` on an instance of a class that extends `Array` return an instance of that class (or of the species it names), as `slice`, `splice` and `concat` do; `flat` and `flatMap` honour a species named through `constructor[Symbol.species]` on a plain Array (an `Object` species, a typed array, a frozen Array and a non-constructor behave as in node). `flat("2")` converts its depth argument.
