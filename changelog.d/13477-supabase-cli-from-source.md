The Supabase CLI (`supabase/cli`, `apps/cli/src/main.ts`, a pnpm workspace with a global virtual store) compiles from its TypeScript source to a native binary whose `--version` and `--help` match the Node bundle byte for byte.

- **pnpm isolated stores and Node-API addons.** A prebuilt `.node` for another platform is left to fail at runtime, as napi-rs loaders expect under Node, instead of failing the compile. A platform payload is approved through the allowlisted wrapper copy the walk entered. The `compilePackages` wildcard enumerates `node_modules/.pnpm`.
- **Static `with { type: "text" }`** reads any file as a text module, as Bun's text loader does.
- **Named imports of CommonJS modules with opaque exports** (UMD `factory(...)` and similar) bind the property from `module.exports`, as Bun and bundlers do; modules whose exports are fully visible keep the static error.
- **Codegen:** long image-literal key names are digest-named like the record they point to; the native reader parses inline alias-scope metadata.
- **Resolve:** a package is compiled from its TypeScript sources only when they are self-contained.
- **Runtime and HIR:** an inherited getter of a callable class instance runs on the right receiver, `instanceof` walks the function's prototype chain, and arrows passed to `super(...)` read the bound `this`.
- **Per-unit facts reach their fixpoint** on the CLI's 64,283 units (round 11, about 7 minutes), with no cycle rule. Babel's `fe` (oxfmt's bundle), a recursive arrow that reads its own contract, published a result transfer and an escape in turn: replaying the transfer through a key loaded the parameter into a node outside the stand-in's run, so the caller's own argument came back as another call's value. Those nodes now belong to the run of the node they feed. A no-fixpoint report names, at round 64, 128, 256 and so on, the units each round solved and the contract fields they changed. A ⊤ function result has one spelling, and the end-of-round shared join takes only the units solved that round.
