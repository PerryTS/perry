`this.#x` reads and writes of a class whose private fields live in its class-family layout stay on the compiled slot access: the site learns the field's slot even though the layout lists the element as optional, and a hit tests the slot for the hole, so an access before the field's definition still throws `TypeError` (#10501, #11791). On the issue's benchmark `private_field_rw` goes from 163× Node to 5.9×.
