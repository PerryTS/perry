Enable generated TypeScript `Component.handleHttp` bindings for the pinned WASI HTTP 0.3.0 handler. Transfer accepted requests to the owning agent's async call driver, retaining the HTTP owner and its original public Promise across suspension and moving GC. Resume under fresh callback frames and the captured async context. Explicit HTTP errors preserve reusable components; closing the server cancels even a handler waiting on an unresolved import. This extends the native component boundary to ABI 8, requiring matching compiler, runtime and optional engine archives. Generic application future/stream bindings and async guest adapters remain separate work.
