Whole-program facts: a guard narrows a local by presence. Code that a truthy test of the local selects (`x && …`, `x ? … : …`, `if (x)`, `!x || …`, an early `if (!x) return`), or that `x != null` or `x !== undefined` selects, reads the local's values without `null`/`undefined` (only `undefined` for the strict test). This is the same predicate the guards' interval clips use, so `&&`, `||`, `?:`, `if`, `while`, predicates and early exits narrow alike. A closure's guard narrows a `const` the closure captures. A read of an array from a function that may fall off its end, such as `typeNodes && typeNodes.length`, is an own Array length again. `PERRY_FACTS_GUARD_PRESENCE=0` turns this off.
