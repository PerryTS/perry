`Buffer.prototype.readUInt8`/`readInt16LE`/`readFloatBE`/`readDoubleLE`, the other fixed-width readers, `readIntLE`/`readUIntBE` and `readBigInt64LE`/`readBigUInt64BE` check the offset as Node does: a non-number offset (`"1"`, `null`, `{ valueOf }`, `1n`) throws `ERR_INVALID_ARG_TYPE` instead of being coerced, a fractional or `NaN` offset throws `ERR_OUT_OF_RANGE` `It must be an integer`, an offset the bytes do not fit at throws `ERR_OUT_OF_RANGE` `It must be >= 0 and <= <length - size>`, and a buffer too short for the read throws `ERR_BUFFER_OUT_OF_BOUNDS`. `readIntLE` and its siblings reject a missing offset before checking `byteLength`.
