Whole-program facts: a property the program writes on a built-in function value is an ordinary field of that value. Program reads and the runtime's implicit reads, including conversion, JSON, iteration and accessors, see the stored value without exposing it merely at the store. Declared members still contribute the realm's values; constructors' declared runtime-read statics keep their existing conservative treatment, and handing a function value to unknown code still exposes its stored fields.
