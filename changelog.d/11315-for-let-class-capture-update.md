- **fix(hir): a class captured inside `for (let i …)` no longer sees the loop's post-increment value (#11250).** The class-capture refresh passes (`insert_class_capture_refresh_after_assignments` / `…_inside_expressions` in `perry-hir/src/lower/expr_function.rs`) treated the loop head's own update (`i++`, `i = i + 1`) as an ordinary assignment and re-snapshotted the class evaluated in the previous iteration, so the last class observed `3` (`0,1,3`; `1,2,3` for the `i = i + 1` form). A lexical head binding is per-iteration, so the head's writes are now excluded from those refreshes. In-body writes still refresh, and `var` heads (hoisted out of `For::init`) keep their single shared binding. Test: `test-files/test_gap_11250_for_let_class_capture_update.ts`.
