- **Two more built-in patch shapes are honoured by direct calls (#10848).** (1) A replacement written through a local bound to the namespace (`const M: any = Math; M.min = f`, `const C = console; C.info = f`, `Object.assign(C, {…})`) was invisible to the whole-program pre-scan, so `Math.min(…)` kept running the intrinsic; `patched_builtins::scan_module` now collects namespace aliases alongside the prototype aliases. (2) `Promise.resolve/reject/all/…` were lowered as a dynamic call in HIR, but codegen's `try_lower_promise_static_call` recognised the `GlobalGet(0).Promise` receiver and bound the intrinsic again; the patched-call receiver is now read through the real global object (`Expr::GlobalThisExpr`), which no intrinsic arm matches.
