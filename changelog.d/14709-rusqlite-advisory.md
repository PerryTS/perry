Dependencies: `rusqlite` 0.39 → 0.41 (`libsqlite3-sys` 0.37.0 → 0.39.1, bundled SQLite 3.53.x → 3.54.1) in `perry-stdlib` and `perry-ext-better-sqlite3`, for RUSTSEC-2026-0459 / CVE-2026-119375: SQLite before 3.54.0 could return uninitialized page-cache memory when a database was opened with a sibling `-wal` file of a different page size. Fixes the `security-audit` job (`cargo audit`) on `main`. No behaviour change in `node:sqlite`, `bun:sqlite` or `better-sqlite3`; `Statement::column_names()` / `columns()` / `columns_with_metadata()` now return iterators, so their call sites drop `.iter()` / `.into_iter()`.
