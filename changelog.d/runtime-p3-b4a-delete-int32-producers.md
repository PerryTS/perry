Cleanup: nothing in the runtime can build an INT32-tagged Number anymore. `JSValue::int32` is gone, its test uses now build plain doubles, and the realm schema no longer labels the constructor identity capture as a Number. A bound method of a class prototype (an evaluation's by-name method value) now carries the prototype object as its receiver, not the internal `0x7FFE` prototype word, so that word never reaches a JS operation. The decoders of that word in JS-operation paths (property descriptors, `defineProperty`, `hasOwn`, `delete`, symbol reads, proxies, weak collections, `instanceof` and others) are deleted. The word stays as a method's internal home, read only by `super` lookup (P3 B4a).
