A literal `require("pkg")` of a compiled CommonJS module inside an ES-module-shaped file (one the CommonJS wrapper does not rewrite) is now the same compile-time edge the wrapper writes: the target initializes on the first call and the call returns its exports. Before, the call stayed a runtime-loader lookup while the program was marked CommonJS-closed, so nothing was published for the loader and the require threw MODULE_NOT_FOUND. The program stays closed; only a computed `require(name)` opens it.
