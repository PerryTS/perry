Performance: a local bound once to an array literal and used only as a push receiver, through `.length`, through an index read, or as the operand of `return` is an owned array. No other code can hold it while the function runs, so nothing can freeze it, give it an own property or a custom prototype, or leave its head forwarded. Its inline `push` therefore skips the forwarding chase, the Array type test and the named-layout read, and keeps only the `_reserved` admission mask. A local is not owned if any other body mentions it: a closure, a method, a parameter default, a class field initializer or a global initializer. Pushing numbers into a fresh local array, in instructions per outer iteration, with Node in parentheses: 5 pushes, 522 to 481 (532); 16 pushes, 1120 to 978 (957); 40 pushes, 2840 to 2485 (1888); 200 pushes, 12741 to 10917 (10070). `PERRY_OWNED_PUSH_ARRAYS=0` turns it off.
