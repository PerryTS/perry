codegen: the latch of a labelled loop carries an `!llvm.loop` loop ID that names its region (`!{!"perry.region", !"<region id>"}`); the original copy of a byte-view-versioned loop also lists `!{!"perry.byte_view.fallback"}`, and its admission branch carries `!perry.byte_view.version`. The compiler-output proofs find a named region in optimized IR by that loop ID (it survives rotation, unrolling and vectorization) instead of by block labels, and count buffer slow paths of the original copy apart only where the marked admission guards it.
