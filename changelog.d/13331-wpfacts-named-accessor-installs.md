wpfacts: `Object.defineProperties(o, map)` with a literal map (inline or in a constant binding) installs one named accessor or value per key of the map instead of an accessor under a computed key; only a map with a computed key, a key added after birth or an unknown value still answers "any key". `Object.defineProperty(o, K, d)` and class accessors `get [K]()` with a constant `K` are named the same way. A named definition on a prototype is a key of the chain that is no instance slot (as a class getter), not E5 HARD on the prototype.
