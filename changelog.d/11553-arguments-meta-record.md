Move `arguments`-object metadata off the address-keyed `ARGUMENTS_OBJECTS` table and onto the object's own `ObjectMeta` record (#11506). Every materialized `arguments` object used to cost a thread-local hash insert, a rekey whenever the object moved, and a dead-owner prune on every collection. Now it is one NaN-boxed word, `ObjectMeta::arguments`: `TAG_TRUE` for an unmapped object with the restricted `callee`, `TAG_FALSE` for a sloppy object with no parameter alias, or a `GC_TYPE_ARRAY` holding a sloppy mapped object's parameter box addresses. The array is a traced child edge like `expando`, so it moves and dies with its owner. The table, its rekey, its `DEAD_KEY_PRUNES` entry and its `gc_rekeyed_key_tables.json` verdict are gone. `scan_arguments_object_roots_mut` now only roots the shared per-arity key lists.

A mapped object is born with its alias room: codegen calls the new `js_arguments_object_alloc_mapped(raw_args, callee, mapped_count)`, and the `js_arguments_object_map_index` calls after it only store into that room. They still cannot allocate, because the prologue holds the object in a bare register across them. The room is `min(mapped_count, argument count)`, which also fixes a spec divergence. CreateMappedArgumentsObject maps only the indices a call actually passed, but the table mapped every parameter. So for `f(a, b)` called as `f(1)`, `arguments[1] = 5` read back `b`, and a later `b = 7` showed through `arguments[1]`. Both now match Node.

`arguments_object_get_index`/`set_index`, `arguments_object_to_vec`, `arguments_object_to_array` and `arguments_object_after_define` now root the object across the key interning, descriptor reads and result growth that follow the lookup. The new lookup dereferences the receiver, where the old one only hashed its address.

Microbenchmark: 10M calls of a function whose `arguments` escapes into a helper, median of interleaved runs, Linux x86_64. The sloppy mapped path went from 33.5 s to 28.0 s (−16%, 7 runs); the strict unmapped path from 29.4 s to 27.0 s (−8%, 5 runs). Checksums are identical.

Validation: new `test_gap_11506_arguments_meta_sloppy.cts` and every `*argument*` gap test match Node 26.5.1 under default settings and under `PERRY_GC_FORCE_EVACUATE=1 PERRY_GC_VERIFY_EVACUATION=1`, except `test_issue_3580_arguments_object_semantics`, which is a known failure identical on `main`. With `PERRY_GC_SCHEDULE_SEED=1 PERRY_GC_SCHEDULE_RATE=1` added, every fixture ran at least 6 copying minors with evacuation verified. New runtime tests: `arguments_mapping_survives_a_moving_collection`, `only_passed_arguments_are_mapped`, `only_the_state_word_identifies_an_arguments_object`. `ObjectMeta` grows by one word (144 → 152 bytes).
