R10 experiment, rejected for landing: forcing three bounded JSON.stringify writers to remain inline restores ordinary small-record performance and retains the roughly 9.5× zero-spacing gain, but the full matrix and longer recheck expose regressions. Object parsing is 0.78% slower, 8 MiB array stringify 0.80% slower, and numeric-array stringify 0.70% slower in the recheck; all 11 paired repetitions are slower. No release version bump. See benchmarks/json_performance/INERT_SPACER_INLINE_R10.md for all measurements, validation and known baseline limitations.
