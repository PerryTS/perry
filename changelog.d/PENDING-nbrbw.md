A hoisted `var` read before its first write now reads `undefined` again when the local would otherwise be an int32 local (#12658): `function f(k){ var r = 0; if (k) { r = n + 1; } var n = 5; n = n * 2; return r + n; }` printed `undefined` for `f(1)` instead of `NaN`. The integer-local proof exempts the hoisted `undefined` seed from judgment, which is sound only when no read can see the seed; it now drops every candidate that some read may reach before a write (and, through its dependency edges, the locals computed from it). That check is the Closed World 5d `typed_locals` definite-assignment walk, moved into `collectors/read_before_write.rs` as the one predicate both facts ask. The Number-by-construction facts already rejected the seed (`undefined` is not a Number write; the undefined-seed flow checks every read) and are unchanged.
