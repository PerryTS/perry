Fix a miscompile of exported functions whose module calls them once (zod 4.4.3: `undefined is not iterable at generateFastpass`). Per-unit facts flattened such a function into its module scope as if it ran once, and a call through its parameter was compiled as a direct call of that module's own argument for every caller. Only closed functions (decision 13: not exported, stored, passed or published under any name) are flattened now; the CommonJS factory only when its module records are its only other references. A flattened copy whose emitted body is still reachable is an internal compiler error.
