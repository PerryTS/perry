perf(runtime): allocate the per-image dense parent table zeroed, and stop double-publishing in-window parent edges into `CLASS_REGISTRY` (#11502).

`parent_dense` (65,536 `AtomicU32`, 256 KiB per image) was built with `(0..N).map(|_| AtomicU32::new(0)).collect()`, which writes every slot and so dirties all 64 pages the first time any class gets a parent. It (and the 16 KiB anon-shape fast table, which had the same pattern) now comes from `Box::<[AtomicU32]>::new_zeroed_slice`, i.e. the allocator's zeroed path, so only the pages holding a registered child become resident. Measured on Linux x86_64 with mimalloc's THP advice off (`MIMALLOC_ALLOW_THP=0`, the 4 KiB-page case): a program with one `extends` went from 1824 to 1757 minor faults (median of 60), the same as a program with no `extends` (1758), and its median peak RSS from 17,190 to 16,630 KiB. With mimalloc's default `MADV_HUGEPAGE` on its arena, the table shares a 2 MiB huge page that is already resident, so the RSS saving there is nil either way.

`register_class` also inserted every edge into the `CLASS_REGISTRY` hash map under its write lock, even though readers of in-window child ids answer from the dense table and never consult the map. An in-window edge is now stored only in the dense table (`class_meta_registry::publish_parent_edge`); the map holds only out-of-window children and the never-produced unrepresentable `u32::MAX` parent. Three readers walked the map directly: the `extends Error`, `extends DataView` and `extends <TypedArray>` probes. They now walk through `get_parent_class_id` via a shared `any_registered_ancestor`. The typed-array probe's cycle bound now counts dense edges too (`parent_edge_count_bound`). `CLASS_REGISTRY` is private to `class_meta_registry`, so no new reader can bypass the dense table.

Tests (`object::class_meta_registry::dense_parent_tests`): in-window edges never reach the map (including after a re-parent); out-of-window edges do; the three builtin-subclass probes see a grandchild through dense-only edges (a 40-level typed-array chain included); and the unbounded ancestor walk terminates on a cycle.
