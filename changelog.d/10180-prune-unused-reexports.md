Perry now postpones unused named and wildcard re-exports during module collection when package sideEffects declarations prove their static dependency trees safe to omit. Pure import/export-list barrels are normalized to equivalent re-exports. Export demand grows to a fixed point across later importers and barrel chains; imports used by module code, dynamic-import namespaces, live bindings, and effectful or uncertain dependencies remain available. The compile summary reports omitted modules. Set PERRY_NO_REEXPORT_PRUNE=1 for an unpruned comparison, or PERRY_COLLECT_ONLY=1 to write the collection audit without generating code.
