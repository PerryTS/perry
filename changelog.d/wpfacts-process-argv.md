Whole-program facts: `process.argv` is one array of strings the runtime makes before the program runs. A read of `argv` from `process` (by name or by a computed key) denotes it, its elements are strings, and what the program pushes or stores there, or a `process` or global object handed to unknown code, joins it; so a string read from `process.argv` is a string receiver instead of unknown code (the chess test program proves 622 of 647 sites, was 620: `chess.ts:477` trim and `main.ts:35` length), with no proven site lost in chesst, fastify_inject, d_zod4 or tssrc.
