Runtime: throws in the runtime go through four typed functions, by where the value came from: `throw_core` (an error the runtime built, `CoreError`, made only by the error constructors), `rethrow_caught` (a value a catching funnel took, `Caught`), `throw_program_value` (a value the program handed over) and `throw_open`; `js_throw` stays the entry of compiled code. This change adds the API and converts one group of sites per kind; the rest follow. The errors `Buffer.alloc`, `Buffer.concat`, `buf.swap16/32/64`, the buffer read/compare range checks and `new tty.ReadStream(fd)` throw for a bad size, argument, range or fd are now real `RangeError`/`TypeError` objects: `e.stack` is a string and `Object.keys(e)` is `["code"]`, as in Node (they were plain objects with own `name`, `code` and `message`).
