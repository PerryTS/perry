Whole-program facts: the counted walk HIR lowers a `for…of` over an ordinary array to (`for (let k = 0; k < a.length; k++) { const x = a[k]; … }`, from #14224) binds its element to what the iteration of the array yields, as the IteratorRecord loop's element is. The read is below the length, so it no longer adds the past-the-end `undefined` of an arbitrary index read, and a string method on the element (`for (const s of ys) s.trimEnd()`) is native again.
