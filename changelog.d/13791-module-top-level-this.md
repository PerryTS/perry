- **Module top-level `this` is `undefined` (#13558).** A module's `[[ThisValue]]` starts as `undefined` (ECMA-262 §16.2.1.6.4), but Perry lowered every top-level `this` to the CommonJS `module.exports` stand-in, so `console.log(this === undefined)` in a `main.mjs` printed `false` where Node prints `true` (test262 `language/module-code/eval-this.js`). Lowering now consults the module goal it already derived for strictness — ESM format/package context (`.mjs`, `.mts`, nearest `package.json` `"type": "module"`) or in-source `import`/`export` declarations — and emits `undefined` for that top level, including through arrow functions and a folded `eval('this')`. A CommonJS entry keeps the `module.exports` stand-in object, the `PERRY_GLOBAL_SCRIPT_THIS` opt-in still gives a CommonJS file the Test262 script's `this === globalThis` (a module stays `undefined` under it), and module code being strict, `this.x = 1` at module top level now throws. Module-goal *detection* for ambiguous sources is unchanged: a file whose only module syntax is `import.meta` or a top-level `await` is still classified CommonJS, exactly as it was for strictness.
