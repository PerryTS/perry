Fix Buffer method calls and member reads ignoring a patched `Buffer.prototype`. A program that replaces, redefines or deletes a `Buffer.prototype` member (`Buffer.prototype.equals = f`, `Object.assign(Buffer.prototype, …)`, a computed key, `eval` or `new Function`) now calls and reads what node does. `Buffer.prototype` is intrinsic family `Buffer`, sealed when it is first built; its shadow bit gates the runtime name dispatch, so an untouched program runs the same code as before and startup is unchanged.
