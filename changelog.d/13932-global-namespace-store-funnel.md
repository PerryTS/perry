Fix namespace calls such as `Object.keys(x)` after a program stores into the global object: a computed-key store (`globalThis[k] = v`) or `Object.assign` / `defineProperty` onto the global object now guards the call on the namespace's runtime pristine bit instead of keeping the intrinsic, so a replaced namespace is called (it printed the intrinsic result before). Whole-program facts treat the strict existing-global store `Object = w` as a store into the global object, so values reachable through the replaced namespace stay live. A parenthesized or TS-typed target such as `(Object as any) = w` is scanned as the same store as `Object = w`.
