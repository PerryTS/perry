`Expr::Closure` carries the type parameters the closure declares (`type_params`): arrows, function expressions, object-literal methods and nested function declarations fill it. Monomorphization no longer substitutes an enclosing function's type argument into a closure that redeclares the same name, so `const first = <T>(xs: T[]): T => xs[0]` inside a specialized `outer<T>` keeps its own `T`. Crates outside the workspace that construct `Expr::Closure`, or match it without `..`, add the field.
