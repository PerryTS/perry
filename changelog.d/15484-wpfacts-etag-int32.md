Forward intervals through comma expressions and bound an in-bounds charCodeAt to a code unit. After a direct write to a local that no closure writes, later elements of a comma expression read the written value interval. A charCodeAt whose index the source proves in bounds (never-reassigned string, up-counting non-negative integer counter, untouched length guard) is in [0, 65535] with no NaN, so FNV-style hash locals stay int32.
