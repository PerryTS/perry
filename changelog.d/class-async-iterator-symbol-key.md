A class's `[Symbol.asyncIterator]()` method (plain or `async *`) is now a property of the prototype under `Symbol.asyncIterator`, so `obj[Symbol.asyncIterator]` returns it and the prototype no longer shows a string key `"@@asyncIterator"`. React Flight checks that property to serialize async iterables; Next.js's `/list` page failed with "Only plain objects ... can be passed to Client Components".
