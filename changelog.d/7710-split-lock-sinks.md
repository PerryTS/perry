### Fixed

- **Three more process-global test sinks with split lock domains, found by #7680's follow-on survey of #7672/#7674.** `async_hooks` (`HOOKS`, `RESOURCES`, `NEXT_ASYNC_ID`, and five more statics `reset_for_tests()` clears) sat behind **four** disjoint test lock domains — a private module lock, `AsyncHookRuntimeTestGuard`'s own private lock, the GC guards' shared lock, and (`test_async_hooks_promise_alloc_remains_malloc_tracked`) no lock at all. `tui::state::SLOTS` / `STATE_DIRTY` sat behind three. Both are `per_test_global!` now, which removes the need for any lock — the redundant private locks are deleted.

- **`agent_dispatch_tests.rs`'s timer queues were already `per_test_global!` (#7674), and that had silently made two of its five #6185 cross-agent dispatch tests vacuous.** Those tests spawn a "worker" thread and assert it can neither fire nor see a timer the "primary" thread scheduled — but a freshly spawned thread gets its own **empty** per-thread queue by construction, so the assertions held no matter what `crate::agent::owns` did. Sabotaging `owns()` to always return `true` confirmed it: only 2 of 5 tests caught the sabotage before this fix. Fixed with a new opt-in escape hatch, `PerThread::shared_key()` / `PerThread::adopt()` (`per_test_global.rs`), that lets a test whose actual subject is cross-thread visibility put a deliberately-spawned worker thread onto the SAME table instance the spawning thread already has — restoring genuine coverage without reintroducing the #7672 hazard for the ~180 other readers per-thread storage protects. After the fix, 4 of 5 tests catch the same sabotage (the 5th tests `owns()` directly and always did). Also unified the file's private `TIMER_QUEUE_TESTS` lock with `crate::gc::global_side_table_test_lock()`, matching the `plugin::REGISTRY` precedent and defending the window where primary and worker now genuinely share a table.

  Each conversion carries a deterministic regression test (write on one thread, clear/read on another) confirmed to fail against the pre-fix shape.
