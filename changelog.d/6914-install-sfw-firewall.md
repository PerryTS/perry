**`perry install` rides Socket Firewall:** the secure install wrapper (#738) now auto-detects an `sfw` binary (perry's dev-tools rack first — the SRI-pinned copy `tools:install` places there — then PATH) and runs the wrapped `bun`/`npm` install *through* it, adding network-time malware scanning to the existing offline scan + lifecycle-script allowlist: wire → tree → execution. Fail-open when sfw is absent (one stderr note; `--no-firewall` opts out and silences it); the child env sets the `SFW_SHIM_ACTIVE_*` sentinels so a shimmed package manager execs the real binary instead of nesting a second proxy, and `SFW_UNKNOWN_HOST_ACTION=ignore` keeps enterprise sfw from blocking non-registry hosts. Companion to the supply-chain soak PR (#6912); notably closes the gap where the bun path bypassed the sfw shims entirely (bun is not a shimmed ecosystem).
