RSA key generation honors `modulusLength` and `publicExponent` (#15445): `crypto.subtle.generateKey`, `generateKeyPairSync` and `generateKeyPair` always produced 2048-bit keys with exponent 65537. Sizes and exponents Node rejects are rejected with Node's errors, so a missing `modulusLength` (or WebCrypto `publicExponent`) is now an error. RSA public keys from 4097 to 16384 bits load for verification, encryption and export.
