Fixed the `perry-runtime` unit tests, which stopped linking after named builtin imports landed. A function-info record declared through a macro from another crate got a linker name with different spacing from the one its importers used; record names are now spelled from the body path's identifier segments, so they no longer depend on which macro carried the declaration. The native export checks added in the same change now read a closure's function info through the checked accessor, so a closure header without a body record no longer crashes them.
