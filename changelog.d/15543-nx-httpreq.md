Performance: a node:http `IncomingMessage` is now an ordinary heap object on a fixed layout, so a request costs fewer instructions per request (the empty handler by about 1.5%, a Next.js page by about 11%, an API route by about 5% on the nextjs-hello server). `req.headers` is built once, so its identity and mutation now match node (the same object on every read, and a write to it stays), the response `'close'` event is emitted on the tick after `'finish'` as in node, and `readingMore` is an accessor on the readable-state prototype.
