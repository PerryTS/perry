The compiler now knows, for every parameter and `this` of an ordinary function or method, what the body does with the value: drops it, returns it, stores it in its receiver, or keeps it. The rule accepts only field reads the whole-program facts prove are plain own data loads, identity compares, and arguments of calls whose bodies drop them, and is computed as a least fixpoint over the call graph. Nothing consumes it yet; with `PERRY_LIFE_CENSUS=<file>` set at compile time the compiler writes, for every `new` in the program, whether the object could live in its creating function's frame and, if not, the first thing that blocks it. Generated code is unchanged.
