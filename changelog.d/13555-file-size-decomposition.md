**Every Rust file over the 2000-line cap is now under it, because each was split along a responsibility rather than trimmed to fit.** `scripts/check_file_size.sh` (a `lint` step) was red on nine files between 2002 and 2264 lines. Each is now a module that owns one job plus the modules for the jobs it was mixing: `block.rs` (2002 → 1609) keeps only the IR emitter, with `FpFlags`, `EhScope` and `RegCounter` in `block/`; `node_stream_event_emitter.rs` (2002 → 1772) keeps the emitter surface, with event delivery in `emit.rs`; `canonical_keys.rs` (2264 → 1872) keeps the trie, with its views, census and record types in `views.rs`/`stats.rs`/`records.rs`; `layout_desc.rs` (2031 → 1897) keeps the `perry_layouts` section, with the scattered `perry_atoms` code in `atoms.rs`; `gen_rest.rs` (2015 → 1951) keeps the exhaustive 124-arm match, with the model-node builders it calls in `nodes.rs`; and `create_families.rs` (2028 → 1070) keeps fact collection, with its records, site derivation, emission and proto-export registry in `models.rs`/`site.rs`/`emission.rs`/`proto_exports.rs`.

Two couplings the splits exposed are fixed rather than papered over: `LlBlock` had been reaching into `RegCounter`'s private `byte_owner_root_slots` (once with `borrow_mut`), so those operations now live on the type; and `node_stream_event_emitter.rs` is included as `crate::node_stream::event_emitter`, so its `super::` meant `node_stream` — extracting a child module silently repoints every `super::X`, which is why fifteen paths inside `emit.rs` say `super::super::X`. The rule this work follows, and the per-file inventory, are written down in `odd/tasks/file-size-decomposition.md`. No behaviour changed: `perry-codegen`'s lib suite is 2622 passed / 13 failed / 1 ignored on this branch and on `main`, with the failing test names set-identical, and the moved tests pass in every touched crate.
