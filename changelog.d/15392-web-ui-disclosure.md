Add `Disclosure(title)` to `perry/ui`: a section whose children, attached with `widgetAddChild`, show when the reader expands it. The web target renders `<details>`/`<summary>`; native backends show a `Section`, always expanded. On the web target, `widgetReorderChild` no longer counts a `Section`'s title as its first child and `widgetClearChildren` no longer removes it.
