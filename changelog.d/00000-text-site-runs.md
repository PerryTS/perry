The whole-program facts solve no longer loops without end on a wrapper that calls the function it replaced through `orig.apply(this, args)`, as next.js `node-crypto.js` does for `randomBytes`. Such a wrapper, run once per call site (rules C and E2), keyed the solver-made `apply` call by its own fresh id, so each level of the recursion made a new run. The nextjs compile reached 90 GB in five minutes before the work bound could stop it. Runs are now keyed by the program-text site: a solver-made call takes the site of the call its chain started at. Separately, sinking a value into a native call no longer scans every rule on the node to find out whether that call's throw region is already attached, which made the nextjs solve quadratic on nodes that many native calls sink.
