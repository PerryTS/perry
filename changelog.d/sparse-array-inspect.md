`console.log`, `util.inspect`, `util.format` (`%s`, `%o`, `%O`, `%j`'s cycle check) and an Error's `errors` array print a sparse Array (`a[3000000] = 1`, `a.length = N`, `new Array(N)`) from its own elements: the store's slots, then the far elements its named layout keeps, with each run of absent indices as one `<k empty items>` entry (`[ <3000000 empty items>, 1 ]`). They read `length` raw slots from a short store before, printing heap words or crashing (memory safety). Shared walk `array::array_for_each_own_element`; an inspect hook that shortens the Array ends the trailing run at its live length.
