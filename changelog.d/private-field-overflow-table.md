A private field read or write on an object that has an overflow table (after a computed-key add, a `delete`, or an accessor define on the instance) reaches the field's own slot. The table addresses its entries by position, and a class layout names each key's storage slot separately from its list position, so the position of the `#p` entry is not its slot: `class Q { #p = 1; a = 2 }` read `a`'s value for `this.#p` once the instance had a table, and `this.#p = v` overwrote `a`. The private storage lookup now keeps a table entry as a table entry (read and written through the table, which follows the entry to its fixed slot or holds the value) instead of using its position as a slot number; an intrinsic's private read takes the same path.
