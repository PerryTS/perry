**Inside its own body, a per-evaluation class declaration's name now means that evaluation for `new`, `instanceof`, async bodies and inlined factories as well (#11142).** #11188 (#11157) gives a function-local class declaration with private elements or a dynamic `extends` a compiler-private self-binding, and routes its static reads, writes and calls through it. Four gaps remained:

- **`new RC()` and `x instanceof RC` inside the body** still used the shared template. They now go through the self-binding (`fresh_class_decl_self_binding`, used in `expr_new.rs` and `arm_bin.rs`). @redis/client 6.1.0's `RedisClient.factory` / `create` (`attachConfig({ BaseClass: RedisClient })` from a static method) now builds a subclass whose pinned parent is the caller's evaluation. `client instanceof RedisClient` and `#options in client` return `true`.
- **Inside an `async function` or generator**, the self-binding read `undefined`. Codegen stores the fresh object straight into the owner slot, and the async/generator transform had moved that local into a boxed state-machine variable. The declaration's binding is now `(owner = <fresh>, owner)`, the same shape `lower_class_expr` uses, so HIR passes see the assignment.
- **A factory inlined into module init** kept the callee's `ClassExprFresh::evaluation_owner` id, while the captures that read it were renamed, so the self-binding stayed `undefined`. `remap_local_ids_in_expr` and the inliner's `substitute_locals` now remap it.
- **The template-keyed `RegisterClassCaptures` snapshot** of a self-bound declaration is now taken after the evaluated object exists, so the fallback snapshot holds the evaluation instead of `undefined`.

Tests: `test-files/test_gap_11142_class_self_binding_static_factory.ts`, and the `perry-hir` tests `lower::tests::class_decl_self_binding`.
