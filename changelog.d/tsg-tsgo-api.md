`--type-check` now speaks the native-preview 7.0.0-dev.20260612.1 snapshot API: binary MessagePack tuples, initialization, project and type handles, native type flags, and zero-based UTF-8 source positions. Config, syntax, and semantic errors are reported and stop compilation. Missing checkers and unsupported preview versions produce an explicit warning and compilation continues without checking. The unversioned preview protocol is gated to the verified executable version before starting IPC.

Coverage includes real pinned-tsgo 10- and 300-file projects, standalone diagnostic parity, Unicode positions, inferred literal types, malformed/large wire messages, and missing/old/new checker fallback. Real checker tests are opt-in and require an explicitly installed pinned executable; they do not download tools in CI.
