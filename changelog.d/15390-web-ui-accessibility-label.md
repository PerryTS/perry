Add `widgetSetAccessibilityLabel(widget, text)` and `Label(text, field)` to `perry/ui`. On the web target the first sets the widget's `aria-label`, and `Label` is a `<label for>` bound to the field (or to the input inside a composite widget such as a `Toggle`), so tapping the caption focuses the field and screen readers announce it. Native backends keep the platform's default accessible name and show a `Label` as its text.
