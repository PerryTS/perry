Add `widgetSetAccessibilityLabel(widget, text)` and `Label(text, field)` to `perry/ui`. On the web target the first sets the widget's `aria-label`, and `Label` is a `<label for>` bound to the field (or to the input inside a composite widget such as a `Toggle`), so tapping the caption focuses the field and screen readers announce it. On the Apple targets, Android and GTK4 the first sets the platform's accessible name, and `Label` is a `Text` that names its field. On Windows the first does nothing and `Label` is only a `Text`.
