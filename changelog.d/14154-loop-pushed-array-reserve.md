Performance: an empty array literal bound to a local that a later loop pushes into (`const moves = []; for (…) moves.push(m)`) is born with 16 slots instead of 4, so sixteen pushes need no reallocation. A literal pushed only outside a loop, or one created fresh in each iteration of the loop that pushes into it, keeps the four-slot birth. 16 pushes into `[]` drop from 1,832 to 1,080 instructions. `PERRY_PUSHED_ARRAY_RESERVE=0` keeps the four-slot birth.
