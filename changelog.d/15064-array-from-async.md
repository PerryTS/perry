`Array.fromAsync` is an own function of the `Array` constructor again: `typeof Array.fromAsync` is `"function"` (name `fromAsync`, length 1), and value reads, `.call` and `Reflect.apply` reach it. A direct `Array.fromAsync(...)` call no longer throws `TypeError: fromAsync is not a function` or traps its callbacks, because the whole-program facts no longer read the name as an absent global. A constructor receiver builds the result as the specification requires: `Array.fromAsync.call(C, items)` and `class List extends Array {}`'s `List.fromAsync(items)` resolve to an instance of `C` / `List`. test262 `built-ins/Array/fromAsync` goes from 0 to at least 60 of 95.
