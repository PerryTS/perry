Stream construction births its two lifecycle slots and state-view owner slot with attributes through the existing canonical keys trie, removing intermediate key and descriptor edits. Direct constructors initialize the lifecycle slots by index. Per-side public fields preserve their existing overflow layout, and subclass fields retain ordinary property definition timing; widening the public inline layout was rejected because it increased buffer stream unpacking instructions by 1.14%. Once wrappers birth their observable `listener` property in a fixed function-bag slot. Stream hooks retain the original function and use the existing explicit receiver forwarder at invocation, eliminating redundant per-instance closure copies. Runtime by-name lookup and transition memos are unchanged. Constructor helpers borrow the builder’s existing rooted receiver and options handles, refreshing them after user getters or allocation instead of carrying stale scalar copies. This fixes stream construction when option getters trigger moving collection.
