Cross links to Linux that run lld work again with the default hot-text order. The x86_64 link from macOS and the clang fallbacks of the aarch64 and musl targets pass `-fuse-ld=lld`, but they got the GNU ld flavor of the hot-text linker script, which lld rejects ("unable to insert .text before .text"). A link line whose last `-fuse-ld=` names lld, including one set through `PERRY_EXTRA_LINK_ARGS`, now gets the lld flavor (the hot run in its own output section, `.text.perry_hot`). GNU ld links are unchanged.
