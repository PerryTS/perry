**A shape Region can no longer settle on a reservation too small to hold the native birth layouts.** `Region::new` halves its reservation when the address space is limited, and its floor was `2 * DYNAMIC_BASE_ROWS` — the process-wide chunk space, which ends before the rows agent creation actually seeds: `WEAKMAP_BIRTH_LAYOUT` and `WEAKSET_BIRTH_LAYOUT` sit past it. Under a constrained address space the Region could accept 4,194,304 rows against a native page ending at 4,227,072, leaving the agent unable to publish the layouts it needs before any user code runs. The floor is now the larger of the chunk-space requirement and that page, rounded up to a whole directory page, and the retry loop ends by trying the exact floor rather than assuming a power-of-two descent lands on it. Extracting the loop into `reserve_with` makes the halving testable with an injected allocation failure: one test drives a world where only the native page fits and asserts the floor lands there, the other asserts that a world where nothing that small succeeds fails loudly instead of running with a Region that cannot hold the birth layouts.
