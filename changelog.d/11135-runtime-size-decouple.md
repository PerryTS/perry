- perf(size): the runtime a small program links is ~25% smaller — a loop program 7,425,832 → 5,589,376 bytes, a small CLI 7,673,864 → 5,804,416, an async program 7,508,504 → 5,804,512 (stripped, macOS arm64, auto-optimize; the `prebuilt-core` archive gets the same cuts). No compute regression on a quiet-host A/B (fibonacci, binary trees, closures, JSON, strings, promises, throws: all within noise or faster). Levers, one commit each:
  - Runtime built with synchronous unwind tables (`-Zuse-sync-unwind=yes` in `.cargo/config.toml`, the auto-optimize driver and the musl script). Asynchronous tables are not compact-unwind-encodable, so ~90% of runtime functions carried a DWARF FDE (~500 KB); every PC the EH transport, GC walk and `_Unwind_Backtrace` unwind from is a call site, where synchronous tables are exact.
  - Native-module hubs no longer pin module surfaces: `bound_native_callable_export_value` stops installing `node:module` (the `MODULE_CJS` `.constructor` read is an armed hook), per-module constant resolvers (`NM_CONST_REGISTRY`, registered by `js_nm_install_<module>()`) replace the inspector/tls/zlib/http/cluster/process arms of `get_native_module_constant`, the EventEmitter ops move to a table armed by the `events`/`stream` installers, `populate_global_this_builtins` no longer installs the `process`/`console` dispatch buckets (codegen emits `js_nm_install_process`/`js_nm_install_console`/`js_install_global_value_surfaces` at every value site; dyn-eval and `node:vm` install both), and the URL prototype accessors join the `global-url` gate.
  - New perry-runtime feature `gc-instruments` (census, from-space quarantine/scan, seeded schedule, alloc-site sampling). In `default`; auto-optimize adds it when an instrument knob or `PERRY_GC_INSTRUMENTS=1` is set at compile time. A binary built without it **aborts at startup** if one of those knobs is set, instead of silently running nothing. GC scripts that set knobs only at run time now export `PERRY_GC_INSTRUMENTS=1`.
  - `crate::cold_sort` (one shared stable sort and one `(u64, u32)` pair sort) replaces ~290 per-site sort monomorphs on cold paths; `crate::once_init::get_or_init(fn() -> T)` leaves one `OnceLock::initialize` per type instead of per call site.
  - Programs proven synchronous (`sync_program`: an allowlist over every module's HIR — unknown constructs, async, `globalThis`, dynamic code, native modules, JS modules or stdlib keep the loop) end `main` with the exit sequence instead of the event loop. `PERRY_SYNC_PROGRAM_DIAG=1` prints the verdict.
  - New gate: `scripts/runtime_size_budget.py` compiles `benchmarks/runtime_size_budget/*.ts`, requires the expected output and no auto-optimize fallback, and fails when a stripped binary exceeds `budget.json` by >2% (in the `binary-size` job).
