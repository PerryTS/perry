- **perf(size): `localeCompare` no longer links the `Intl` namespace (−388 KB)** (#11114). Compiler feature detection (`crates/perry/src/commands/compile/collect_modules/feature_detect.rs`) enabled `perry-runtime/intl-namespace` for any `localeCompare` mention, linking every `Intl.*` constructor plus `icu_decimal` into programs that only sort strings. `localeCompare` returns a number and its runtime path (`string/compare.rs` + `intl::validate_locale_compare`) sits outside that gate, so the trigger is dropped; it still enables `string-normalize`. A `localeCompare`-only program on macOS arm64 went from 8,054,048 to 7,657,200 bytes (−396,848) with byte-identical output. Programs that mention `Intl`/`Collator`/`toLocale*` are unaffected.
