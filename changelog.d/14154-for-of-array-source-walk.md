Performance: `for (const x of e)` over a non-literal source evaluates `e` once and, when it is an ordinary array with default iteration (the IteratorRecord's own array-mode proof), walks it by index in a plain counted loop: no per-step mode selector and no iterator-close `try`/`finally`. Length and element are read at each step in the iterator's order, so pushes and truncation during the loop behave as before. Strings, Maps, Sets, generators, arrays with their own iterator and Array subclasses that override it take the IteratorRecord loop unchanged. A (parenthesized or cast) array literal keeps the IteratorRecord's constant-bound loop, and `x.values()` / `x.keys()` / `x.entries()` keep the Map/Set view's index path. Bodies over 2 KiB of source are not duplicated. Chess-engine search drops by 2.6% and perft by 3.7%. A for-of over an 8-element module constant that never exits early costs 11% more per loop (334 vs 300 instructions), because the walk's packed-array admission is a second runtime call. `PERRY_LITERAL_FOR_OF=0` turns it off.
