A class linked by name to a built-in parent (`class DOMException extends Error`) no longer gives a program class to unknown code when the global name may read that class (a store with an unknown key onto `globalThis`, `g[k] = dom.Event`). The facts solve now models that parent as program code: `super()` runs it, the instances' prototype chain continues at its prototype object, and the instance is marked hard E11 without escaping. Before, the program class escaped with its methods, and a later `new Map()` that may construct it held the realm.
