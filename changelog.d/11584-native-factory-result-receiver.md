**A native factory's result keeps native dispatch when used directly (#11568).** `createHook({...}).enable()` read `enable` off an untagged native handle (`undefined`): only a bound `const h = createHook()` carried the class tag, and the chained form had its own five-row factory table (http servers only). Both now share one table (`lower/native_factory.rs`), so createHook, dns Resolver, readline.createInterface, the perry/tui hooks and the pg/mysql2 factories work chained. A function that returns such a chain (`return createHook(...).enable()`) is also recorded as returning the native instance, so `f().disable()` no longer dynamically dispatches on the raw handle (a SIGSEGV).
