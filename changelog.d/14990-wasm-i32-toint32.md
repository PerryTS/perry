WebAssembly: a JS value crossing into an `i32` (an import result, an exported-function argument, a `WebAssembly.Global` value) goes through ToNumber then ToInt32, so `true` is 1, `"7"` is 7 and `4294967295` wraps to -1 instead of saturating; `f32`/`f64` go through ToNumber. emscripten's `emscripten_resize_heap` returns `true`, so every heap growth had looked failed to the guest and Oniguruma/Shiki returned wrong matches (#14965).
