Gap-suite parity fixes: `URLPattern.prototype` carries `@@toStringTag`; a type reference to a native namespace (`crypto.Hash`) no longer forces the namespace object, so `createHash("shake256", { outputLength })` keeps its length; `Uint8Array.prototype.toHex.call(u8)` and the other base64/hex methods accept a typed-array `Uint8Array`; `URL.revokeObjectURL` is a static value and `URL.parse` precedes `URL.canParse`; `util.setTraceSigInt` accepts any argument, as Node 26 does; `perf_hooks` `mark`, `measure` and `PerformanceObserver.observe` throw Node's messages with the `Received` clause.
