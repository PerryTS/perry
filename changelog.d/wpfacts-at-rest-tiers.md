I32 at rest, B2 (RFC §10.7, PR B follow-ups (c) and (g)): an at-rest int Array (I32 words) now takes the element paths a double Array takes. Its storage kind is part of the receiver's representation (`FactsArrRep::at_rest`; a class field's `Arr` representation learns it after the at-rest admission), so the rep-keyed element tier, C3's in-floor field read call and the held bases of PR-D / N2 address the same `h + 24 + 8i` slot and decode the I32 word through one accessor (`rest_elems::decode`). A read with an int32 key tests one unsigned bound instead of a double round trip, a read whose key the facts prove in the floor has no test at all and is a proven Number (no `??`, no coercion), and a counted loop's entry check proves a counter key in an at-rest local's floor as it does for a buffer view. Check mode tests the I32 word at every such load; the probe `PERRY_REST_DIAG=1` prints the form each at-rest site took, and `PERRY_REST_TIERS=0` restores PR B's lowering.
