**fix(runtime): a same-thread notify can no longer be consumed by another agent's wait, so a `worker_threads` worker's own net server no longer stalls (#11434).** `js_notify_main_thread` set `NOTIFIED`, one process-wide flag, and every JS agent's `js_wait_for_event` consumed it. A worker that queued work for itself outside its loop's turn lost that wake whenever the main thread's wait swapped the flag first. perry-ext-net releases the bytes that arrived before an accepted socket's `'connection'` callback exactly this way, so the worker then parked with its own events undrained.

The notify now also sets a thread-local flag, which only that thread's wait consumes. Cross-thread producers are unchanged. With a worker hosting its own echo server, 11 of 20 runs passed on main and 20 of 20 with this fix. The new gap test is `test_gap_11434_worker_own_server`.
