- Link-time ShapeIds: a loop region whose receiver the compiler names (a class instance, `this`, a parameter declared as a class or as a closed object type) now takes its guard's ShapeId from the driver's static id. The guard compares the receiver's ShapeId against the immediate and runs the region with the slots that id names as constants: no word load and no prime. A receiver of any other shape runs the unchanged generic copy. The route census (`PERRY_RECV_ROUTE_COUNT=1`) counts static hits as `rloop_static`.
