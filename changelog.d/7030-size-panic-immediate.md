**Binary size (opt-in):** new `PERRY_SIZE_PANIC=abort-immediate`, layered on `PERRY_SIZE_OPT`, rebuilds the Rust standard library with the `immediate-abort` panic strategy. That removes the backtrace symbolizer (gimli + addr2line + rustc_demangle + the default panic hook's formatting — 159 KB measured) and, with nothing left to unwind, the per-function unwind tables as well. Size-mode hello world: 2,274,776 → 1,960,408 bytes (−314 KB, under 2 MB). Requires a nightly toolchain for `-Zbuild-std`. JS semantics are untouched — `throw`/`catch`, `finally`, error stacks and `uncaughtException` all stay byte-identical to Node; only a Rust-level internal panic loses its symbolized backtrace. The default and plain-size-mode paths are byte-for-byte unchanged.
