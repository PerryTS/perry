**A `node:url` factory enables the global-url member tables (#11560).** `pathToFileURL(p)` returns a WHATWG URL whose components are `URL.prototype` accessors (a9c6b0202), installed only under `perry-runtime/global-url`. The gate matched the static URL lowering but not a `node:url` NativeMethodCall, so an auto-optimized program reaching URLs only through `node:url` read `pathToFileURL(p).href` as `undefined` — every `import(pathToFileURL(p).href, { with: { type } })` became `import(undefined)`. Fixes `issue_10104_runtime_data_imports` and `test_dynamic_import_data_10104`.
