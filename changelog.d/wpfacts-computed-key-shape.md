Whole-program facts: a computed key built from literal parts (`o[type + "s"]`, `` o[`${a}:${b}`] ``) names only members whose name matches those parts (prefix, suffix, the literal parts in order). Such a key no longer reads `constructor` (so no Object or Function constructor whose absent methods would take the arguments), an own field or builtin member it cannot spell, or an element; a store through it writes only the names it can spell. Keys whose shape admits `constructor` or a number, keys with no literal part and keys held in a variable are unchanged.
