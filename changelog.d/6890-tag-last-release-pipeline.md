Tag-last release pipeline: `release-packages.yml` dispatched with `cut_release=true` now gates on tests, builds every leg, and only then creates the `vX.Y.Z` tag + GitHub Release and publishes — a red run no longer burns a tag or ships a half-published release. The dangerous "latest release" fallback on manual dispatches is gone (plain dispatch is a build-only smoke run; re-publishing takes an explicit `existing_tag`), and `cut_release_notes.sh` gains `--notes-only` / `--fold` modes for the split notes-then-cleanup flow.
