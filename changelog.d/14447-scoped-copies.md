A copy of a local inside a loop, a branch or a closure body is folded into its source (`scoped_copies`, after the straight-line `local_copies`): when neither local is ever written, both have the same type (a primitive or a class the module declares) and every use of the copy is a read after it in its own block, the reads name the source and the declaration goes. The inliner binds each argument of an inlined call to a fresh local, so `const p = new P(i, i + 1); s += len(p)` in a loop left `p` with two names and on the heap; it is now dissolved into its fields like an object that was never passed (100M iterations: 0.29 s to 0.16 s, no heap use). A captured copy, a read before the declaration, a source declared later or in an earlier `switch` case, and a local of any other type are left as they were.
