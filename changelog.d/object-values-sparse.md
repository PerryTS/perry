`Object.values`, `Object.entries` and `Object.keys` of an Array list every own element: the far elements of a sparse Array (`a[3000000] = 1`) are included, and an Array above 100 000 elements is no longer answered with `[]` (values / entries) or without its store's indices (keys). One rooted walk serves the three; the old arms allocated key strings and pairs while holding raw pointers.
