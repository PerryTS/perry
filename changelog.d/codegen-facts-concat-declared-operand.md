Check mode no longer reports a false `call kinds` proof ("string operand @0", rc 86) for a `+` lowered as the facts' string concatenation whose operand is a string only by a declaration, such as `xs[i] + t[i]` on `t: string` (the read is `undefined` past the end). `expr/facts_string.rs` now tells an operand's basis apart (none / declared / facts) and witnesses only the operands a fact calls a string; the lowering is unchanged (default-mode code is identical).
