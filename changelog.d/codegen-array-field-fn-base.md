Performance: a method body holds the element base of an Array held in a field of `this` from its first read to its end (function-level bases, N2), not only across one loop. When every statement from the first field read call (`this.at(sq)` = `this.board[sq] ?? 0`) to the end of the body can neither call, store, allocate nor run user code (its back-edge polls and the cold arms of reads outside the floor are its only region enders; a `for (const d of KNIGHT)` walk that is unrolled counts as its body), and the rest of the body reads the field at least twice, the base is installed once before that statement and serves every read after it, including those in the loops inside, which then install nothing. The polls and the cold arms re-derive it, exactly as for a loop. `PERRY_FACTS_FN_BASES=0` turns it off; `PERRY_VERIFY_FACTS=1` checks it as for a loop; `PERRY_FACTS_SABOTAGE=fnbaseadm` and `fnbasewalk` are the negative controls; `PERRY_ARRAY_BASE_DIAG=1` prints the verdict per method.
