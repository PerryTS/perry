Object spread with later literal keys (`{...src, k: v}`) and `Object.assign({}, src)` now create their result with room for every key it receives, so filling it no longer allocates a per-object metadata record and a spill array. The spread result is born with slots for the source's keys plus the literal keys after the spread, and an `Object.assign` whose target is an empty object literal creates that target after evaluating the first source, sized to that source's own keys. `Object.assign` also skips building the source's symbol list when the source's shape proves it has no symbol keys. Key order, property attributes and getter timing are unchanged.
