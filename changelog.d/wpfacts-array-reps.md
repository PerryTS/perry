Internal: whole-program facts now give a binding or class field that holds only plain program Arrays its own representation, `Rep::Arr` (element representation, length floor, dense below the floor, fixed length). Only an array literal, a spread literal and `new Array(...)`/`Array(...)` are plain births; a JSON array (which may be a lazy header) and every runtime-born array are not, and a call site whose callee may be either kind births one template per kind. `new Array(k).fill(v)` is born without holes. `Rep::join` is now one full table (a Number and an Array join to Boxed), and every slot-encoding decision of P2's typed signatures goes through `Rep::encoding()`, so an array-typed slot never makes a function typed. Nothing consumes the representation yet, so emitted code changes only where the fused fill makes an array's iteration hole-free. `PERRY_FACTS_ARRAY_REPS=0` turns it off; `PERRY_VERIFY_FACTS=1` checks the claim at each element read of such a local, and `PERRY_FACTS_SABOTAGE=arrdense|arrelem|arrlazy` are its negative controls.
