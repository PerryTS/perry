- Link-time ShapeIds: the plain mint aborts on a refused static id, as the typed install does (ids are by content). An importer's structural view with exactly the definer's facts requests the definer's id, so init order never matters. Each agent now runs a generated seed unit (after `js_gc_init` in `main`, at every other agent's start) that mints the static literal ids the guards embed before any user code, so a key list built earlier by `JSON.parse` or dynamic adds can no longer take those facts under a counter id; the object cache keeps the seed set in a `.seeds` sidecar so cold and warm builds seed the same set. An empty literal gets no static id (its shape is the runtime's own). `PERRY_STATIC_SHAPE_CENSUS=1` prints each static request and whether it hit.
