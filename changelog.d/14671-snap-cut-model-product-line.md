Internal (instrumented census and offline snapshot cut model, no change to any production binary): the cut model reports a product cut that follows an explicit classification per blocker kind instead of skipping the first four ladder steps. Every blocker kind is a stop unless a member rule passes it, and the output prints the reason for each passable member kind (unset env keys, named env values other than USER, tty and style-bit, the dispatch sentinel predicate, the supports-color argv predicate, which is matched by module name and says so) and for each stop (uid/gid, the USER copy, tty.winsize, env enumeration, entry-birth holds, the first suspended module body). Hypothetical what-if lines name the assumption they drop. "Before init N" is the boundary of the outermost open frame at the blocking row, printed beside the blocking init. An env key read unset inside an env-enumeration init is now recorded, so a later delete of it is covered by the same member. The dynamic `process["argv0"]` read opens a host-value census scope like `process.argv`.
