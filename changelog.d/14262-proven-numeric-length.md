Fix: `x.length` is a Number in operator lowering and in the static type answer only when `x` is a literal, a binding whose initializer proves a String, an Array or a numeric typed array, or a binding the whole-program facts prove holds only strings and ordinary Arrays. A declared `string[]` element written through `any` can be a Number, whose `length` is `undefined`; a Number accumulator adding it printed `undefined` instead of `NaN`.
