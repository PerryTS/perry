CommonJS plumbing is compiler-owned: each program gets one generated support module (`perry:cjs`), imported first by every wrapped module. It holds `require.cache` as an object whose keys are the graph's module paths (each absent until its module loads, null prototype), the main record, and the shared loader helpers. Module records are object literals with one layout. The wrapper's own `require.cache[<path>]`, `module.exports`, `parent` and `children` reads become proven single loads, and no CommonJS state lives on `globalThis`. Reassigning `require.cache` no longer redirects loading, matching Node, whose loader reads `Module._cache`.
