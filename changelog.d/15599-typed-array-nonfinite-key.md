A typed array store at a NaN or infinite Number key runs `ToNumber` on the value before it drops the store, as Node does: `ta[NaN] = { valueOf() { … } }` calls `valueOf` once. A store whose value's conversion makes the index out of bounds (a `valueOf` that shrinks or detaches the buffer) no longer writes the element: the index is validated after the conversion, and an index that stays in bounds is still written. A dynamic typed-array store returns the value at its current address after a collection inside that conversion.
