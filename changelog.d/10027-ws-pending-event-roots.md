Keep WebSocket pending-event listener snapshots and message payloads rooted across moving garbage collection. The registry scanner updates stored listeners, but previously left copied dispatch vectors and message arguments pointing into retired nursery memory after allocation or an earlier callback collected. All pending-event branches now use transient roots, matching synchronous server event delivery. A regression forces relocation in the first message callback and verifies that the second receives both the relocated callback and the original payload.

Generic WebSocket client listener registration now shares the buffered-message drain with receiver-method registration (#10029), so frames sent before an asynchronous authentication callback registers its listener are delivered in order.
