Performance: a loop that reads an Array held in a field of `this` on every iteration holds the Array's element base across the loop. When a field read call (`this.at(sq)` = `this.board[sq] ?? 0`) whose field is a dense whole-program `Arr` runs on every path to the loop's back edge, and nothing else in the loop can collect, call, store or allocate (its back-edge poll is the one region ender), the loop's guarded preheader loads `this.board` once, resolves a growth forwarding stub to the live head once, and keeps the head: each read in the loop is then one load at `base + 24 + 8 * i`, with no field reload, no pointer masking and no forwarding test. A read whose key can leave the call's floor tests the key against the dense floor and otherwise keeps its own read, after which the base is re-derived. The poll's slow block re-derives the base from `this`'s root after a collection. There is no second loop body. `PERRY_FACTS_ARRAY_BASE=0` turns it off; `PERRY_VERIFY_FACTS=1` tests the head at the install and at every refresh, and at every read that the held base is the live head; `PERRY_FACTS_SABOTAGE=arrbase`, `arrbaseadm` and `arrbasepoll` are the negative controls; `PERRY_ARRAY_BASE_DIAG=1` prints the installer's verdict per loop.
