Facts dump (`PERRY_FACTS_DUMP` only, per-unit runs): every census report carries its reasons. A unit that uses another unit's layout beyond its contract now says why: a store no store effect covers (key and object: undeclared key, key not definite, accessor key, class object, prototype), the keys the layout gains, the escape reason of each token (with the function whose walk first escaped it) or its hard mark, an aborted unit, a function used as an object, an override. At the fixpoint the `<census>` unit holds one `report` record per broken display with its owners, the round it broke in, the units whose reports broke it and the units still reporting it. The seed of a broken layout names the display. With the dump off nothing is captured: native images and fact fingerprints are unchanged.
