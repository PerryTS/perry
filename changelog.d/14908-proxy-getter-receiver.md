A Proxy with no `get` trap now runs an accessor it inherits from its target with the Proxy as `this`, as `target.[[Get]](key, proxy)` requires. A builtin getter's brand check therefore sees the Proxy, so `new Proxy(new Uint8Array(4), {}).length` and the typed array's `.byteLength`, `.byteOffset` and `.buffer` throw `TypeError` as in Node. So do `Map`/`Set` `size` and the `ArrayBuffer`/`DataView` getters read through such a Proxy. These reads used to answer the target's own value.
