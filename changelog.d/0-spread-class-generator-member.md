A spread of a class instance whose class declares `*[Symbol.iterator]()` (`v4.set(...v3, 1)`, `f(...vec)`, `new C(...vec)`) calls the generator member directly and drains it into the argument array in place, when the operand's class is known at the call site. The site checks the receiver's family layout and every prototype's static shape (so the prototype slot still holds the declared generator); a replaced, shadowed or redefined member takes the generic spread. r2b `set(...vec3, 1)`: 930-1,260 -> 420-525 ns per call on qb9 (node 140-256).
