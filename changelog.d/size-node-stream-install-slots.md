Binary size: a program that does not use `node:stream`, `node:events` or an http server no longer links the Node stream family (about 0.95 MB; chess 9 308 288 -> 8 359 488 B, hello2 7 344 552 -> 6 387 560 B on Linux x86-64). The two always-linked references that pinned it, the http server handle's inherited-member check in the generic property read and the `cluster` default export's EventEmitter constructor, now go through slots that the http handle classifier's registration and the events install fill. Programs that use the family link and behave as before; an empty slot fails loudly.
