Binary size: a program that does not use `node:stream`, `node:events`, `node:cluster` or an http server no longer links the Node stream family (about 0.95 MB; chess 9 308 288 -> 8 363 584 B, hello2 7 340 456 -> 6 387 560 B on Linux x86-64). The two always-linked references that pinned it now go through slots: the http server handle read's comparison with the stream intrinsics (filled where the http handle classifier registers) and the generic `cluster` default export (filled by the cluster install). Programs that use the family link and behave as before; an empty slot fails loudly. The default hot-text order is recorded again on the smaller runtime (peak RSS unchanged).
