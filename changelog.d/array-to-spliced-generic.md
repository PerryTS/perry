`Array.prototype.toSpliced` works on every receiver: an Array-subclass instance, an Array with an own method, an array-like or a string through `.call`, a Proxy. It was a no-op thunk that answered `{}` whenever the call was not lowered to the dense body; it now runs the spec-generic body (ToIntegerOrInfinity of start, then of skipCount, `Get` for each kept index, always a plain Array).
