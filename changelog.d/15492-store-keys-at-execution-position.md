Performance: a class layout places each key a constructor stores at the position where the constructor stores it. A key that is not a reservation (a class capture stash, a method-name store, an inherited field, a computed string key) used to go after all reservations, so a constructor that stored one first, such as the early capture stash at entry, put every instance on the overflow. Each stored key now goes before the first reservation stored after it; the class field order, the facts birth and the layout agree. A store `o[K] = v` with `K` a const bound to a string literal folds into the named store `o.name = v`.
