Fix native-base `super` reads and prototype inheritance for subclasses with captured symbol helpers. Instance `super` property reads now follow the home prototype's actual parent edge with the original receiver, unifying native and compiled parent lookup instead of looking for a declared prototype under a native reserved class id. A fresh class evaluation without dynamic heritage now copies the parent edge from its declared prototype's shape, preserving native inheritance when symbol captures require a distinct class object.

The spread failure was introduced by the method-before-arguments split in #11910: the early read returned `undefined` for native methods, so `super.emit(ev, ...args)` threw `value is not a function`. The captured-symbol subclass failure is independent and also reproduces on `2386aaaab4`, the parent of that change. Both fixes use existing prototype shapes; they add no tables, registries, caches, latches, or method-name checks.

Regression fixtures cover EventEmitter `emit`/`on`/`once` spread forwarding, getter receiver and lookup-before-iteration order, Readable `push`, and minipass-shaped symbol helpers and separate factory evaluations. The CommonJS fixtures run directly and through a TypeScript entry point discovered by the gap suite.

Validation on Linux with Node 26.5.1: both CJS fixtures and their TypeScript entry point fail on `dffccc7e64` and match Node with the fix. All 32 related gap checks pass, including `test_gap_11910_member_call_order.ts`, with no regressions among tests that passed on main. The runtime suite passes 5,262 unit tests and one integration test with zero failures on both main and the fix; formatting and the Node-version consistency check pass.
