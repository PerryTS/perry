Performance: an element read `a[i]` whose receiver is a local, parameter or module constant that whole-program facts prove holds only plain program Arrays (`Rep::Arr`) now reads under that representation. It needs no pointer-band test and no type test; no forwarding test when the Array's storage never moves; no bound when the key's interval lies below the Array's length floor (the constant length as the bound when the length never moves, the capacity otherwise); the slot is addressed right behind the header when the length is defined; no hole test below a floor that is never a hole; and, in a number context, no number test when the read is a proven Number. Such a read below the dense floor of a fixed Array is one load with no cold path, and `x ?? d` on it is `x`. A scalar-replaced literal never takes the tier. `PERRY_FACTS_ARRAY_TIER=0` restores the previous reads (and `PERRY_FACTS_ARRAY_REPS=0` the facts under them); `PERRY_VERIFY_FACTS=1` re-tests every such read's claim where it loads, including that the elements start at the front of the allocation, and `PERRY_FACTS_SABOTAGE=arrfront` is the negative control for that.
