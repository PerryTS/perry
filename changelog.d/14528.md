An index read with a Number key on a `Date`, a `Promise` or an `Error` returned a raw word of the object, or of the memory behind it, with no bound (`new Date(0)[2147483647]` crashed); it now reads the property, as on every other object. A store through an index into such an object, a `Map` or a `Set` held behind an array annotation (`number[]`, `any[]`) is no longer dropped, an object literal behind `any[]` no longer gains a `length` with it, and module-scope index reads on these objects no longer answer `NaN`.
