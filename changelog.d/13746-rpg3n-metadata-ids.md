codegen: numbered metadata ids come from one module counter. A buffer alias scope owns three consecutive ids (scope node, scope list, noalias list) and the alias domain and loop IDs follow from the same counter, so a module with more than 100 buffer alias scopes no longer defines `!201` twice ("Metadata id is already used"). Native construction (the default for large split modules) builds the module's numbered `!N` nodes from the same skeleton lines the text path parses: `!alias.scope`/`!noalias` references and the loop/branch metadata of typed branches are attached instead of silently dropped, and an unknown attachment form is an error.
