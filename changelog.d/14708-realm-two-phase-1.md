Runtime: the population of the realm's global object is split into two phases, the core (`populate_realm_core`) and the rest (`populate_realm_rest`), with a "realm complete" predicate (`realm_is_complete`) and a phase-B driver. Phase B holds no row yet and the two phases run back to back, so nothing changes in behaviour or cost; this is the base for a realm that is built by need (start-up instructions).
