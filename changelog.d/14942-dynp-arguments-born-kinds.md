Arguments objects are now born on their own runtime layout kinds (Arguments and ArgumentsStrict): length, callee and @@iterator are the first slots and the elements follow inline, mapped elements read their parameter cells, and every other operation takes the ordinary generic path. Observable behavior is unchanged; arguments-heavy code executes far fewer instructions (the escaping-arguments micro row drops from about 7000 to about 1365 instructions per iteration), and delete and defineProperty no longer test every key for an array index.
