Performance: a straight-line run of field reads and overwriting stores on one receiver (`this`, or a local until it is written) proves the receiver layout record once, at the first access; each later access tests only its key bit in that record and the slot hole. A call, a store that may add a key, a write to the receiver local, or any other expression ends the run, and nothing is kept between runs. `e.set(x, y, z)` followed by reads of `e` drops from 203 to 176 instructions per call (m_num), 356 to 338 with pointer values; skinbench instructions per pass are equal to main (645.07M vs 645.11M) and its code is 5 KB smaller.
