Performance: an add of two operands that are each numeric by construction (`k + i` of loop counters, Number locals, arithmetic results) is an `fadd` of two canonical numbers, so its result is proven non-pointer like the other arithmetic. A store or push of such a value now skips the live "may this be a heap pointer" test and its addref, layout note and barrier bookkeeping. An add with any other operand (a string, an `any`, a property read) keeps the test. Pushing `k + i` into a fresh local array, in instructions per outer iteration, with Node in parentheses: 5 pushes, 388 to 315 (532); 16 pushes, 978 to 748 (957); 40 pushes, 2473 to 1910 (1888); 200 pushes, 10916 to 8110 (10070). `PERRY_NUMERIC_ADD_BITS=0` turns it off.
