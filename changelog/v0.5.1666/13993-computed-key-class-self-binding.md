A class declared in a function that can run more than once, with a computed-key member (`[Symbol.iterator]() {}`), now sees its own evaluation under its own name (#13965). Such a class is a fresh class object per evaluation, but its body read the shared template instead, so `x instanceof C` inside its constructor was `false` for real instances and a static method returning `C` returned a different object than the caller's `C`. A CommonJS module compiled through `compilePackages` runs in a factory with exactly this shape: undici's `HeadersList` copy constructor (`init instanceof HeadersList`) fell through to `new Map(headersList)`, which broke `fetch()` from source.
