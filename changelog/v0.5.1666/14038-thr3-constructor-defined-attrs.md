Objects: a constructor that defines its own keys with `Object.defineProperty(this, k, { value, ... })` / `Object.defineProperties(this, {...})` gives those keys a place in the class layout, with their attributes. The definition fills the slot in place, the object keeps its layout and shape, and no descriptor header bit is set, so field and method guards stay on their fast path. The three.js-style `defineProperties` constructor in the r3b repro drops from 290 ns to 9.3 ns per object (a plain-assignment constructor: 7.5 ns). A `[[Set]]` or class field before the definition still adds a plain data property, in node order, and attribute readers (`getOwnPropertyDescriptor`, `Object.keys`, writes to non-writable keys, freeze) see exactly what node sees.
