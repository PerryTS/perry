perry-runtime's lib tests pass in the release and perry-dev profiles with the default thread count. The GC liveness counters (`copying_minor_cycles` and friends) now count in every lib-test build, not only debug ones, which is what 59 moving-GC tests read; shipping archives are unchanged and a compile-time assert keeps their counters zero-sized. Tests that assert on process-wide state (the event-pump wake flag, the has-active registries, typed-feedback counters, thread-slot claims, the guest host tables) run in their own process through `test_isolation::in_own_process`, and `TestOpsGuard` serializes component host-ops installs, which stops an uncaught throw in one `http::pump` test from aborting the whole test binary. CI's full-tier run now also runs the runtime lib tests in release.
