Builtin method calls read the method the receiver actually inherits. A Map, Set or Date that takes its own prototype (`Object.setPrototypeOf(s, p)`) now calls the method on `p` even where the compiler knows the receiver is a Set and calls the builtin directly; before, `s.has(x)` still ran `Set.prototype.has`. The direct Map and Set call checks for an own or inherited override under every name it lowers, including the ES2025 Set methods. A `new String(...)` wrapper whose prototype is replaced, or that has its own method, now calls that method; before, a call through an untyped value unwrapped it and ran the built-in string method.
