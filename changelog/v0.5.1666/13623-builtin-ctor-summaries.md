**The facts model now summarizes the builtin constructor families it was missing: `AggregateError`, `Date`, `RegExp`, the typed arrays and `ArrayBuffer`/`SharedArrayBuffer`.** `ns_by_name` maps them — `AggregateError` splitting out of `Error`, the typed-array family plus `DataView` to `TypedArray` — which is what makes both spellings resolve, because `construct_named` consults that table before its own. `AggregateError` shares `Error`'s summary and models its `errors` field from the iterated first argument; `Date()` is `ToString`-shaped while `new Date()` is an object summary; `RegExp(re)` may hand back the regexp it was given, so that edge is added; typed arrays and `ArrayBuffer` get the `TypedArray` summary with its numeric-element field, a `ShareBuffer` edge from the source, and the `B4Resizable` hard fact when an `ArrayBuffer` is built with a second argument. A call that spreads cannot be read by fixed argument positions, so `new_builtin_ns` rematches the site with every fixed and spread value in each position it consumes. The branches for these names in `construct_named` were dead once the table mapped them and are removed; `ns_statics` covers the new variants, with `Date`/`RegExp`/`TypedArray`/`ArrayBuffer` deliberately left undescribed rather than claiming a precision the model lacks. Each summary is visible in the facts dump (`what: Date`, `RegExp`, `TypedArray`, `Error`, plus AggregateError's `errors` field) and the compiled program matches Node.
