A symbol is known by its GC header, not by a by-name fallback: persistent symbols live in one process symbol space, `globalThis` is an ordinary layout record whose builtin keys are image atoms, and the by-name symbol fallback (`req_handle_symbol_fallback`, `SMALL_HANDLE_SYMBOL_OWNER_EVER`, the `is_persistent_symbol` scans and the TEXT-entry exception) is removed. Symbol-keyed reads and writes use the layout slot like any other key, and a `globalThis` read of a builtin name is answered from the global object static layout. Atom registration no longer probes the builtin global index and reuses the probe vacant slot on a miss.
