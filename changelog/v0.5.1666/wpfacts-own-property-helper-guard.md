Whole-program facts: an own-property test made through a helper function guards the read. `function has(o, k) { return hasOwnProperty.call(o, k); }` followed by `has(o, k) && o[k].m()` (also in a conditional, behind `!has(o, k) ||`, with `Object.hasOwn` inside, through a value alias of the helper, a closure, or a body the solver summarized) reads the object's own properties only, exactly as the test written in place does. The helper is recognized from its body, not from its name. The read stays ordinary when the helper has a second return or other operands, tests another parameter, object or key, has default parameters, is async, a generator, bound or only declared, when its binding or a parameter is reassigned, when the callee may be another function, when the tested built-in was replaced, or when anything runs between the test and the read.
