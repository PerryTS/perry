`push` on a frozen, sealed or non-extensible array now reports the first `Set` that fails, as node does: `Cannot add property N, object is not extensible` with arguments, and the read-only `length` error for a frozen array with none. `Object.isFrozen` and `Object.isSealed` of a manually locked array that carries named or `length` descriptors are now true, and `Reflect.ownKeys` of such an array lists `length` once.
