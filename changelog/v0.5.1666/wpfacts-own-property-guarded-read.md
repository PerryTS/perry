Whole-program facts: a computed read `o[k]` that runs only after an own-property test of the same object and key (`hasOwnProperty.call(o, k) ? o[k] : …`, `&&`, the first thing an `if` branch runs; `o.hasOwnProperty(k)`, `Object.hasOwn(o, k)`, `propertyIsEnumerable.call(o, k)`) reads the object's own properties only, so it no longer yields the inherited `constructor` or the `Object.prototype` methods. The read stays ordinary when the test may be another function, the key may be an object, or the object is not a plain program object.
