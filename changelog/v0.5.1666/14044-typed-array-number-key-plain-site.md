A Number-key store into a typed array or Uint8Array reached through an array-typed binding or parameter (`function f(a: number[]) { a[i] = v }` called with a `Float64Array`, `Int32Array`, `BigInt64Array` or `Buffer`) is stored with the typed array numeric [[Set]]: it was dropped, or threw a wrong TypeError. A non-index Number key (`1.5`, `NaN`, `-1`) coerces the value and drops the store, as in Node.
