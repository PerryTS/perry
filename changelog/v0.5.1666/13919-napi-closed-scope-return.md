A Node-API function that closes its own handle scope before it returns the object it built there (node-addon-api's `Napi::HandleScope` shape) returns that object instead of `undefined`: closing a scope releases its handles for reuse, and a handle stays readable until a new handle takes its slot, as under V8. A returned handle that no longer reads throws `ERR_INVALID_RETURN_VALUE` instead of becoming `undefined`.
