The Map, Set, String and RegExp String iterator prototypes are locked in a compiled program, like the Array iterator and generator prototypes (DEC 250): replacing, redefining or deleting their `next` or `@@toStringTag` is a TypeError; adding a new member is allowed. Whole-program facts read their `next` as the builtin, so a value iterated with for-of over a Map stays known when the program stores to the `next` of an unknown object.
