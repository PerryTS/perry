HTTP/2 sessions now behave like Node on the wire for SETTINGS and PING. A SETTINGS frame carries only the options the caller named (a default server and client send an empty frame), any HEADER_TABLE_SIZE is honoured, localSettings change when the peer acknowledges and the handshake acknowledgement emits localSettings, and the settings and ping callbacks receive the measured round trip. ping() validates its payload and callback, and a PING acknowledgement with no PING outstanding fails the connection with GOAWAY(INTERNAL_ERROR). The turnloop HTTP/2 core now receives PUSH_PROMISE and can send one; a client leaves push enabled and declines every promise with RST_STREAM(CANCEL) until pushed streams have a JavaScript surface.
