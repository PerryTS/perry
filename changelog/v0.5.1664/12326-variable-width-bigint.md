Fix Effect 4.0.2 startup failures caused by Perry's signed 1024-bit BigInt limit. Its arbitrary generators initialize `BigInt(Number.MAX_VALUE)`, that value plus `1n`, and `1n << 1024n`; these are valid JavaScript integers. The first throw came from `bigint/convert.rs::limbs_from_integer_f64` through `magnitude_fits_1024`; `arith.rs::js_bigint_add` and `bitwise.rs::shl_checked` imposed the same signed-width rule.

BigInt constructors, arithmetic, comparisons, shifts, wrapping and conversions now share arbitrary-precision arithmetic and a variable-length two's-complement payload owned entirely by the GC allocation. This removes the fixed-width overflow rules and the special case for comparing Numbers beyond that width. Hashing, N-API, thread transfer, serialization and FFI consumers preserve every limb; explicitly narrowing APIs still read the low word. No persistent cache, side table or external allocation ownership is added.

Regression coverage includes the Effect reductions, wide literals and retained values across GC, arithmetic and signed wrapping, Map keys, narrowing APIs, transfer/N-API/FFI round trips, and negative controls for coercion and operator errors.

Validation on qb6 against Node 26.5.1: Effect 4.0.2 and 4.0.0-beta.83 schema construction/decoding and schema-record match, as do Zod, TypeScript, qs parse/stringify, buffer and worker drivers. The original timed Effect driver matches after normalizing only its elapsed-time fields. All 14 selected BigInt gap tests, 56 default runtime tests, 58 runtime tests with N-API enabled, and 5 FFI tests pass; the negative control also passes on pristine main. Two GC-stress seeds retain 4,000 wide values through 12,008 copying collections each. No second Effect wrong-output wall appeared.

Off-lock, interleaved n=3 instruction checks with `PERRY_LL_RS4GC_MAX_INSTRS=2097152`: Effect beta.83 −0.028%, Zod −0.038%, TypeScript −0.011%, buffer −0.0005%, worker −0.008%. RSS was checked alongside full-collection counts. THP-off and smaps sampling identify file-page placement, huge-page rounding, and worker scheduling noise; worker same-binary instruction spread reaches 0.68%. File-size, formatting and Node-version checks pass. Address-class and runtime-root-holder inventory checks fail identically on pristine main, with no new findings.
