**V8 heap snapshots now include the image strings they can reach.** The snapshot enumerates live objects by walking the nursery and old-gen allocators, and image strings — real GC-headed `GC_TYPE_STRING` cells marked `STRING_IMAGE_MARKER` — live in linker-owned memory that neither walk can enumerate. Live literal values and every edge pointing at them were silently missing. A snapshot-local pass now follows the traced slots of the nodes already collected and admits tracked string images into the snapshot's own node index, before labels and edges are assigned, so a string referenced twice becomes one node with an edge per reference. No runtime registration or new root scanner is added, and the cells are read, never rewritten. The regression asserts exactly one node for a string shared by two array slots and at least two edges to it; with the pass removed the string is absent (`left: 0, right: 1`).
