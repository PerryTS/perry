Arrays carry their named properties in an ordinary layout holder through the new ArrayHeader.named word. Creation-point value flow declares fixed named slots, including NodeArray properties, without producer-name checks. The holder replaces the four named storage modes and the address-keyed full-array table; element descriptors are layout facts, independent of named attributes. Array iteration reads only its own or Array.prototype Symbol.iterator slot when the program can write it. The iteration latch, shape-pair memo, prototype proofs and array/element loop regions are removed. Array copying operations copy elements, with bulk copying retained for the intrinsic dense walk.
