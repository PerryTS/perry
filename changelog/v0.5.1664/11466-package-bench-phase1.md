**bench(packages): Phase 1 package-performance harness + first report.** `benchmarks/packages/` holds 50 workloads over 26 npm packages whose native bindings were removed (axios, pg, mysql2, mongodb, redis, ioredis, jsonwebtoken, uuid, nanoid, validator, qs, dotenv, commander, lru-cache, dayjs, date-fns, moment, cron, node-cron, exponential-backoff, decimal.js, big.js, bignumber.js, node-forge, fastify, rate-limiter-flexible), with exact version pins, plus two controls. `scripts/package_bench.py` compiles them with Perry, checks liveness (package compiled natively per the SBOM, no removed-binding symbols), requires byte-identical output to Node on every measured run, and measures instructions (`perf stat`) and wall-clock per iteration with a two-N method, plus cold start, RSS, binary size and compile time, against Node 26.5.1 and Bun 1.3.14. It starts and stops its own database/HTTP servers and serialises measurements through a shared host mutex (`/tmp/perry-bench-lock.d`). First results on main `36420d2e56` are in `benchmarks/packages/REPORT.md`; the run filed #11446, #11447, #11448, #11449, #11450, #11459 and #11460. Not wired into CI.
