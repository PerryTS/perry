Facts dump (`PERRY_FACTS_DUMP` only): a complete per-site ledger input. The lowering writes `<dump>.census`, one line per source member read, element read, call, `new`, member write, update and delete with the HIR variant it lowered to, so folded and specialized sites keep a source identity. Member writes (`PutValueSet`, `PropertySet`, `IndexSet`, updates) carry dump-only source spans and get site records. Each analysis mode adds a `<census>` unit: a HIR walk per site kind compared with the recorded sites, and a record for every HIR site no analysis walked. Every open operand of a site names the first unknown value on its proof path from a closed list of causes (unit edge, escaped parameter/receiver/field, intrinsic prototype store, opaque builtin, computed key, module namespace, external input, dynamic code, ...), with its root node, root function and seed text; legacy verdict records name the obligation they failed. With the dump off nothing is captured: native images and fact fingerprints are unchanged.
