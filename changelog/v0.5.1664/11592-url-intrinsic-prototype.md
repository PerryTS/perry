**A native URL links to %URL.prototype%, not to whatever `globalThis.URL` currently is (#11585).** Since a9c6b0202 moved `href`/`hostname`/… onto `URL.prototype`, `create_url_object` looked the prototype up through the global `URL` binding, so a module-level `function URL` shadowing it made every native URL inherit the user function's prototype and read its components as `undefined` (`test_issue_5912_url_new_local_shadow`). The builtin's prototype is now recorded when it is built and used directly.
