Megamorphic reads of object literals are confirmed by their slot guess again. The static-shape seed unit runs before any module's string pool, so the key lists it built for literal shapes held their own strings instead of the pools' key atoms, and the megamorphic read's one-pointer confirm never matched a seeded literal: every such read fell to the by-name walk (lead_mega1 225.8 -> 435.8 instructions per read after link-time ShapeIds). The seed now mints the atom of each key name before building the list, exactly the atom the pool later finds, so a seeded list holds the same strings as one written after the pools ran.
