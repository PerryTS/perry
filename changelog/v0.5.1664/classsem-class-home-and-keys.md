Native construction with a distinct new.target includes weak collections, and prototype lookup respects their actual subclass link independently of the weak brand.

Add unit coverage for lexical homes, TDZ and raw key distinction.

This preserves the ordinary bind path while keeping exact computed keys. Member ordering uses one shared sort followed by deduplication, and direct lexical homes use the shared holder operation without adding site caches.
