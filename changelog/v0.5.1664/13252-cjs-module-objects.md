CommonJS plumbing is compiler-owned. Each program gets one generated support module (`perry:cjs`), imported first by every wrapped module. It holds `require.cache` as an object whose keys are the graph's module paths (each absent until its module loads, null prototype), the main record, and the shared loader helpers. Module records are object literals with one layout, and each module's `exports` is born with the names the module assigns as declared keys. The wrapper's own `require.cache[<path>]`, `module.exports`, `parent` and `children` reads, a module's own `exports.X` reads and the export snapshots become proven single loads. No CommonJS state lives on `globalThis`. Reassigning `require.cache` no longer redirects loading, matching Node, whose loader reads `Module._cache`.
