Ordinary constructor functions reserve their straight-line own-property slots at birth using an immutable optional tail on the function body information. Slots stay absent until stored, while the instance retains the actual live prototype and normal constructor return/new.target behavior. Symbol keys bind to the existing rooted program values, including cross-module aliases and Symbol.for identity; unresolved bindings retain ordinary construction. Checked symbol stores prove the current family word and fixed-position key and preserve inherited setters, descriptor edits, deletion/reinsertion order, borrowed calls, and right-hand-side effects. The ordinary shape carries the checked prototype identity; a different current prototype takes ordinary construction. Small instances retain the ordinary inline capacity floor, and later keys use normal shape growth.
