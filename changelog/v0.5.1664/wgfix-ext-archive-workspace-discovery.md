Fix source checkout discovery when Perry is built with an external `CARGO_TARGET_DIR` and run outside the checkout. The compiler records its build workspace and uses it as a fallback only while it remains a Perry workspace at the compiler's version. This lets auto-optimize build missing extension archives, including `node:http`, with runtime and stdlib without requiring `PERRY_WORKSPACE_ROOT`. Installed compilers ignore missing or mismatched source hints and report how to supply matching extension archives.
