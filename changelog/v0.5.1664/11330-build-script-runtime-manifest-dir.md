**fix(build): read `CARGO_MANIFEST_DIR` at build-script run time.** `crates/perry/build/android_template.rs` used `env!("CARGO_MANIFEST_DIR")`, which bakes the path in when the build script is compiled. Cargo reuses a compiled build script across checkouts that share a target directory, so after the checkout that compiled it was deleted, every later build panicked at `build.rs:5`. The build script now reads the variable at run time.
