- perf(runtime): the universal method dispatcher's own-override check no longer looks up `globalThis.Function` by name on every dispatched call (#10497, #10502). `%Function.prototype%`'s identity is memoized per realm as a third row of the per-thread intrinsic-prototype cache (`array/prototype_addr.rs`), which the registered root scanner rewrites and forwarding-chain healing keeps current. The cache is primed at the end of `populate_global_this_builtins`, so reassigning the writable `globalThis.Function` no longer changes what the runtime treats as Function.prototype. On `main` that reassignment broke `getPrototypeOf`, `hasOwn` and dispatch through the real intrinsic. The own-override predicate now uses the canonical interned key instead of allocating one per call (the runtime half of #10957). The own-override site only builds its argument vector when an own user method exists, and it re-reads the receiver and arguments after resolving that method. The dispatcher now validates method names with a strict UTF-8 fast path. The object-literal `get`/`set`/`has` method probe is −22.3%.
