Closed World: a `var` declared at the top level of a body (the module's own top level, a CommonJS factory body, or any other plain function body) that is assigned exactly once, by its declarator, and that no reader can observe before the declarator runs is proven to hold its initializer's value at every read. Readers in other bodies receive the initializer's type as a binding proof through the body's one outer seed set (`typed_locals::outer_proofs`), which also carries Closed World 5d's capture proofs (equal facts stand, the narrower of two comparable facts wins, incomparable facts leave the binding unproven) and feeds both the lowering oracle and `FnCtx::typed_locals`; 5d's capture proofs therefore now pick the lowering too. An array literal, or an IIFE whose every return yields a never-written local holding one, proves `Array`, so qs utils' `hexTable[c]` in `encode` takes the array element lowering instead of the unknown-receiver keyed path.

The proof is a compile-time fact computed from the HIR (`collectors::definite_init`): the declarator is a top-level statement; there is no other write anywhere in the module (assignment, update, `with` fallback, or a direct-eval setter); and the code before the declarator neither reads the binding, names a function or binding that can reach a read (through calls, nesting, aliases, object literals, getters, `valueOf`/`toString`, Proxy traps, `module.exports`), nor creates such a closure anywhere but as a hoisted declaration. Exports reaching a reader (ES-module cycles), class members reaching a reader, script-global vars, and reads outside the declaring body disqualify. CommonJS `require` cycles are covered: a re-entered module can only reach what its earlier statements stored on `exports`. Element types are not claimed.

A proven array that only its own construction (appends) and element/`length` reads ever name is confined: no user code can hold it, so its guarded element reads test the sticky prototype-chain invalidation byte instead of calling `perry_array_element_kind` per read; it is emitted only in programs with an element-descriptor writer, the only programs that emit that query. A CommonJS table-read micro: -21.9% instructions; qs stringify +0.02% (an out-of-line `perry_array_index_normalize_i32` on `hexTable[c]` now that the read takes the array tier); zod and tsc unchanged.

`PERRY_DEFINITE_INIT=0` turns the facts off; `PERRY_DEFINITE_INIT_TRACE=1` prints every verdict; `PERRY_DEFINITE_INIT_SABOTAGE=<check>` is the negative control used by the `test_gap_cwvar_*` fixtures.
