- **fix(runtime): an object's overflow ("spill") slot could be skipped by the GC, so qs `parse` read stale values (#11550).** `spill_store_slot` treated the bits already in a slot as its old value, so that a pointer-over-pointer overwrite could skip the GC slot-mask update. The spill buffer's rounded-up tail past `length` is never initialized, though. When the leftover arena bits there were pointer-shaped, the first store into that slot skipped the mask update, and the collector never marked or rewrote the slot. A copying minor then left a from-space address in a live object, and a full collection freed the live value. Slots at or past `length` now read as holes, and raising the high-water mark hole-fills the gap it exposes. qs 6.16.0 `parse_nested` under `gc_schedule_fuzz.sh` with from-space protection: 181/200 seeds faulted on main, 0/200 with the fix, all with Node's checksum. qs instruction counts are unchanged (+0.014% / −0.07%). Witnesses: `test_gap_gc_11550_null_proto_spill_tail` loses values on the shipped default before the fix, and `test_spill_store_past_length_ignores_tail_garbage_11550` runs one planted copying minor.
