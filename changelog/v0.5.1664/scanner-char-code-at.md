Extend the existing checked `charCodeAt` emitter to runtime-proven strings from the untyped String dispatcher, removing its duplicate static-type admission. Unify the dispatcher's non-string miss with the existing guarded-builtin fallback, deleting the redundant per-site ordinary method cache and temporary `this` root. ASCII heap and short strings retain the same checked payload load; Unicode, coercing positions and custom non-string methods retain their existing dispatch and decoder semantics.
