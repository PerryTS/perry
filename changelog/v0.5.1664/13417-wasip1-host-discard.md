Add the opt-in `PERRY_WASM_DISCARD=1` build of the `--target wasip1` output, which imports `perry_host.discard_pages` so the runtime can hand freed, page-aligned memory (shrunk resizable `ArrayBuffer` tails, large freed blocks, arena blocks) back to the host; the default build still imports only `wasi_snapshot_preview1`. The reference preview 1 host implements the import with a `--no-discard` knob and call counters, and the import checker allows it by name and signature under `--allow-perry-host`.
