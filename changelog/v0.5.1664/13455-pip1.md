The Map get-then-set idiom (`m.set(k, f(m.get(k)))`, or `const cur = m.get(k)` followed by `m.set(k, ...)`) now probes the Map once: the `get` reports the entry slot and the `set` stores into it when nothing ran in between, the key bits match and the value is a plain number. Any call between them (user code, collection, delete, clear, growth) makes the set an ordinary `js_map_set`. 51-pipeline -11.1% instructions.
