Reduce private-member access costs for ordinary and fresh class evaluations (#10501). Cache qualified brand, field-marker and value names by scalar class/evaluation identity in a bounded per-thread cache. Warm marker and value reads use shape-validated field slots. Plain writable private-field slots use the existing inline/overflow store funnels, including their GC barriers; descriptor and exotic cases retain generic setter dispatch. Initialization and remaining writes reuse GC-rooted interned keys.

Brand checks, initialization checks and private accessor handling remain intact. Cache entries retain Rust-owned strings and scalar layout facts, so they neither retain class evaluations nor need rewriting during moving GC. Regression coverage exercises separate evaluations, eviction, receiver shape changes, foreign/uninitialized receivers and a warmed cache across copying collection.
