Bring cc startup back below the level before the element-kind word. The
per-slot init helpers no longer run the dense-prefix frontier row on every
slot of a fresh array. Each builder states the prefix once, when its fill is
done: key lists at their total, JSON arrays at their length (before, the
prefix stayed 0), the map result at its leading written run, and the HTTP
methods list at its length. The stream record fill lowers the prefix on a hole.
The descriptor hook now scans the edit keys for an array index before it
classifies the owner, so named installs no longer classify the owner. cc
--version runs 2.67M fewer instructions than main, 0.92M below pre-EK main.
