- **perf(runtime): Proxy trap invariants read the target property facts** (#13089).
After each get/set/has/deleteProperty trap, the trap-result invariant check re-reads the target's own property. It used to build a descriptor object and read its six fields by name, allocating a key string for each read: ~12,900 instructions and nine allocations per Proxy `[[Get]]`. The check now reads the descriptor authority's facts (the value or accessor pair and the attributes) directly. Only exotic targets (a nested Proxy, a String object) still read a public descriptor, now through a rooted handle. solid.js store reads run this check on every access. Witness: Proxy gets with an ordinary target use 82% fewer instructions. Gap test: `test_gap_proxy_invariant_target_facts.ts`.
