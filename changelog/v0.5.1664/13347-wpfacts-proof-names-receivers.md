Whole-program facts: a site proof now names the receivers it is over. A read
whose only receivers were closed markers with nothing beside them (a published
method no unit calls, or only the runtime calls) was counted proven over zero
receivers per unit; it is now a dead or primitive site, or the guarded body of
its class, as the whole program says. No emitted code read those proofs.

An escaped module namespace object is no longer writable by unknown code (ES
10.4.6): its keys keep what its module's bindings hold, so calls through an
escaped namespace stay proven in the whole program (effect 3,730 -> 3,878).
