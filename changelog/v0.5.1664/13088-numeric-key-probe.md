- **perf(runtime): integral Number keys on arrays and objects read by atom** (#13088).
A computed Number key that is not an array index on an Array (`arr[arr.length - 1]` on an empty array reads `"-1"`) and an integral key on an ordinary object (`record[id]`) used to be formatted into a new heap string and matched by bytes through the complete by-name Get, at ~10,700 instructions per read. The key text is now formed on the stack and read by its atom from the receiver layouts, the same way an emitted `obj["-1"]` site reads it. An index text takes only an answer the probe finds, and anything the probe declines still takes the complete read. Witness: `a[a.length - 1]` reads on empty arrays use 89% fewer instructions. Gap test: `test_gap_numeric_key_named_read.ts`.
