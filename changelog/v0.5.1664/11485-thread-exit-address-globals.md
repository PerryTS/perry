- **runtime/stdlib: process-global tables forget an exiting thread's addresses (#11471).** A process-global table keyed by, or holding, a heap address outlived the thread whose arena owned it. After `Arena::drop` freed the blocks, another thread reused the addresses and the stale entry described a different object. #11319, #11462 and #11463/#11467 were three instances, each found by chasing a flake. An audit of every mutable process-global `static` in perry-runtime and perry-stdlib that can hold a 64-bit word (805 candidates, 234 of them counter-only atomics) found 83 more tables of the same shape. Examples: `SYMBOL_PROPERTIES`/`SYMBOL_POINTERS` (a new object at a reused address inherited a dead worker's symbol properties, or read as a Symbol), `OBJECT_PROTOTYPES`, `DOM_EXCEPTION_ERRORS` (a reused address passed `instanceof DOMException`), `CRYPTO_KEY_REGISTRY` and the external buffer registries, the Web Streams, zlib and worker registries, the stdin/readline/TLS/async_hooks/v8 listener tables, `GLOBAL_THIS_PTR`, and the child_process/pty/dgram/native-async reactors, which also kept the event loop alive for a dead thread.

  New mechanism: `arena::thread_exit`. `Arena::drop` and, new, `MallocState::drop` (for `gc_malloc` blocks such as `Symbol()` headers) report the ranges they are about to free to `release_freed_ranges`. That calls one hook per perry-runtime table and every hook registered with `register_thread_exit_range_hook`, which is how perry-stdlib tables participate. `FreedRanges::holds_bits` decodes both NaN-boxed and raw addresses. `HANDLES` payload types register per-type releasers through `register_handle_payload_releaser`. A few statics that held a handle into a per-thread table were made per-thread instead, or are released at agent retirement: the diagnostics_channel console channel ids, `Buffer.poolSize`, and the turnloop signal subscription ids.

  Gate: `scripts/thread_exit_address_globals.py` (in `lint`) enumerates the candidates and requires a thread-exit verdict for each one in `scripts/thread_exit_address_globals.json`. It fails on an unclassified static, a stale entry, or a `thread_exit_invalidated` verdict whose hook no longer runs at thread exit. `--self-test` plants each shape. Regression tests are in `crates/perry-stdlib/src/runtime_thread_exit_tests/`, one per fixed table where feasible. Each one populates the table from a spawned thread, asserts the entry exists while the thread lives, joins, and asserts it is gone. Each test was also run with its hook disabled and failed.
