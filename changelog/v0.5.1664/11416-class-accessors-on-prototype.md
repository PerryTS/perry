Class `get`/`set` members are real accessor properties on the class prototype object, and an ordinary object's accessor pair lives in its key's slot. Reads and writes of inherited class accessors are served from the inherited-access table (the holder's slot holds the pair), so the per-thread `(class id, ShapeId, key)` accessor cache from #11348 is removed, and reflection (`getOwnPropertyDescriptor`, keys, `in`, `hasOwnProperty`, for-in) reads the real properties instead of synthesizing them. Writing to a getter-only accessor now throws a TypeError in strict code and is ignored in sloppy code, as in Node; `"#x" in obj` no longer reports private accessors as public keys.
