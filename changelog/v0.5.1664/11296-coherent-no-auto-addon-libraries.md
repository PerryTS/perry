Fix no-auto-optimization builds of Node-API addon programs that also link the stdlib. The runtime, stdlib, and linked well-known wrappers now rebuild in one Cargo invocation with Node-API support, preventing a prebuilt stdlib's non-host `js_process_dlopen` stub from winning the link. Requested WebAssembly support and the HTTP client pump are preserved in the same build, and rebuilt wrapper paths replace their prebuilt counterparts.

Three regression tests exercise the production resolver with real miniature Cargo workspaces, rejecting missing features and prebuilt decoys before linking and running C executables with stdlib first. All three fail independently before the fix and pass after it. Existing tests for runtime defaults, shared HTTP builds, and prebuilt-wrapper selection also pass. No version bump.
