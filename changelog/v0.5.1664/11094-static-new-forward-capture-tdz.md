- **fix(codegen): a `new C()` in C's own static initializer no longer throws a spurious TDZ ReferenceError for a capture declared after the class (#11086).** For a class nested in a function, `new` appends the class's captured outer locals as trailing ctor args. When that `new` runs during class definition (`static readonly BASE = new Point(...)`) and a method captures a `const` declared after the class, the forward read the still-dead-zone box and threw `Cannot access 'wnaf' before initialization`. This is the `@noble/curves` `weierstrassPoints` shape, which `new ethers.Wallet(pk)` hits. `lower_new` now lowers the `cap_args_appended` forwards inside the `js_tdz_suppress_begin/end` window that the decl-site capture snapshots already use (#6052/#6523). Methods still see the live binding once it is initialized. Regression test: `test-files/test_gap_11086_static_new_forward_capture.ts`.
