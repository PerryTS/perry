Make the thread-exit custody gate green again by reconciling `scripts/thread_exit_address_globals.json` with the collector and namespace work that moved under it, and by re-auditing the one contract that needed it (#11471).

Four independent defects, none of them a live bug:

* **Nine stale entries** in `gc/instruments.rs`. `#13443` moved those counters behind the crate-local `Counter` wrapper (`static STEP_MAX_US: Counter = Counter::new()`), so their declarations are no longer `AtomicU64` scalars and rule 2 no longer enumerates them. The exemptions outlived their subject.
* **`symbol.rs:NEXT_SYMBOL_ID`** — its entry is gone because the gate now discharges it mechanically: every mention is a `load`/`fetch_add` and nothing borrows it.
* **`turnloop_pool/mod.rs` `CANCELLED` and `REFUSED`** — two pool lifetime totals, initialized to zero, written only by `fetch_add(1)` and read by `load`. They were not discharged mechanically because both names also appear as property-name identifiers inside the `realm_decl!` block for `node:dns` / `node:dns/promises` in `object/namespace_create.rs` (`CANCELLED = "ECANCELLED"`). Rule 2 is crate-wide and name-based on purpose, so it keeps them as manual candidates; the two `no_heap_address` verdicts are the review that asks for, and they record the collision so the next reader does not have to rediscover it.
* **`arena/region.rs:REGIONS`** — the `allocation_lifetime` contract needed a real re-audit, not a re-hash. `#13463` changed the registry's value from a bare end offset to `BackingExtent { end, alignment }` and `#13463`/`#13479` made `arena/young_large.rs` a boundary caller by allocating large-object backings through `region::map`. The custody claim still holds: `region::unmap` removes the start key from `REGIONS` before any physical release, with a `debug_assert_eq!` on the extent length between the two, and `young_large`'s release path (`release_arena_block` → `region::unmap`) keeps removal ahead of release as well. `young_large.rs` is now a pinned source, so the next change to it forces the same re-audit.
