- **perry-codegen**: an object literal's shape no longer takes another module's class prototype, and the TUI of the natively compiled OpenCode v1.18.30 no longer aborts at startup with "the static ShapeId ... was refused by the shape mint". Anonymous literal births now pass class id 0 to their shape mints, as the startup literal seed does; passing the anonymous class's own id broke whenever that per-module id collided with a declared class elsewhere.
