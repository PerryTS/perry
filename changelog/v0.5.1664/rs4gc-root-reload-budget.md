Reduce precise-root reload IR by keeping the managed pointer as the input of the existing tied-register barrier. This lets large native functions fit the default statepoint instruction budget without increasing the cap or weakening moving-GC rooting. Use the existing rooted byte-view receiver for identity checks instead of retaining an unrooted address, and invalidate the existing byte-view proof at each lexical binding so immutable views need no redundant identity check between bindings.
