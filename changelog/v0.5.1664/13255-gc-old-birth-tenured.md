fix(gc): objects born in the old generation are TENURED by construction. `arena_alloc_gc_old` (hole reuse and bump, the promotion path and the excluding-pages variant) stamped only ARENA, so the write barrier's parent gate took born-old objects for young ones and never recorded a young pointer stored into them; the next minor collection could free the young object (a property overflow and its names, a promise's continuation, a native pod's owner) while the old object still pointed at it. Both old allocators now set ARENA | TENURED on every path and the manual stamps are gone. New tests cover every old birth path and move an old receiver across remembered-set pages.
