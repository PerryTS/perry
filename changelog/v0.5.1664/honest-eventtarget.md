EventTarget, Event, CustomEvent, AbortController and AbortSignal use shared prototype methods and accessors, with state in ordinary symbol-keyed shape properties. Reflect exposed symbols like Node and keep private state hidden. Preserve DOMException Error semantics, subclass prototype inheritance and named worker-transfer rejection. A built-in global with no intrinsic static surface keeps its receiver, so `Event.NONE` and `DOMException.ABORT_ERR` read the constructor object itself. An `instanceof` miss on an object whose own prototype is materialized is final.
