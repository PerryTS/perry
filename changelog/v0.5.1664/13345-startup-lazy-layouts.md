Faster startup for small programs. The runtime no longer builds its own object layouts (iterator results, stream, server, URL and timer records, ...) before `main`: each is installed when the first such object is born. The fixed transition caches (about 1.1 MB per thread) are mapped on first use instead of being allocated and zero-filled at thread start, the atom table is sized once, the `Math` namespace object is linked only when a program actually reads it (a `console.log` call no longer counts as `Math.log`), and the main thread leaves its runtime state to the OS at exit. Hello world on macOS arm64 starts in 2.33 ms instead of 2.95 ms (20.4M instead of 22.6M instructions, 184 instead of 203 dynamic imports, max RSS 5.3 MB instead of 6.0 MB); on Linux x86-64 its runtime does 0.87M user-mode instructions instead of 1.81M.
