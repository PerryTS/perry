String-method argument coercions share out-of-line runtime entries instead of duplicating tag guards at every dynamic call site, and omit coercion for proven numeric and string representations. Index operations fuse coercion and integer conversion; charCodeAt retains its existing inline conversion without an eager helper call. The coercing index entry converts once, without rechecking the already-coerced scalar; tagged inputs go through the existing ToNumber authority, including legacy constructor values sharing the int32 tag. Spec order, rooted argument re-reads before receiver access, and protection of string results across later coercions are preserved.

The root checker recognizes paired checked/body export declarations generically, keeping the new checked string entries visible to archive and call-effect audits.
