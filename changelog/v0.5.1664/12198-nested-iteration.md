Fix nested collection loops throwing when an enclosing array loop uses a replaced Array.prototype[Symbol.iterator]. Function-body lowering now passes the array guard's forced protocol mode to that statement alone, matching module-body lowering. This removes the ambient lowering-context flag that incorrectly made nested Set/Map/typed-array drivers step the collection itself as an iterator; nested loops now choose their own existing driver. The regression includes an async boundary and a forwarding array iterator, as in OpenCode's prompt-conversion path.
