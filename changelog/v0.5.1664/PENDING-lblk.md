Labeled blocks (#12662, #12663): an unlabeled `break`/`continue` inside a labeled non-loop block now targets the enclosing loop or switch, not the block's lowered run-once do-while. The lowering rewrites such a jump into a labeled jump to its real target. A user or synthetic label on a for-of is attached to the loop inside the iterator-close `try`, so `continue label` no longer closes the iterator early (and skips the close on the real exit). The Number-at-read flow joins every `break`/`continue` at its target; it ignored them, so `blk: { if (k) break blk; v = x * 1.5; } return v + 1` printed undefined instead of NaN.
