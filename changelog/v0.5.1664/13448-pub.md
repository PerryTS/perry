wpfacts: per-unit facts publish callable identities to closed callees and the arguments their runners pass (DEC223, DEC224). A function handed to a known closed callee keeps its identity through that callee's contract; each unit that runs it publishes the join of what it passes, which stands beside the parameter markers, while an undescribed position, an escape beyond publication, a unit over the work bound or a census break keeps the parameters unknown. Passed closed module functions publish through DEC19, an absent ordinary caller contract is no input, escaped results beside unknown normalize independently of arrival order, and contract-published functions stay described beside unknown results. Facts dumps gain publication-route records and a verdict per function copy. A class accessor thunk stores its code address without touching the closure layout, so linking no longer decides whether a startup closure takes a layout transition.
