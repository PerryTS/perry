- **perry (compile)**: a namespace import no longer lets a member named like a global intrinsic shadow that global in the importer. `import * as Arr from "./Array.ts"` registered `Arr`'s `Array` member as a bare-name fallback, so the importer's own `new Array(n)` constructed the member instead of the builtin — `undefined` results, and a link failure in the OpenCode v1.18.30 build, whose effect modules all do this (#10945). Bare-name fallback entries now skip global-intrinsic names, as #10356 does for classes; `Arr.Array` still resolves.
