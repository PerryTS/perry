**Doc-tests install the npm packages the examples compile from source (#11560).** Since the uuid / nanoid / validator / fastify native bindings were removed (09-19), `stdlib/utilities/snippets.ts`, `getting-started/npm_packages.ts` and `stdlib/http/fastify_json.ts` import packages that must be compiled from their real source, but the doc-tests job never ran npm and uuid / nanoid / validator / mysql2 were not root devDependencies, so the imports stayed unresolved and the link failed on `_uuidv4` / `_nanoid` / `_fastify`. They are now root devDependencies (all versions past the 7-day soak window) and the job runs `npm ci` before the examples.
