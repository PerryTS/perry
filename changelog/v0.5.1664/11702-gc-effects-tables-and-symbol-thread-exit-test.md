- **fix(gc-effects): regenerate the macOS-aarch64 and Windows-x86_64 GC call-effects tables after #11682** (#11695). #11682 regenerated only the Linux table. On the other two targets, `js_abort_controller_signal`, `js_abort_signal_is_aborted`, `js_abort_signal_throw_if_aborted` and `js_error_is_error` were committed `Leaf`/`ThrowOnly` while their archives prove `Reenters`, so codegen could skip a statepoint the runtime needs. The tables are the CI artifacts from main run 36653831017. They also pick up the new `js_event_target_subclass_init` and the pre-existing safe drift.
- **test(stdlib): keep the symbol thread-exit probe live** (#11696). Since #11682, ordinary objects keep their symbol properties on the object (`shaped_symbols`), so the address-keyed side tables are empty for them. `thread_exit_releases_the_threads_symbol_side_table_entries` now checks table release on an array holder and a class static. It asserts that an ordinary object's symbol value, attrs and accessor live on the object, using the new `symbol::symbol_on_object_for_test` probe, and never in the tables. Both halves were sabotage-checked red.
