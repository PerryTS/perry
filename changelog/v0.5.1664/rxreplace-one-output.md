String.prototype.replace and replaceAll build every result in one native output, for string and RegExp patterns, templates and callbacks alike: pieces are copied as they are appended (a surrogate pair split across two pieces is joined), the result is allocated once, and nothing is traced or read twice. The empty-replacement special case is gone; it falls out of the same path. A builtin RegExp replace no longer arms a trap or stores lastIndex per search: no user code runs between searches, so only the final lastIndex is written. Templates are parsed once per replacement, and literal ASCII patterns are searched over bytes.
