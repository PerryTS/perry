Ordered Linux function layout removes forced huge-page segment alignment and padding inside text. Startup backs only complete aligned 2 MiB pages inside the selected prefix after PIE relocation; smaller prefixes return before policy I/O, copying or collapse. Partial boundary pages stay file-backed. The mapper also removes its extra strstr/mremap dynamic imports, using one bounded policy scan and the existing syscall entry. Generated and native runtime code share one order, with no execution tier or GC change.
