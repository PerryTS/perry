`perry compile --source-root <DIR>` (or `PERRY_SOURCE_ROOT`) bakes module paths relative to a root instead of the build directory: `__dirname`, `__filename`, `import.meta.*`, `require` bases and `require.cache` keys, stack-frame labels and runtime error text name `<target>/<path under the root>` (`--source-root-target`, default `/`), so builds are reproducible and carry no absolute build path. Compile-time file access is unchanged, and without the option the output is the same as before.
