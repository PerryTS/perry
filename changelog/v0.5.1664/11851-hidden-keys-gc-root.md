- **fix(stream): root the `HIDDEN_KEYS` key cache (#11851).** #11828's per-thread cache of longlived hidden-field key strings (`node_stream_readwrite.rs`) stored raw addresses, and nothing scanned it. A full mark-sweep reclaims unmarked longlived objects (`gc/oldgen/sweep_objects.rs` `process_object`), so after the last stream using a key died, `hidden_key()` could hand out a reclaimed string. Each thread now registers the `node_stream_hidden_keys` mutable root scanner on its first key, which marks and rewrites every cached address. The hit path stays allocation-free. Also converts the 8 raw-handle debt sites #11828 added in that file to `with_{mut,const}_ptr`. New tests in `gc/tests/runtime_roots/hidden_keys.rs` cover mark, rewrite and registration + `gc()`.
