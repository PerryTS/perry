Reuse ordinary data shapes throughout descriptor reflection and object copying. Plain record allocations carry the already-resolved ordinary birth shape instead of reminting it. Reflection resolves each ordinary key once for presence, attributes and its data/accessor slot. `getOwnPropertyDescriptors` and `defineProperties` share rooted key snapshots taken directly from default data shapes, bounded by the shape's own prefix count and validated at every use; reflection results are born with that complete key list. Descriptor decoding uses the shape's data and prototype facts instead of reclassifying the receiver through registries. Complete default data definitions use the existing shape-owned CreateDataProperty mechanism, and Object.assign's prototype preflight omits lists whose shape proves all keys harmless.

Unify byte-view copying and Proxy target copying with Object.assign's existing descriptor-driven enumeration and strict Set flow. This fixes dropped symbol properties on byte views and skipped Proxy target traps. Integer ordering, descriptor field presence and decode-before-apply, getters/setters, symbols, restricted targets and moving-GC roots remain part of the shared mechanisms. No cache, registry, name-based witness check or second descriptor validation gate is added.
