Package enumeration terminates on workspaces whose members are symlinked into each other's `node_modules`. The walk now tracks the canonical path of every directory it has entered, so a symlink cycle is visited once instead of forever; `perry compile` no longer spins in `Collecting modules...` on a pnpm workspace. Wildcard expansion still reports every installed package exactly once, and a path that cannot be canonicalized is walked under its literal path rather than skipped.
