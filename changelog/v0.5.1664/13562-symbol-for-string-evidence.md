**`Symbol.for` no longer dereferences raw bits on magnitude alone.** The raw-`StringHeader` arm accepted the address if `is_plausible_heap_addr` passed, and a subnormal double's bits are heap-plausible: `Symbol.for(1e-310)` read a `StringHeader` out of unowned memory and registered whatever it found as the key, instead of applying `ToString`. The arm now also requires `try_read_tracked_gc_header_of_type(bits, GC_TYPE_STRING)` — evidence that the address is an owned allocation of kind string — and everything else falls through to `js_string_coerce`, the full `ToString`. Regression coverage asserts the fixture is both heap-plausible and unowned before checking `Symbol.for(n) === Symbol.for(String(n))`, and keeps the legacy raw-pointer callsite working (its raw and boxed forms resolve to the same symbol). Without the guard the first test aborts the process rather than mismatching, which is the point: the read is of memory the runtime does not own.
