Property reads consume their existing holder proof for inline and spill storage. A direct accessor keeps its immutable pair's getter even when the lane is in spill storage; compiled getter sites load that lane and compare the pair before calling with the original receiver. Deep chains and setter-only pairs keep their collecting path. This removes repeated getter derivation for spilled accessors without changing the cache format or root traversal.

Computed reads consume a proven data or absent lane before generic Get. Saturated four-way sites reuse the dynamic dispatcher's plain own-slot proof, avoiding a fresh holder walk; other saturated reads retain generic Get. The proof and publication have no intervening collection or user code, so the handle scope and post-Get confirmation are removed. Wide key lists use the existing content-validated shape index without an initial linear word scan; small lists select the last public declaration. No new cache, latch, side table, or runtime name filter is added. Regression coverage exercises spill getter replacement, deletion, shadowing, throwing getters, symbols, saturated sites, and private/public name separation.

On an unsaturated miss, computed reads normalize a runtime string to the same existing atom identity used by publication and consume the shared entry before rebuilding its holder proof. This avoids repeated shape walks when `typeof` or another runtime operation supplies a string with the same contents and a different word. Atom normalization is moved from publication, without adding a lookup to identity hits.
