Fixed `require()` and `import` of subpath modules that have no dispatch bucket (`stream/promises`, `fs/promises`, `timers/promises`, `readline/promises`, `stream/consumers`, `stream/web`, `diagnostics_channel`, `trace_events`): their exports now run the real implementation (previously the call returned `undefined`), the namespaces are the same object however they are reached, `readline.promises` exists, and `new StringDecoder()` works through a namespace member. A call to a missing export now throws `TypeError: <module>.<name> is not supported`. The global `performance` value arms the `perf_hooks` dispatch bucket where it is named, so `const p = performance; p.now()` still runs in a program that never imports `node:perf_hooks` (such as a Worker module).
