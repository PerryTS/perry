Fixed drizzle-orm/mysql2 transactions hanging (or segfaulting) after a few hundred iterations (#9356). Three stacked defects on the `perry-ext-mysql2` path: native-async token promises were nursery-allocated, so a copying minor moved them under the worker's captured raw pointer and the worker settled a retired from-space address — token promises now allocate in non-moving malloc space; the stdlib pump never drained tokens settled through `JsPromise::resolve_with`/`reject_with`, leaking one registry entry (and one rooted promise) per query — the pump now drops the token when it settles; and a top-level `await` parked for the full 1 s idle budget on a promise that had already settled during the drain — the busy-wait loop now re-checks promise state after the tick phases and only parks while still pending.
