A computed property read, `Reflect.get`/`Reflect.has`, or `??=` on a native handle (`new Headers()[key]`) no longer boxes the raw registry id with the heap-only `JSValue::pointer` (the contract build aborted with `op=JSValue::pointer P=Heap`) and `handle[key] ??= v` no longer reads an array header from the id (SIGSEGV in every build). The by-name read ingress boxes its raw receiver with the unknown-word constructor, and the keyed setter classifies its receiver word with the canonical GC-header reader.
