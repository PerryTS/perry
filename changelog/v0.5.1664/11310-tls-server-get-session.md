- **tls: server-side `TLSSocket.getSession()` returns a Buffer (#11310).** `js_tls_socket_get_session` only consulted the client-side TLS metadata, so on a socket delivered by `tls.createServer`'s `secureConnection` it always returned `undefined`, where Node returns the serialized session `Buffer`. It now falls back to the server-side socket registry. Once the handshake has negotiated a protocol, it returns an opaque session stand-in derived from the certificate the server presented, the same shape as the client path's stand-in. Regression test: `test-files/test_issue_11310_tls_server_get_session.ts`.
