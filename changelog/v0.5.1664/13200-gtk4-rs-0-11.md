### Changed

- Upgrade the GTK4 backend to gtk4-rs 0.11 (`libshumate` 0.8, `webkit6` 0.6), so `glib`, `gio`, `cairo-rs` and `pango` resolve to one version each. Building `perry-ui-gtk4` now requires GTK 4.10 or newer (Ubuntu 24.04+, Debian 13+); Debian 12 is no longer supported for the GTK4 backend.
