Honest pointers: a `POINTER_TAG` word now always names a GC-headed object, either on the current thread's heap or in process-wide immortal space (image strings, leaked symbol cells). Native registry ids (Web Fetch, streams, timers, sockets, SQLite, TLS, x509, ECDH and every other stdlib or extension handle) travel under the distinct `HANDLE_TAG` (`0xFFF9`). A Proxy is a nonmoving GC cell boxed as `POINTER_TAG | addr` like every object; its brand is the header kind (`GC_TYPE_PROXY`) plus the cell's extent, so the bit-zero proxy tag and the collector's canonicalizing decode (`tagged_heap_addr`, `canonical_raw_receiver`) are gone.

- Constructors. `js_nanbox_pointer` and `perry_ffi::JsValue::from_object_ptr`, the constructors for words of unknown kind, box an id-band payload under `HANDLE_TAG` and zero as `null`; the id-band arm is out of line. `JSValue::pointer`, inlined at thousands of runtime sites, is the plain box of a GC-headed object again; contract-check builds abort on an id-band payload there. Stdlib and extension producers that OR-ed `POINTER_TAG` over ids by hand call the unknown-word constructors.
- Consumers that recognised ids by `POINTER_TAG` plus an id band check the tag (descriptors, `defineProperty`, prototypes, `instanceof`, `@@toStringTag`, `in`, symbol owners, Reflect, JSON, iteration, `apply`, Promise assimilation, return override, FormData/fetch bodies, WeakMap keys, the incremental store barrier, method sites, for-in). One `Type(value) is Object` predicate replaces eight hand-written copies.
- Provenance re-proofs on tagged values are deleted (census classes A and C2-kind). `addr_class::pointer_value_header` reads the header after one fused tag-and-null compare; `js_array_get_f64`, `js_packed_arraylike_index_get`, the `.length` leaf, iterator/spread sources, `js_jsvalue_equals` forwarding, builtin-receiver facts, `hasOwn`, own symbol slots, the data-get walk, the generic read/store lanes, strict dense stores, named-props words, native payload admission, typeof, return override and the compiled-code box entries answer from it. Re-proofs that an OBJECT header or an owned page already settles (closure tests after an OBJECT header, a live owner's re-admission) are removed. Raw untagged words keep allocator admission.
- `clean_arr_ptr` inlines only its honest tagged lane and raw arena lane; the forwarding walk, lazy materialization and buffer exceptions are one out-of-line resolver, and a non-array header is rejected without it.
- `PERRY_GC_VERIFY_MARK` in contract-check builds (`PERRY_CHECK_CONTRACTS=1`) and unit tests checks the invariant: every `POINTER_TAG` word in a live object's traced slots names a header on this heap or in immortal space, and no `POINTER_TAG` root carries an id-band payload. Release and ordinary instrumented builds carry none of the verifier.
- Raw-byte numeric ingress canonicalizes every NaN (typed arrays, DataView, Buffer, clone, OHOS callbacks, raw float lanes, FFI returns), so `JSValue::number` boxes the bit pattern and `is_number` and emitted numeric tests use the sign-closed tag band (`|bits| >= 0x7FF9…`), which excludes `HANDLE_TAG`. `test_gap_honestptr_negative_nan`, `test_gap_honestptr_nan_postmessage` and `scripts/run_honestptr_nan_ingress.sh` cover this.
- Kind-typed entry selection (step 4). A receiver the compiler itself constructed (`new Map(...)` / `new Set(...)`, or an immutable, never-written, non-TDZ local bound to one) is a kind proof by construction: `map.size`, `set.size` and the generic `map.get` call `js_map_size__Map` / `js_set_size__Set` / `js_map_get__Map` with no receiver check and the same arguments. The size entries are GC leaves, so those calls carry no statepoint. A declared `Map<K, V>`, a subclass instance or a reassigned binding keeps the checked receiver and the generic entry.
- One contract-check build. `PERRY_CHECK_CONTRACTS=1` while compiling emits the typed-element witness (`js_typed_element_contract`) and builds the runtime with the kind-entry assertions and the honest-pointer verifier; a run that asks for it from an unchecked runtime aborts. Every witness reports `[perry-contract] op=… P=… proof=… value=…` through one function. The knob is no longer a gc-instruments knob (that feature is on by default).
- Descriptor owners (#12513). `attrs_live_in_keys` decodes a header only for a word proven GC-headed by the canonical classifier: a `POINTER_TAG` word answers from its header, a raw address needs the allocator's proof, so a native `Box` owner whose preceding bytes look like an OBJECT header is no longer read as one.
- `delete` on a native handle and the nullsafe member-read fallback (`headers.payload`) admit `HANDLE_TAG` receivers.
- `js_nanbox_pointer` admits the common word, an address between the id band and the NaN-box tag space, with one unsigned compare; tagged words, null and ids take one out-of-line arm.
