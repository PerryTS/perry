Fixed inherited `Object.prototype` members being invisible to value reads and `in` on ordinary objects until a program explicitly touched `Object.prototype` or called one of its methods. An actual inherited lookup now materializes the realm global before resolving the intrinsic, with its receiver and key rooted across bootstrap. This preserves the lazy address lookup used by array writes while making `obj.toString`, `obj.hasOwnProperty`, and related presence checks agree with Node from the first access.
