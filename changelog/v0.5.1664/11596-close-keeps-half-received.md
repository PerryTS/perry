**`server.close()` keeps a connection with a half-received request (#11586).** Since the turnloop port (b77aba634) the HTTP/1 connection counted as busy only once a request head was fully decoded, so `close()` destroyed a client that had sent part of its head — Node (19+) closes idle keep-alive sockets only. Buffered, not-yet-decoded request bytes now count as busy, as the tokio implementation's `read_active` did. Fixes `test_issue_4971_tls_connect_options`; new gap test `test_gap_11586_close_keeps_half_received`.
