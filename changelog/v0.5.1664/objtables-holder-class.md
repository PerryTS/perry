Allocate collecting nonmoving holders in a dedicated old-generation block class, using the approved O1 policy. Map stores, Set stores and captured async-context holders remain subject to ordinary reachability, sweeping and thread teardown, while defrag and idle compaction exclude their backing blocks. Exact-fit hole reuse preserves the class in the existing free-list index; no per-object registry is added. The holder-class test checks collection, class-specific hole reuse and relocation selection, with a negative control that removes the class fact.
