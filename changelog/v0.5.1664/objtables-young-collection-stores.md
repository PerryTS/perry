Map and Set stores and AsyncLocalStorage snapshot holders are now ordinary young, movable GC objects instead of old-born nonmoving collecting holders, so a short-lived collection dies in a minor again (`new Map(); m.set(i, i)` x200k: old-gen in use back to 96 B, RSS 57 MB -> 17 MB). Each store traces its own entries; the header's `entries`/`elements` alias is re-derived by a rewrite hook when the store moves, and a move hook hands the native indexes to the copy. A copying minor releases the native buffers of the stores that died in from-space by walking the blocks' exact object-start bitmap; no registry is involved. Native handle property bags keep one bag per mutator on the native record, so another thread can set its own properties on a shared handle again, as with the former per-thread tables.
