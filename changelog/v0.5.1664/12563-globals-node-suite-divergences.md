Four `globals` node-suite divergences on `main` are closed, each with its own root cause — no fixture special-casing. The fifth of the seven named in #9202 (`globals/navigator-constructor-identity`) was already closed on `main` by #12556.

`String.prototype.replaceAll` with a non-global RegExp threw Perry's own wording (`requires a global RegExp`) from both of its rejection sites; node's message is `String.prototype.replaceAll called with a non-global RegExp argument` (node-suite `globals/string-replaceall-regexp-global`).

An array's per-index descriptor/attribute record lives in the array's own property bag, which is also where its NAMED keys come from, so `Object.defineProperty(arr, "1", …)` filed `"1"` there and every own-key enumerator reported the index a second time — `Object.keys([1,2,3])` after a non-configurable define on index 1 returned `0|1|2|1` where node returns `0|1|2` (`globals/json-parse-reviver-internalize`). The bag-backed list now drops the canonical indices the caller's element scan already reached, for `Object.keys`/`values`/`entries`/`getOwnPropertyNames` and `Object.assign` (`array_named_property_enumeration_names`); the sparse-index sweep that deliberately reads those records keeps them.

`addModule instanceof WebAssembly.Module` answered `false` for a module the runtime had built: the wrapper is an ordinary heap object whose shape answers `PROTO_ID_DEFAULT`, so `js_instanceof_dynamic`'s terminal-shape short-circuit owned the comparison and returned `false` from the `Object.prototype` walk before the wasm brand probe below it could run. The probe now runs first, still after the own `@@hasInstance` hook (`globals/webassembly-module-metadata`).

`strings.raw` on a tagged template read `undefined` while the own `raw` property resolved: installing that property materializes the array's property reserve, which relocates the array and leaves a forwarding stub at the address the cooked/raw pair was keyed on, while the read path resolves the receiver before the lookup. `install_template_raw_property` now returns the live head, which is what its own doc already promised (`globals/tagged-template-cache-freeze`).
