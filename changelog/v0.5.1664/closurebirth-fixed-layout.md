Closure birth now uses fixed intrinsic function ShapeIds seeded once in each agent's authoritative shape table. This removes the base-function and class-function TLS shape caches; prototype kinds, attributes and keyed/dictionary transitions continue to be shape facts. Added a capture-birth micro with one to three captures and a call-only negative control.

Compiler-created function literals now pass their known layout to shared birth helpers. One to three captures arrive in registers and are stored directly in the closure, avoiding the temporary capture buffer, memcpy, capture classification and per-birth body-kind selection. Larger capture ranges use the same fixed-header contract and one shared rooted collecting fallback; zero-capture literals pass their known intrinsic shape. Name/length properties and constant-function facts require no birth-time allocation or registration. Mutable capture cells retain their existing shared scope layout.

Compiled closure names now live as immutable relative byte ranges in the static body descriptor and are decoded only on reflection. The optional eight-byte name range leaves native descriptors and the per-closure header unchanged; existing code-address metadata remains for stack frames and native/legacy functions.

On qb6, interleaved n=5 instruction measurements against main reduce one/two/three immutable-capture iterations by 15.0%/16.6%/18.3% and mutable-capture iterations by 7.1%/6.4%/5.7%, with a flat call-only negative control. Factory text shrinks from 71/80/89 to 66/69/71 bytes for immutable captures; mutable factories grow by three bytes each while removing the boxed initializer call. qs stringify matches Node and uses 2.23% fewer instructions, with 21.4 KiB less emitted text and unchanged full/minor collection counts. Forced-moving capture and metadata checks cover identity, shared cells, lexical slots, name overrides and function kinds.
