### Fixed

- Fixed a flaky perry-stdlib test, `thread_exit_releases_the_threads_external_buffer_registrations` (#11547), which failed intermittently with "EXTERNAL_BUFFER_REGISTRY outlived the thread". The test checked the external-buffer registries for the dead thread's buffer address after `join`. By then a concurrently running test (`thread_exit_releases_the_threads_crypto_key_entries`) can be handed the same arena address and register it again. A sequenced diagnostic confirmed this: the release had removed the entry, and the sibling then got the identical address in 12 of 15 rounds. The release hook itself was fine. The test now records the registries' state from a thread-exit range hook that runs after their own release, while the block still belongs to the exiting thread. It reads them through the new thread-local-free probe `perry_runtime::buffer::external_registries_hold_for_test`. `external_buffer_verdict_is_taken_at_release_not_by_address` is a regression test that fails with the old address-only check. With the registry release removed, the fixed test fails every run.
