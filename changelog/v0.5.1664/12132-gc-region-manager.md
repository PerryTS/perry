GC arena blocks on Linux now come straight from the OS in 2 MiB-aligned regions, pooled per agent, instead of from the Rust global allocator; mimalloc keeps ordinary native allocations. Linux GC blocks are 2 MiB, and page size follows how much of a unit is used: complete 2 MiB units get huge-page advice in every generation, while sub-unit extents and tails stay on base pages. RSS drops 15–45% across tsc, Zod, qs, commander, fastify, Effect, buffer- and worker-heavy programs and upm, with system CPU within noise of main. A parse bump no longer lowers an already armed whole-arena GC trigger, which removed a minor-collection storm with larger blocks. Census bitmap capacity follows the block size, and the defrag selector decides from the allocation kind stored in the block.
