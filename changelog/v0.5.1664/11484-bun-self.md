Fix Bun platform `self` initialization and identifier resolution (#10306). Bun realms install a configurable, enumerable, replaceable accessor returning their global object, once per thread. Assigning or deleting it remains observable across later module initialization. Node main-thread reads continue to throw ReferenceError when no binding exists, while `typeof self` returns `undefined`.

Remove the lowering shortcut that treated `self.Math` as the global builtin regardless of the actual binding. Add lowering tests, a runtime bootstrap test, and a platform-specific parity fixture covering replacement, deletion, descriptors, lexical shadowing, and dynamic imports. Tighten four stale address-audit counts to match already-landed source changes; no new address exceptions are introduced.
