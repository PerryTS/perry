Fixed the `perry-runtime` unit tests, which stopped linking after named builtin imports landed. A function-info record declared through a macro from another crate got a linker name with different spacing from the one its importers used; record names are now spelled from the body path's identifier segments, so they no longer depend on which macro carried the declaration. The GC test fixtures now build closures with a function-info record, as the runtime always does, and debug builds assert that invariant where the native export checks read it.
