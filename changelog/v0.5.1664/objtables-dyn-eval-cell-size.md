The parsed-function owner is a compact collecting leaf cell holding one native `Rc<InterpFn>` (8 payload bytes on 64-bit hosts). Capture zero still owns it and full/minor marking follows that ordinary GC reference. Sweep releases the native reference once, without TLS, callbacks or GC allocation. This replaces the general FFI native-handle allocation, its 136-byte payload, debug metadata and separate `Box<Rc>` on each interpreted closure. It adds no cache or side table.
