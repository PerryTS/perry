**fix(compile): `require.resolve` keeps the `@parcel/watcher` facade identity.** #11254 made the generated CommonJS `require.resolve` table resolve file requests to their canonical filenames. For the registered `@parcel/watcher` facade entry points, that returned `…/watcher.node`, which the generated import deliberately avoids: the facade stays native even under `compilePackages`. The shared `is_watcher_facade()` predicate now governs both the import and the `require.resolve` identity. This repairs `parcel_watcher_tests::explicit_and_wildcard_compile_packages_preserve_watcher_facades` on main, which broke only once #11252 and #11254 were both in.
