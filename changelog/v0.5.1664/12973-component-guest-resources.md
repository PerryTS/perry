Perry-authored synchronous components gain WIT resource adapters in both directions. Generated guest factories create owned resources with GC-rooted payloads and optional destructors; imported owners support borrowing, transfer and explicit disposal. Argument lowering rejects duplicate transfers and ownership/borrow conflicts before consuming any owner, and escaped borrows expire at call return. Resources in an interface imported and exported by the same world retain distinct nominal identities; WIT aliases preserve the original resource identity.

Guest adapter ABI version 2 requires matching regenerated adapters and runtime archives. Explicit disposal remains necessary; deferred GC cleanup, general resource providers in native Perry, HTTP and P3 async remain separate work. The component execution harness includes an independent Rust resource provider/caller and an optional forced-moving Wasm guest profile using the instrumented WASI runtime.
