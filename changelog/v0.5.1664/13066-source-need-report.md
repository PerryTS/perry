`PERRY_SOURCE_NEED_REPORT=<path>`: a default-off, compiler-only census of retained function source. Every function, closure, class member and class whose source codegen stores in `.perry_src` is classified as never a value, a value that reaches no sink, or possibly stringified. The census writes per-owner and union byte totals and checks them against the linked section. The runtime knob `PERRY_SOURCE_READ_LOG=<path>` logs each retained-source read, as the runtime witness. Emitted code is unchanged.
