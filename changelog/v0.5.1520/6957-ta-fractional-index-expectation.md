Re-pin `inline_typed_array_fast_path_matches_slow_path` to the spec-correct fractional typed-array index behavior: `t[1.5]` now yields `undefined` on both the inline fast path and the runtime slow path (§10.4.5.2), matching Node — the assertion had encoded the old truncate-to-`t[1]` quirk, which #6903 fixed.
