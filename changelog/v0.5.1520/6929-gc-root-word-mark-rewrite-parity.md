**GC hardening — the mutable-root mark path and the rewrite path now accept the same word forms (#6910).**

A GC root slot can carry a heap reference NaN-boxed (`POINTER_TAG` / `STRING_TAG` / `BIGINT_TAG`) or **bare** — the untagged user address written straight into the word. Four hand-copied predicates decided that question four ways: `try_mark_value` (shadow-slot root marking) accepted NaN-boxed tags only, while `try_rewrite_value` (mutable-root + heap-slot rewrite), `CopyingPointerSet::decode_bits` (copying minor) and `heap_word_candidate_addr` (incremental mark barrier) all accepted bare addresses too. A bare address in a shadow-stack slot was therefore a root to three of the four surfaces and invisible to the fourth.

The concrete harm is a use-after-free, not a missed rewrite: an unmarked object is never evacuated, so it never gets a forwarding address for the rewrite pass to follow. If such a slot was the only reference, mark skipped it, evacuation skipped it, rewrite found nothing to do, and **the sweep freed it**, leaving the slot pointing at reclaimed memory. The failure would also have been invisible to CI — the unit-test build defaults to `ConservativeStackScanMode::Full`, whose native-stack scan accepts bare addresses and would have rescued the object, while production resolves `Auto -> SkipDisabled` and has no such net. Green tests, production-only UAF.

Latent today: no shipped representation puts a bare address in a shadow slot (every phase deliberately chose tagged-at-rest). Fixed rather than documented because the representation-selection RFC §5.6 unboxed pointer reps (`Ptr<Shape>`, `Str`, closure envs) are designed to store exactly that form.

Fix: a single decoder, `gc/root_words.rs`. `decode_root_word` returns `RootWord::{Nanboxed, Bare}`, and `mark_mutable_root_bits`, `try_rewrite_value` and `heap_word_candidate_addr` all route through it, so adding a representation teaches all three at once. `RootWord::encode` preserves the stored form across a rewrite (bare stays bare, a NaN box keeps its tag). `mark_global_root_bits` folds into `mark_mutable_root_bits` — both slot kinds share one decoding and `MutableRootSlotKind` now selects a telemetry bucket only. Marking is address-identical for the two forms once decoded, so the hot path pays no extra lookup.

`try_rewrite_value` additionally picks up the arm64_32 (ILP32) payload guard `heap_word_candidate_addr` already carried; on watchOS it was truncating 48-bit payloads to 32-bit addresses. Inert on 64-bit targets.

Two surfaces deliberately stay outside the shared decoder, both safe because they are supersets rather than subsets: `try_mark_value_or_raw` (conservative native-stack scan, also resolves interior pointers) and `CopyingPointerSet::decode_bits` (copying minor — additionally requires 8-byte alignment and a live classification, and its mark and rewrite are the same operation so it cannot disagree with itself). The tagged-at-rest/bare contract is documented on `js_shadow_slot_set`, including the standing prohibition on *interior* pointers in a slot.

Tests: `gc::tests::root_words`, four tests, all pinning `ConservativeStackScanMode::Disabled` because the `Full` default masks exactly this bug. `bare_address_in_shadow_slot_survives_a_real_collection` and `mutable_root_mark_and_rewrite_accept_the_same_word_forms` were both verified failing on the pre-fix mark path and passing after; the latter drives `mark_mutable_root_slots` / `rewrite_mutable_root_slots` themselves over both slot kinds, so a call site abandoning the shared decoder also fails it. Green across the full GC stress matrix: `PERRY_GC_FORCE_EVACUATE=1`, `PERRY_GC_VERIFY_EVACUATION=1`, `PERRY_GEN_GC=0`, `PERRY_WRITE_BARRIERS=0` and four combinations.
