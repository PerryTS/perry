fix(ui): `widget.animateOpacity(target, dur)` / `.animatePosition(dx, dy, dur)` now compile in their documented non-reactive form (#8470). The desugar bailed when no argument read `State.value`, dropping the call onto the generic instance-method path, which rejected a method `types/perry/ui/index.d.ts` declares — so the API worked only when an argument happened to be reactive, and `docs/examples/ui/animation/snippets.ts` was a hard `COMPILE_FAIL` in the `doc-tests` release gate. The non-reactive arm emits the animation call directly, guarded on the receiver resolving to a perry/ui native instance so a user class sharing the method name is untouched.
