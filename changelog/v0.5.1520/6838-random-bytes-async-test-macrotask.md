**Test fix:** `native_dispatch_random_bytes_value_form_fires_callback` asserted the async `randomBytes` callback fired synchronously. #6430 moved that callback onto a macrotask (`setImmediate`) to match Node's libuv-threadpool timing, so the test had been failing on `main` ever since. It now asserts the callback does *not* fire inline, pumps the callback-timer queue, and then checks the delivered `(err, buffer)` arguments — locking in the macrotask timing instead of the old inline behavior. No runtime change.
