fix(fs): `import { promises } from "node:fs"` binds the promises submodule. The named import lowered as a native METHOD (`fs.promises`), so `promises.realpath(p)` dispatched the callback-API `fs.realpath` and resolved `undefined`. The binding now routes to the `fs/promises` (and `stream/promises`, `dns/promises`) submodule namespace, whose members are the real promise-returning thunks.
