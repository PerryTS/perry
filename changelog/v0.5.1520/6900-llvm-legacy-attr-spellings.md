Fix `--backend llvm` compiles through older clang (e.g. Apple clang 15 on macos-14): the #6283 helper attribute groups are now spelled with the legacy `readnone`/`readonly` function attributes instead of the LLVM-16+ `memory(...)` syntax, which old IR parsers rejected with "unterminated attribute group". New parsers auto-upgrade the legacy spelling, so optimization semantics are unchanged.
