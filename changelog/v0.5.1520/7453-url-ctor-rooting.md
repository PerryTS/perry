- **`new URL(input, base)` no longer holds a raw heap string pointer across a collection point.** `js_url_coerce_string` returns a raw `StringHeader` pointer rather than a NaN-boxed value, so nothing else kept it alive while `base` lowered (arbitrary user code) and was itself coerced (allocates for any non-string). An evacuating cycle in either window left `js_url_new_with_base` parsing freed bytes. The coerced pointer is now rooted before the window and re-read after it — the ordering is the fix, since rooting after the coercion would root an already-stale value. `URLPattern` held its input in a bare register across the same window and now lowers both operands through `lower_exprs_rooted`. Latent, as every member of this class is: the static IR is the evidence, per `docs/src/internals/gc-rooting-invariant.md`. (#7453)
